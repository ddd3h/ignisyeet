# IgnisYeet Archive

このディレクトリには、v0.3リリース時にアーカイブされた古いファイルが含まれています。

**アーカイブ日時**: 2025年6月10日  
**アーカイブ時点のバージョン**: v0.3  

## アーカイブ内容

### `src/` - 古いソースファイル
- `main_old.cpp` - 初期バージョンのメイン
- `main_new.cpp` - 中間バージョンのメイン  
- `main.cpp` - v0.2メイン
- `output.cpp` - 古い出力システム
- `rocket.cpp` - 古いロケットクラス

### `old-binaries/` - 実行可能ファイル
- `test_*` - v0.3開発中のテスト実行ファイル
  - コンパイル済みバイナリ
  - make経由で再生成可能

### `old-makefiles/` - 古いビルドファイル
- `Makefile.old` - 以前のMakefile

## 復元方法

必要に応じて、これらのファイルを元の場所に戻すことができます：

```bash
# 例: 古いメインファイルを復元
cp archive/src/main_old.cpp src/

# 例: テストバイナリを復元
cp archive/old-binaries/test_gravity test/
```

## 注意事項

- アーカイブされたファイルは現在のv0.3システムと互換性がない可能性があります
- 復元前に現在のコードベースとの整合性を確認してください
- テストバイナリは現在のMakefileで再生成することをお勧めします
