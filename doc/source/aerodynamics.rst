空力解析
========

本章では、抽出した形状（:doc:`geometry`）から空力係数を求める方法の全体像を説明する。
IgnisYeet は空力係数を三つの方法で推算でき、設定の ``aero.method`` で選ぶ。
どの方法も、Mach 数 :math:`M` と迎角 :math:`\alpha` の格子上の **係数表** を同じ形式で作る。
飛翔計算はこの表を内挿して使うので、どの方法で作った表かを区別しない。

本章ではまず係数の定義を述べ、三つの方法の考え方と違いを比べる。
最後に、すべての方法に共通する係数表と内挿・外挿を説明する。
各方法の詳細は、部品積み上げ法を :doc:`barrowman`、パネル法を :doc:`panel`、CFD を :doc:`cfd` で述べる。

空力係数の定義
--------------

機体座標系で、空気力を機軸方向の **軸力** :math:`A` と機軸に垂直な **法線力** :math:`N` に分ける（:numref:`fig-body-frame`）。
動圧 :math:`q=\tfrac12\rho V^2` と基準面積 :math:`S=\pi d^2/4` を用いて

.. math::
   :label: eq-coeff-def

   N = C_N\,q\,S,\qquad A = C_A\,q\,S

と無次元化する。:math:`C_N` は迎角とともに増え、:math:`C_A` は迎角 0 での抗力係数 :math:`C_{D0}` に近い。
法線力の作用点を **圧力中心** :math:`x_{cp}` と呼ぶ。
:math:`x_{cp}` が重心 :math:`x_{cg}` より後ろにあれば、迎角を打ち消す向きのモーメントが生じ、機体は静的に安定である。
その余裕を基準直径で割った

.. math::
   :label: eq-static-margin

   \text{静安定余裕} = \frac{x_{cp}-x_{cg}}{d}\quad[\mathrm{cal}]

を **静安定余裕**\ （キャリバー）と呼ぶ。圧力中心と重心の位置関係で安定性を判定するのは、Barrowman :cite:`barrowman` 以来の慣例である。一般に 1〜2 cal 以上が目安とされる。

迎角 0 付近での傾き :math:`C_{N\alpha}=\partial C_N/\partial\alpha|_{\alpha=0}` を **法線力傾斜** と呼ぶ。
各部品の :math:`C_{N\alpha,i}` と圧力中心 :math:`x_i` が分かれば、全体の圧力中心はモーメントのつり合いから

.. math::
   :label: eq-cp-sum

   x_{cp} = \frac{\sum_i C_{N\alpha,i}\,x_i}{\sum_i C_{N\alpha,i}}

で求まる。これが部品積み上げ法の考え方である :cite:`barrowman`。

.. _sec-aero-methods:

三つの手法
----------

部品積み上げ法（``method = "barrowman"``、既定、:doc:`barrowman`）
   機体をノーズ・胴体・フィン・ボートテールといった部品に分ける。部品ごとの法線力と圧力中心を細長体理論や経験式で求め、\ :eq:`eq-cp-sum` で足し合わせる :cite:`barrowman,niskanen`\ 。
   抗力も部品ごとの経験式の和である。計算は一瞬で終わり、経験式の範囲内では安定した値を返す。
   一方で、使うのは抽出した寸法（半径分布とフィンの平面形）だけで、表面の形そのものは使わない。フィンと胴体の干渉は一つの係数で表す。

パネル法（``method = "panel"``、:doc:`panel`）
   抽出した形状から閉じた表面メッシュを作り、その上で流れを解く。
   亜音速では、非粘性・渦なしのポテンシャル流を Morino の定式化 :cite:`morino` で解き、Göthert の変換 :cite:`gothert` で圧縮性を入れる。
   超音速では、各パネルの傾きから圧力を決める局所傾斜法を使う。
   フィンと胴体の干渉やノーズの形は、表面の形から自然に入る。粘性は扱わず、遷音速は両側の値の補間である。

CFD（``method = "cfd"``、:doc:`cfd`）
   機体のまわりの空間を体積メッシュで覆い、圧縮性 Euler 方程式（または RANS 方程式）を外部プログラムの SU2 :cite:`su2` で解く。
   衝撃波や遷音速の流れ、フィンと胴体の干渉を、物理方程式から直接得られる。
   ただし、1 ケースに数十秒から数分かかり、SU2・gmsh・Open MPI の準備が要る。
   Euler では、摩擦抗力や底面抗力を部品積み上げ法の項で補う。

このほか、風洞試験などで得た係数表を ``method = "table"`` で読み込むこともできる（:ref:`sec-aero-table-format`）。

主な結果は次のとおりである。

* 亜音速の :math:`C_{N\alpha}` は、CFD とパネル法が 2 % 以内で一致し、部品積み上げ法はそれより 2 割ほど小さい。差は主にフィンと胴体の干渉の扱いによる（:doc:`panel`）。
* 亜音速と遷音速の圧力中心は、CFD とパネル法のほうが部品積み上げ法より後ろにあり、静安定余裕は部品積み上げ法がいちばん小さく出る。:math:`M=2` ではパネル法の圧力中心がいちばん前になる。
* 遷音速・超音速では手法ごとの差が広がる。パネル法の遷音速は補間値で、超音速の局所傾斜法は干渉を含まない。
* 超音速の軸力は、CFD と部品積み上げ法が近く、パネル法が高めに出る。

これらは非粘性の仮定の上での比較で、実測との比較ではない。どの値が実機に近いかは、この比較だけでは決まらない。
差の理由は、パネル法と CFD の章でさらに詳しく調べている。

手法の選び方
------------

* **まず部品積み上げ法を使う。** 計算が速く、外部プログラムも要らない。形状を変えながら設計を進める段階に向く。
* **パネル法で確かめる。** 仮定が部品積み上げ法と独立なので、両者の差を推算の不確かさの目安にできる。
  フィンが大きい機体や胴体が太い機体では、干渉を表面の形から計算するパネル法に物理的な根拠がある。
  静安定余裕は、両者のうち小さいほうで判断するのが安全である。
* **CFD は、遷音速・超音速の係数を確かめたいときに使う。** 部品積み上げ法やパネル法の結果を独立な方法で確かめるのにも向く。
  計算資源と時間がかかるので、Mach 数と迎角の点を絞って解き、その間を内挿する。
* **差の大きい量は不確かさが大きいと考える。** モンテカルロ解析の ``cn_scale``, ``ca_scale``\ （:doc:`dispersion`）に反映するのがよい。

いずれの手法も、風洞試験や飛翔試験による検証の代わりにはならない。

.. _sec-aero-table:

係数表と内挿・外挿
------------------

格子と保存形式
~~~~~~~~~~~~~~

既定では :math:`M=0,0.02,\dots,3.0`\ （151 点）、:math:`\alpha=0^\circ,1^\circ,\dots,30^\circ`\ （31 点）の格子で、
各点の :math:`C_N`, :math:`C_A^{\mathrm{on}}`, :math:`C_A^{\mathrm{off}}`, :math:`x_{cp}`, :math:`C_{N\alpha}`, :math:`S_0`, :math:`S_1`, :math:`S_2`
を ``aero_table.csv`` に保存する。基準量・格子・入力のハッシュ値は ``aero_table.json`` に保存する。
CSV なので、風洞試験や CFD で得た係数に差し替えて使うこともできる。

双線形内挿
~~~~~~~~~~

飛翔中の :math:`(M,\alpha)` が格子の区間 :math:`[M_i,M_{i+1}]\times[\alpha_j,\alpha_{j+1}]` にあるとき（:numref:`fig-table-interp`）、

.. math::

   t_M = \frac{M-M_i}{M_{i+1}-M_i},\qquad t_\alpha=\frac{\alpha-\alpha_j}{\alpha_{j+1}-\alpha_j}

として、四隅の値 :math:`c_{00},c_{10},c_{01},c_{11}` から

.. math::
   :label: eq-bilinear

   c(M,\alpha) = (1-t_M)(1-t_\alpha)\,c_{00} + t_M(1-t_\alpha)\,c_{10} + (1-t_M)\,t_\alpha\,c_{01} + t_M\,t_\alpha\,c_{11}

を求める。

.. _fig-table-interp:

.. figure:: _generated/tikz/table_interp.*
   :width: 70%

   係数表の双線形内挿と、範囲外での線形外挿。

外挿
~~~~

:math:`(M,\alpha)` が表の範囲外にあるときは、最も近い端の区間を使い、:math:`t_M` や :math:`t_\alpha` が :math:`[0,1]` を外れたまま
:eq:`eq-bilinear` を評価する。これは端の区間の傾きをそのまま延長する **線形外挿** である（設定 ``extrapolation = "linear"``）。
``"clamp"`` を選ぶと :math:`t` を :math:`[0,1]` に制限し、端の値で一定とする。
外挿で軸力係数が負にならないよう、:math:`C_A` は 0 以上に制限する。

迎角は :math:`0\le\alpha\le\pi` の全迎角で与えられる。機体が後ろ向きに飛ぶ（:math:`\alpha>90^\circ`）場合は、
前向きの係数を :math:`\alpha'=\pi-\alpha` で引き、軸力の向きを反転させる（:ref:`sec-aero-forces`）。
