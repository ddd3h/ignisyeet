形状の取り込みと抽出
====================

空力係数を計算するには、機体の **胴体の半径分布** :math:`r_b(x)` と **フィンの寸法** が必要である。
IgnisYeet はこれらを機体の CAD データから取り出す。
入力は STEP、IGES、BREP の CAD ファイル（``rocket.cad``）か STL ファイル（``rocket.stl``）で、どちらも機体の表面の三角形の集まりとして扱う。CAD ファイルは三角形に分割（テッセレーション）してから抽出する。
抽出がずれると、その後の空力係数と静的余裕がすべてずれるので、機体の単位とノーズの向きは結果を見る前に確かめる。CAD ファイルの単位はファイルから得られ、STL の単位は ``stl_scale`` で与える。

STL ファイルとは
----------------

この節は、STL を入力にする場合（``rocket.stl``）に当てはまる。CAD ファイルを入力にする場合は、表面の三角形がファイルの形状から作られるので、書き出しの分割や単位の注意は要らない。

STL は、立体の **表面を小さな三角形の集まりで表す** ファイル形式である（:numref:`fig-stl-mesh`）。
もとは 3D Systems 社が光造形（stereolithography）装置のために定めた形式で、
現在は 3D プリンタ向けの標準的な形式として、ほとんどの CAD（Fusion 360、SolidWorks、FreeCAD など）から書き出せる。

.. _fig-stl-mesh:

.. figure:: /_generated/plots/stl_mesh.*
   :width: 100%

   付属のサンプル機体の STL（``examples/sample_rocket.stl``、約 1.4 万個の三角形）。
   左は全体、右は尾部の拡大で、細い線が三角形の辺である。胴体は周方向 72 分割の細長い三角形の帯、フィンは各面 2 枚の三角形でできている。見るところは、曲面が細かい三角形で、平らなフィンが少数の大きな三角形で表されることである。

1 つの三角形（ファセット）は、外向きの法線ベクトル 1 本と頂点 3 つの座標で表される。
ファイル全体はこのファセットを並べただけのもので、面のつながり、色、材質、**単位** の情報は持たない。
テキスト形式（ASCII）とバイナリ形式のどちらも読める。
STL には単位がないので、CAD で mm 単位で作った機体なら ``stl_scale = 0.001`` で m に直す。
曲面は三角形で近似されているため、ノーズのような曲面は書き出し時の分割の細かさ（許容誤差）に応じて多角形状になる。
粗い分割、三角形の向きのそろっていないファイル、内部構造を含むファイルでも、抽出は同じ仮定で行う。

仮定
----

* 胴体は **軸対称**\ （回転体）であり、フィンは同じ形のものが機軸まわりに等間隔に並ぶ。
* フィンは台形（後退角つき）で近似する。クリップトデルタや楕円フィンも等価な台形として扱われる。
* 表面は閉じている（穴のない、ソリッドとして書き出した）必要がある。STL では書き出し方で決まり、CAD ファイルではソリッドとして作られたモデルが当てはまる。閉じた殻が複数あってもよく、内部の構造（隔壁やモータ）が含まれていても、各断面で外側の点だけを使うので影響しない。

機軸の決定
----------

三角形 :math:`k` の面積を :math:`A_k`、重心を :math:`\bm{m}_k` とし、面積で重み付けた重心

.. math::

   \bm{c} = \frac{\sum_k A_k\,\bm{m}_k}{\sum_k A_k}

と、頂点 :math:`\bm{v}` の分散行列

.. math::
   :label: eq-pca

   C = \sum_k A_k \sum_{\bm{v}\in k}(\bm{v}-\bm{c})(\bm{v}-\bm{c})^\top

の **最大固有値に対応する固有ベクトル** を機軸とする（主成分分析 :cite:`jolliffe`）。
ロケットは細長いので、最も広がっている方向が機軸になる。機体をどの向きで書き出しても、同じ機軸が得られる。
固有ベクトルには向き（符号）の任意性があるので、どちらがノーズかは次に述べる規則で決める（:ref:`sec-geometry-orientation`）。
設定 ``nose_direction`` で向きを指定すると、指定した向きを自動判定で覆さない。

断面での切り出し
----------------

機軸方向の全長を :math:`L` とし、:math:`N_s` 枚（既定 600 枚）の断面

.. math::

   x_i = \left(i+\tfrac12\right)\frac{L}{N_s},\qquad i=0,1,\dots,N_s-1

で STL を切る（:numref:`fig-slicing` 左）。断面間隔は :math:`\Delta x=L/N_s` である。

.. _fig-slicing:

.. figure:: /_generated/tikz/slicing.*
   :width: 100%

   左: 機軸に垂直な断面で切る。右: 断面上の点。胴体半径は角度ビンごとの最大半径の中央値として求め、
   それより :math:`\delta` 以上外側の点をフィンとみなす。

胴体半径
--------

断面上の点を極座標 :math:`(r,\theta)` で表し、角度を 72 個のビン（5° 幅）に分け、ビン :math:`j` ごとの最大の :math:`r` を :math:`r_{\max,j}` とする。
断面 :math:`i` の胴体半径は、点を含むビンの :math:`r_{\max,j}` の **中央値** とする。

.. math::
   :label: eq-rbody

   r_{b,i} = \operatorname{median}_{j}\ r_{\max,j}

フィンは数ビンしか占めないので、中央値はフィンの影響をほとんど受けない :cite:`huber`\ （平均や最大値ではフィンに引きずられる）。
また、内部構造の点は同じビンのより外側の点に隠れるので無視される。
全断面での最大値 :math:`r_{\max}=\max_i r_{b,i}` を基準半径とし、基準直径 :math:`d=2r_{\max}`、基準面積 :math:`S=\pi r_{\max}^2` とする。

ランチラグやレールボタンのように短い範囲だけ突き出た部品が基準半径を決めないように、最大値が断面ごとの胴体半径の 90 パーセンタイル :math:`r_{90}` の 1.15 倍を超えるときは、基準半径に :math:`r_{90}` を使い、無視した部品があることを警告する（:ref:`IY-G502`）。
円すいだけの胴体やボートテールのある胴体では、最大値が :math:`r_{90}` の 1.15 倍を超えないので、最大値をそのまま使う。

ノーズの向きの判定
------------------

``nose_direction`` を指定しないときは、次の順で決める。

1. **フィンの位置**：フィンは胴体の後半にあるので、フィンの検出（次節）をまず行い、フィン根元の中央 :math:`(x_{le}+a/2)/L`\ （:math:`a` は根元翼弦）が全長の中央から 0.08 を超えて離れていれば、フィンのある側を後端とする。
   この判定は、先端に太い部品（ボートテールの後ろの細い端、ノズルの突き出しなど）があっても影響を受けない。
2. **端の半径**：フィンの位置が決め手にならない（フィンがない、またはフィンが中央付近にある）ときは、両端それぞれの 2 断面の胴体半径の和を比べ、**小さい方をノーズ** とする（ノーズは先細りで、後端は太い）。この場合は、端の半径だけで決めたことを警告する（:ref:`IY-G504`）。

二つの判定が食い違うときは、フィンの位置を採用して警告する（:ref:`IY-G503`）。

胴体の諸量
----------

空力計算で使う量は、断面の和として次のように定義する。

.. math::

   \begin{aligned}
   S_{\mathrm{wet}} &= \sum_i 2\pi r_{b,i}\,\Delta x\sqrt{1+\left(\frac{\dd r_b}{\dd x}\right)_i^2} &&\text{（胴体の濡れ面積）}\\
   A_p &= \sum_i 2r_{b,i}\,\Delta x,\qquad x_p=\frac{1}{A_p}\sum_i 2r_{b,i}\,x_i\,\Delta x &&\text{（側面投影面積とその図心）}
   \end{aligned}

**ノーズ**

先端から見て初めて :math:`r_{b,i}\ge0.999\,r_{\max}` となる断面をノーズの終端とし、その位置をノーズ長 :math:`L_n`、半径を :math:`R_n` とする。
さらにノーズの形を表す量として

* 接合部の半頂角 :math:`\phi_j`\ ：ノーズの最後の 10 % 区間での :math:`r_b` の傾きの逆正接。円すいなら :math:`\arctan(R_n/L_n)`、接線オジブなら 0 に近い。
* 体積比 :math:`v_r=V_n/(\pi R_n^2L_n)`\ ：ノーズ体積と外接円柱の体積の比。円すいは 1/3、接線オジブは約 0.53。

を求め、抗力の計算（:ref:`sec-nose-drag`）で使う。

**ボートテール**

後端から見て初めて :math:`r_b\ge0.99\,r_{\max}` となる断面より後ろが 3 断面以上あり、
かつ後端の半径 :math:`r_{\mathrm{base}}` が :math:`0.97\,r_{\max}` より小さいとき、その区間をボートテールとする。

フィンの検出
------------

しきい値を :math:`\delta=0.05\,r_{\max}`\ （設定 ``fin_threshold``）とし、:math:`r>r_{b,i}+\delta` の点を **フィン点** とする。
取り出すフィンの寸法は次のように定義する。

1. **枚数**：断面ごとにフィン点の角度を並べ、10° 以上離れたところで区切ったまとまりの数の最頻値をフィン枚数 :math:`N` とする。
2. **フィン区間**：フィン点を含む断面が連続する区間のうち、フィン高さの和が最大のものを採用する（カナードなどがあっても主翼を選ぶ）。
3. **根元**：胴体表面をまたぐ線分を含む断面を「根元が胴体についている断面」とし、その最初と最後の断面から根元の前縁・後縁を求める。
4. **スパン**：区間内での最大の :math:`s_i=\max r - r_{b,i}` をスパン :math:`s` とする。
5. **端翼弦**：区間内で :math:`s_i` を積分した面積 :math:`A_f=\sum_i s_i\,\Delta x` が台形の面積 :math:`\tfrac12(a+b)s` に等しいとして、:math:`b=2A_f/s-a` とする。
6. **後退長**：初めて :math:`s_i\ge0.97\,s` となる断面の位置 :math:`x_k` から、:math:`m=(x_k-\Delta x/2-x_{le})/0.97` とする。
7. **厚さ**：各フィンの中心角からの周方向の幅を厚さとし、全断面・全フィンの中央値をとる。

フィン点はしきい値 :math:`\delta` より外側でしか見えないので、後退した前縁では実際の前縁より少し後ろからしか検出できない。
そこで、根元の最初の 2 断面のフィン高さ :math:`s_1, s_2` から高さが 0 になる位置を線形外挿する。

.. math::

   x_{le} = x_1 - s_1\,\frac{\Delta x}{s_2-s_1}

外挿量は :math:`3\Delta x` までに制限し、:math:`s_2\le s_1`\ （前縁が機軸に垂直な場合）は断面の境界 :math:`x_1-\Delta x/2` を使う。後縁も同様である。

適用範囲と精度
--------------

* 胴体は軸対称、フィンは台形で、軸まわりに等間隔に並ぶ。ポッド、エアブレーキ、非対称な突起、レールボタンなどは取り込まない。
* フィンの断面は一種類（両凸）で扱う。厚さは周方向の幅の中央値であり、翼形そのものは取り出さない。
* 閉じた表面が前提で、穴があるとエラーになる。
* フィン点は :math:`\delta` より外側でしか見えないので、前縁・後縁は外挿で補う。外挿量は :math:`3\Delta x` までである。
* ノーズ長は半径が :math:`0.999\,r_{\max}` に達する位置で決めるので、接線オジブでは幾何学的な終端より手前になる（:numref:`tbl-geometry`）。ノーズ長は抗力の推算（形状係数）にしか使わず、法線力は半径分布全体から直接計算するので影響は小さい。

詳しい一覧は :ref:`sec-lim-aero` にある。

形状がモデルの仮定からはずれるときの抽出の振る舞いは次のとおりである。
ランチラグやレールボタンのような短い突起は、基準半径の決定から除かれて警告が出る（:ref:`IY-G502`）。その抗力は取り込まれないので、``rocket.extra_cd`` で加える。
突き出したノズルや強いボートテールで底面半径が基準半径の 60 % 未満になるときも警告が出て（:ref:`IY-G508`）、底面抗力はこの半径で計算される。意図した形かを確かめる。
隔壁やモータなどの内部構造、複数の閉じた殻は、各断面で外側の点だけを使うので影響しない。
クリップトデルタや楕円のフィンは面積が等しい台形に置き換えて扱うので、形が大きく違うときは ``fin_override`` で与える。
エアブレーキやカメラポッドのような非対称な突起はフィンの検出を誤らせることがあり、非軸対称の効果も入らない。抽出結果を確かめて、必要なら ``fin_override`` を与える。
カナードなどフィンの組が複数あるときは、フィン高さの和が最大の区間を採用するので、主翼でないときも ``fin_override`` で与える。
穴のある STL や開いた殻は、開いた辺が辺の 1 % を超えるか、穴の幅が基準直径の 0.1 倍を超えるとエラーになる（:ref:`IY-G010`、:ref:`IY-G011`）。小さな欠陥は警告にとどまる（:ref:`IY-G501`）。穴をふさぐか、ソリッドとして書き出し直す。
警告の一覧と対処は :ref:`sec-geometry-warnings` にある。

付属のサンプル機体（接線オジブのノーズ、4 枚の台形フィン）での抽出結果を :numref:`fig-geometry-profile` と :numref:`tbl-geometry` に示す。
サンプル機体の STL を mm 単位に拡大し、任意の回転と平行移動を加えて抽出しても、この表のとおり設計値を復元できる（フィン寸法の誤差 1 mm 以内。検証。:ref:`page-vv-verification`）。
円すいノーズ・3 枚フィン・後端から離れたフィンの組み合わせでも、接合部の半頂角、体積比 1/3、フィンの位置を正しく求められることを確かめている。
手法を実測と比べた妥当性確認はない。

選び方
------

STL の単位、ノーズの向き、フィンの寸法は、抽出の結果を見て決める。抽出結果は ``ignisyeet geom`` が書き出し、図にして確かめられる（手順は :ref:`page-howto-own-rocket`）。
:numref:`tbl-choose-geometry` に、各入力を決める基準を挙げる。

.. _tbl-choose-geometry:

.. list-table:: 形状の入力の選び方
   :header-rows: 1
   :widths: 24 36 40

   * - 設定キー
     - 確かめること
     - 方針
   * - ``stl_scale``
     - 全長と基準直径が実機と合うか
     - 常に決める（mm なら 0.001、m なら 1）
   * - ``nose_direction``
     - 抽出したノーズ側が正しいか
     - 通常は ``auto``。警告が出たら軸を明示
   * - ``fin_override``
     - フィン寸法が設計値と合うか
     - ずれる機体では設計値を与える
   * - ``n_slices``
     - フィン寸法が収束しているか
     - 既定 600。小さなフィンは 1200 で確かめる
   * - ``fin_threshold``
     - フィンの検出範囲
     - 既定のまま（0.1 までは結果がほぼ変わらない）

``stl_scale`` は、全長が 0.1〜20 m の外ならエラー、直径が 0.005〜3 m の外なら警告になる。範囲内で単位を間違える場合（例：cm と mm）は、実機の全長と見比べて確かめる。
端の形から決めた警告（:ref:`IY-G504`、:ref:`IY-G503`）が出たら、``nose_direction`` を ``±x``、``±y``、``±z`` で明示する。明示した向きは自動判定で覆さない。
収束の様子は :numref:`tbl-geometry-slices` と :numref:`tbl-geometry-threshold` にある。

関連する設定
------------

STL の単位は ``rocket.stl_scale``\ （既定 1.0）、ノーズの向きは ``rocket.nose_direction``\ （既定 ``auto``）、フィン寸法の置き換えは ``rocket.fin_override`` で決める。
断面数 ``aero.n_slices``\ （既定 600、20〜10000）とフィンの検出しきい値 ``aero.fin_threshold``\ （既定 0.05）は抽出の細かさを決める。
各キーの型と範囲は設定ファイルの章（:ref:`cfg-rocket-stl_scale`）にある。
