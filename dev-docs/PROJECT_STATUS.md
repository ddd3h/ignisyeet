## 🏗️ アーキテクチャ概要

### ディレクトリ構造
```
ignisyeet/
├── include/           # ヘッダーファイル
│   ├── physics/       # 物理モデル (重力、大気、ベクトル等)
│   ├── simulation/    # シミュレーションエンジン
│   ├── rocket/        # ロケット関連
│   ├── environment/   # 環境モデル
│   └── output/        # 出力管理
├── src/              # 実装ファイル
├── test/             # テストファイル
├── dev-docs/         # 開発ドキュメント
├── results/          # シミュレーション結果
└── doc/              # ドキュメント・画像
```

### 主要コンポーネント

#### 物理エンジン
- **Vector3D**: 3次元ベクトル演算
- **Quaternion**: 姿勢表現・回転計算
- **State**: ロケット状態（位置、速度、姿勢等）
- **GravityModel**: 3段階重力モデル
- **AtmosphereModel**: 3段階大気モデル

#### シミュレーションエンジン
- **Engine**: メインシミュレーションループ
- **Integrator**: 数値積分（Euler, Leapfrog, RK4）
- **Vehicle**: ロケット物理モデル

#### 設定・出力システム
- **Parameters**: TOML設定ファイル管理
- **OutputManager**: 結果出力管理

## 📊 パフォーマンス特性

### 計算負荷レベル
- **Level 1モデル**: O(1) - 最小負荷
- **Level 2モデル**: O(1) - 中程度負荷  
- **Level 3モデル**: O(1) - 最大負荷（三角関数計算含む）

### 物理精度
- **重力**: 1km高度で0.03%精度向上（Level 2 vs 1）
- **大気**: ISA標準準拠、11km高度で密度1/4減少
- **空力**: マッハ数・高度依存、最大25M計算/秒
- **風効果**: 100m/s速度でコリオリ力0.007m/s²
