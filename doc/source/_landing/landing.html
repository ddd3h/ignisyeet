IgnisYeet

ロケットの CAD データから空力特性を推算し、6 自由度で飛ばし、落下分散まで求めるオープンソースの飛翔シミュレータ。

機体の外形は CAD モデルから取り出し、空力係数は Mach 数と迎角の格子で一度だけ計算して表に保存する。飛翔計算はその表を使って、ランチャ滑走から着地までを数値積分する。計算の重い部分は Rust、作図は Python で実装している。

できること

CAD データを入力にして、形状の抽出から落下分散のレポートまでを一つの流れで計算する。各カードは、その内容を説明する章へのリンクである。

  • CAD から形状を取り出す

    STEP、IGES、BREP の CAD データ（STL も可）から、胴体の半径分布とフィンの寸法を取り出す。主軸の検出とフィンの自動検出を備え、フィンは手動で指定することもできる。

    形状の取り込みと抽出

  • 空力の推算

    部品積み上げ法（Barrowman）、パネル法、CFD、外部の係数表から選ぶ。係数は Mach 数と迎角の格子で一度だけ計算して保存し、減衰、見かけ質量、Magnus 力、誘導ロールを含む六分力も扱う。

    空力解析

  • SU2 による CFD

    Euler と RANS の CFD で係数表を作る。表面は、抽出した形状、STL、STEP のモデルから作る。SU2 8.3.0 を使い、残差と係数の変化から収束を判定する。

    CFD による空力表の作成

  • 6 自由度の飛翔

    ランチャ滑走から着地までを剛体の 6 自由度で積分する。平らな地球と自転する地球、US Standard Atmosphere 1976、一定・べき乗則・対数・プロファイルの風、RK4・RK45・DOP853 から選べる。

    運動方程式

  • 降下とパラシュート

    頂点のあとの降下を、弾道落下、単一のパラシュート、二段開傘（ドローグとメイン）から選ぶ。降下の方式は着地点を最も大きく左右する。

    降下方式

  • 落下分散と保安距離

    風速と風向の格子、または Monte Carlo で着地点の広がりを求める。誤差楕円と着地距離のパーセンタイルを出し、保安距離を決める手順も文書にしてある。

    落下分散

  • レポート、KML、プロット

    結果は CSV と JSON に書き出す。計算結果をまとめた一つの HTML レポート、Google Earth 用の KML、プロットも出力する。端末には進捗と結果を読みやすく表示する。

    使い方

  • 再現性と検証

    入力が変わらなければ係数表を再利用する。レポートには設定と飛翔結果のハッシュを記す。式と数値解法の検証、他のプログラムとの相互比較、実測との比較（妥当性確認）をそれぞれ章にまとめている。

    検証

計算の流れ

各段階は独立したコマンドで、一つの設定ファイルを共有する。make all で通しても実行できる。

  1. CADSTEP / IGES / BREP、または STLrocket.cad
  2. 形状半径分布とフィンの抽出geom
  3. 空力Mach 数と迎角の係数表aero
  4. 飛翔6 自由度、ランチャから着地までsim
  5. 落下分散風の格子または Monte Carlodispersion
  6. レポートHTML、KML、プロットreport

検証の状況

この結果はモデルの計算結果である。何をどこまで確かめたかを、確かめ方の種類ごとに分けて示す。

  • 検証とテスト

    593 + 41

    Rust のテスト関数 593 本と Python のテスト関数 41 本。式と数値解法は、解析解や理論との比較で検証している。

    検証テスト

  • 相互比較

    OpenRocket / RocketPy

    サンプル機体の上昇を、OpenRocket 24.12 と RocketPy 1.13.0 でも計算した。抗力を共通にした二組の頂点高度の差は +0.01 % と +0.04 %。抗力の組み立てが違う OpenRocket とは 6.7 % の差がある。相互比較は、どれが実機に近いかを決めない。

    相互比較と妥当性確認

  • 妥当性確認

    Basic Finner

    実測との比較は、Basic Finner の超音速の範囲に限られる。それ以外の比較はすべて、手法どうしまたはプログラムどうしの相互比較である。
