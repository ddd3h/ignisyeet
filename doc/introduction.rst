はじめに
========

IgnisYeetについて
-----------------

IgnisYeetは、ロケット物理学の包括的なシミュレーションを提供する
高性能なC++フレームワークです。

設計哲学
--------

多層物理精度
~~~~~~~~~~~~
IgnisYeetでは、同じ物理現象に対して複数の精度レベルを提供します：

* **Level 1**: 基本的な近似モデル（高速計算、教育用途）
* **Level 2**: 中程度の精度（バランスの取れた性能）
* **Level 3**: 高精度モデル（研究・実用レベル）

この設計により、用途に応じて適切な精度と性能のバランスを選択できます。

モジュラー構造
~~~~~~~~~~~~~~
各物理モデルは独立したモジュールとして実装されており、
必要に応じて組み合わせて使用することができます。

開発目標
--------

* **物理的妥当性**: 実際の物理法則に基づいた正確なシミュレーション
* **拡張性**: 新しい物理モデルの追加が容易
* **性能**: 大規模シミュレーションに対応する高速処理
* **使いやすさ**: 直感的なAPIと豊富なドキュメント

対象ユーザー
------------

* ロケット工学の研究者
* 航空宇宙工学の学生
* ゲーム開発者（物理シミュレーション）
* 教育機関（物理学習支援ツール）
