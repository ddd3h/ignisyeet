物理モデル
==========

IgnisYeetは、各物理現象に対して3段階の精度レベLevel 3: 回転地球 + コリオリ力 ✅
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~提供します。

重力モデル ✅ 実装完了
----------------------------

Level 1: 一様重力場 ✅
~~~~~~~~~~~~~~~~~~~~~~~

最もシンプルな重力モデルです。地表付近での近似として使用されます。

.. math::

   \vec{F}_g = -mg\hat{z}

特徴：
* 定数重力加速度 g = 9.81 m/s²
* 高度による変化なし
* 最高速度の計算

適用範囲：
* 低高度フライト（～1km）
* 教育用途
* 概算計算

Level 2: 高度依存重力 ✅
~~~~~~~~~~~~~~~~~~~~~~~~~

高度による重力変化を考慮したモデルです。

.. math::

   g(h) = g_0 \left(\frac{R_E}{R_E + h}\right)^2

パラメータ：
* :math:`g_0`: 地表重力加速度 (9.81 m/s²)
* :math:`R_E`: 地球半径 (6,371,000 m)
* :math:`h`: 地表からの高度

適用範囲：
* 中高度フライト（～100km）
* サブオービタルフライト
* 大部分の実用シミュレーション

Level 3: 回転地球 + コリオリ力
~~~~~~~~~~~~~~~~~~~~~~~~~~~~

地球の自転とコリオリ力を含む完全な重力モデルです。

.. math::

   \vec{F} = m\vec{g}(h) - 2m(\vec{\Omega} \times \vec{v}) - m(\vec{\Omega} \times (\vec{\Omega} \times \vec{r}))

追加考慮要素：
* 地球自転角速度 :math:`\Omega = 7.292 \times 10^{-5}` rad/s
* コリオリ力
* 遠心力

適用範囲：
* 軌道計算
* 長距離弾道ミサイル
* 精密軌道力学

大気モデル ✅ 実装完了
----------------------------

Level 1: 定密度大気 ✅
~~~~~~~~~~~~~~~~~~~~~~

一定密度の大気モデルです。

.. math::

   \rho = \rho_0 = 1.225 \text{ kg/m}^3

特徴：
* 海面レベル密度で固定
* 温度・圧力変化なし
* 最小限の計算負荷

適用範囲：
* 低高度（～1km）
* 概算計算

Level 2: ISA標準大気 ✅
~~~~~~~~~~~~~~~~~~~~~~~~

国際標準大気モデル（ISA）に基づく高度依存大気です。

.. math::

   T(h) = T_0 - Lh \quad (h < 11000m)

.. math::

   p(h) = p_0 \left(1 - \frac{Lh}{T_0}\right)^{\frac{gM}{RL}}

.. math::

   \rho(h) = \frac{p(h)}{R_s T(h)}

パラメータ：
* :math:`T_0 = 288.15` K（海面温度）
* :math:`L = 0.0065` K/m（温度勾配）
* :math:`p_0 = 101325` Pa（海面圧力）

適用範囲：
* 対流圏（～11km）
* 標準的な航空機・ロケット

Level 3: 動的大気 ✅
~~~~~~~~~~~~~~~~~~~~

風と突風効果を含む動的大気モデルです。

.. math::

   \vec{v}_{rel} = \vec{v}_{rocket} - \vec{v}_{wind}(h, t)

風モデル：
* ログ則による風速プロファイル
* 乱流・突風効果
* 時間変動

適用範囲：
* 実際の気象条件
* 飛行安全解析
* 制御システム設計

空力学モデル ✅ 実装完了
----------------------------

Level 1: 基本抗力モデル ✅
~~~~~~~~~~~~~~~~~~~~~~~~~~

最もシンプルな空気抵抗モデルです。

.. math::

   \vec{F}_D = -\frac{1}{2}\rho v^2 C_D A \frac{\vec{v}}{|\vec{v}|}

パラメータ：
* :math:`C_D`: 抗力係数（通常0.3-0.8）
* :math:`A`: 参照面積

特徴：
* 抗力のみ考慮
* 一定抗力係数
* 揚力効果なし

**実装状況**: ✅ 完了 - テスト済み、32.5N抗力@100m/s確認済み

適用範囲：
* 低速度（マッハ数 < 0.3）
* 球形・円筒形物体
* 初期設計段階

Level 2: マッハ数依存モデル ✅
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

マッハ数による抗力変化と揚力を考慮したモデルです。

.. math::

   C_D(M) = C_{D0} + \Delta C_D \cdot f(M)

.. math::

   \vec{F}_L = \frac{1}{2}\rho v^2 C_L A \vec{n}

マッハ数依存関数：
* 亜音速域（M < 0.8）：緩やかな増加
* 遷音速域（0.8 < M < 1.2）：急激な増加
* 超音速域（M > 1.2）：緩やかな減少

**実装状況**: ✅ 完了 - マッハ0.3-2.0でテスト済み、抗力31.8N-5949Nの適切な変化確認

適用範囲：
* 高速飛行（全マッハ数域）
* 翼面を持つ飛行体
* 詳細設計段階

Level 3: 完全空力学モデル ✅
~~~~~~~~~~~~~~~~~~~~~~~~~~~~

圧縮性効果と3次元流れを考慮した完全モデルです。

考慮要素：
* 圧縮性効果
* 迎角依存性
* レイノルズ数効果
* 3次元流れ効果

.. math::

   C_D = C_{D0} + C_{Di}(\alpha) + \Delta C_D(M, Re)

**実装状況**: ✅ 完了 - 全6DOF力・モーメント計算、Cd=0.56/Cl=0.56/Cs=0.17でテスト済み

適用範囲：
* 高精度シミュレーション
* 実機設計
* 研究開発
