はじめに
========

開発の方針
----------

IgnisYeet はどの団体・組織にも属さないオープンソースソフトウェアとして開発している。
飛翔シミュレーションの結果は、保安域の設定や打上げの可否判断といった **安全に直結する判断** の根拠になる。
だからこそ、計算に使うモデル・式・仮定はすべて公開し、誰でも検証できる状態にしておくべきだと考える。

本ドキュメントは、その「検証できる状態」を支えるためのものである。
各章では、プログラムが実際に計算している式を示し、
どの文献のどの手法に基づくか、どこに近似や限界があるかを明記する。
ソースコードは次の場所で公開している。

    https://github.com/ddd3h/ignisyeet

改良や誤りの指摘は Issue や Pull Request で歓迎する。

飛翔シミュレーションとは
------------------------

ロケットの飛翔シミュレーションは、飛翔体の運動を予測する計算である。
主な用途は次の三つである。

* 飛翔経路（到達高度、最大速度、最大動圧など）の予測
* 落下位置の推定と、その風による広がり（落下分散）の評価
* 保安域の設定など、安全対策の基礎資料の作成

ロケットに働く主な力は **推力・重力・空気力** である。

推力
   最も大きな力で、軌道を大きく左右する。IgnisYeet では、燃焼試験などで得た推力履歴（推力曲線）をそのまま用いる。推力の一般論は教科書 :cite:`sutton` に詳しい。

重力
   地上付近ではほぼ一定とみなせるが、高度が上がると小さくなる。IgnisYeet では高度の 2 乗に反比例するモデルを用いる（:ref:`sec-gravity`）。

空気力
   機体が空気中を進むことで生じる力で、機体軸方向の **軸力** と、それに垂直な **法線力** に分けて扱う。
   大きさは機体形状・Mach 数・迎角に依存し、さらに風によって対気速度が変わるため、軌道への影響が大きい。
   空力係数の推算は、細長いロケット向けの部品積み上げ法 :cite:`barrowman` を基礎にし、パネル法と CFD も選べる（:doc:`aerodynamics`）。

これらを総合的に、かつ透明な形で扱うことが本ソフトウェアの目的である。
モデルロケット向けのオープンソースの飛翔シミュレータには OpenRocket :cite:`niskanen,niskanentech` があり、IgnisYeet の空力係数と抗力の推算法はこれに倣っている。

本書の読み方
------------

* すぐに使いたい場合は :doc:`usage` を読めばよい。
* 計算全体の流れは :doc:`overview` にまとめた。
* :doc:`coordinates` から :doc:`dispersion` までが理論編で、プログラムの処理順に並べている。
* :doc:`verification` では、各モデルが正しく実装されていることをどう確かめたかを示す。
* :doc:`limitations` には、現時点のモデルが扱えないことを正直に書いた。結果を使う前に必ず目を通してほしい。
