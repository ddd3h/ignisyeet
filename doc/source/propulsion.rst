推力と質量特性
==============

推力曲線と、機体の質量・重心・慣性は、飛翔計算の入力である。モデルとしての選択肢は少なく、決めるのは入力の値とその不確かさの見込み方である。
推力曲線は頂点高度と加速の履歴を、質量と重心は着地点と静安定余裕を決める。

この章は、推力曲線と推進剤の消費、質量・重心・慣性モーメントの組み立てを述べ、入力を変えたときに結果がどれだけ動くかを示す。

推力の物理
----------

ロケットの推力は、ノズルから噴出するガスの運動量と、ノズル出口の圧力差から生じる :cite:`sutton`。

.. math::
   :label: eq-thrust-theory

   T = \dot m\,v_e + (p_e-p_\infty)\,A_e

:math:`\dot m` は推進剤の質量流量、:math:`v_e` は噴出速度、:math:`p_e` と :math:`A_e` はノズル出口の圧力と面積、:math:`p_\infty` は周囲の圧力である。
比推力 :math:`I_{sp}` を用いれば :math:`T=I_{sp}\,g_0\,\dot m` とも書ける。

しかし、燃焼室の圧力履歴や噴出速度を精度よく予測するのは難しい。
IgnisYeet では多くのシミュレータと同様に、燃焼試験などで **実測した推力履歴** をそのまま用いる。
:eq:`eq-thrust-theory` の第 2 項の高度依存（上空で推力がわずかに増える効果）は考慮していない。

推力曲線
--------

推力履歴は、時刻 :math:`t_k` [s] と推力 :math:`T_k` [N] の点列で与える。形式は RASP 形式 :cite:`rasp` で、書式は :ref:`sec-propulsion-eng` にある。
点の間は線形補間し、最後の時刻を燃焼終了時刻 :math:`t_b` とする。先頭が :math:`t=0` でなければ :math:`(0,0)` を補う。
先頭が :math:`(0,F)`\ （:math:`F\ne0`）の曲線では、点火の瞬間から全推力 :math:`F` がかかる。先頭が :math:`(0,0)` なら 0 から線形に立ち上がる。

ヘッダの直径、長さ、推進剤質量を質量モデルに使う。全備質量（6 番目の値）は検査に使うだけで、質量モデルには使わない。
空のモータケースの質量は ``rocket.dry_mass`` に含める。

推進剤の消費
------------

燃焼中の質量流量は推力に比例する（比推力が一定）と仮定する :cite:`sutton`。
すると時刻 :math:`t` までに消費した推進剤は、その時刻までの力積に比例する。

.. math::
   :label: eq-prop-mass

   I(t) = \int_0^t T(t')\,\dd t',\qquad
   m_p(t) = m_{p0}\left(1-\frac{I(t)}{I_t}\right),\qquad I_t=I(t_b)

:math:`I_t` は全力積、:math:`m_{p0}` は初期の推進剤質量である。:math:`I(t)` は推力曲線の台形積分で厳密に求まる。
サンプルのモータ（架空）の推力と推進剤質量を :numref:`fig-thrust-mass` に示す。

.. _fig-thrust-mass:

.. figure:: /_generated/plots/thrust_mass.*
   :width: 100%

   サンプルモータの推力曲線（左）と推進剤質量（右）。推力曲線の面積が全力積 :math:`I_t` で、推進剤質量は力積に比例して 0 まで減る。

質量・重心・慣性モーメント
--------------------------

推進剤を、モータケースと同じ直径 :math:`D_m=2r_m`、長さ :math:`L_m` の一様な円柱とみなす。
その重心はモータの中央 :math:`x_p=x_{\mathrm{aft}}-L_m/2` にある（:math:`x_{\mathrm{aft}}` はモータ後端の位置）。
乾燥質量 :math:`m_d`、乾燥重心 :math:`x_d`、乾燥慣性モーメント :math:`I_{xx,d}, I_{yy,d}` と合わせて

.. math::
   :label: eq-mass-props

   \begin{aligned}
   m &= m_d + m_p,\qquad x_{cg} = \frac{m_d\,x_d + m_p\,x_p}{m},\\
   I_{yy} &= I_{yy,d} + m_d\,(x_d-x_{cg})^2 + m_p\,\frac{3r_m^2+L_m^2}{12} + m_p\,(x_p-x_{cg})^2,\\
   I_{xx} &= I_{xx,d} + \frac12\,m_p\,r_m^2
   \end{aligned}

とする。:math:`I_{yy}` は重心まわりのピッチ・ヨーの慣性モーメントで、平行軸の定理 :cite:`goldstein` で現在の重心まわりに移している。
慣性乗積や重心の横ずれがなく軸対称のときは :math:`I_{zz}=I_{yy}` である。それ以外の慣性テンソルの扱いは :ref:`sec-inertia-tensor` で述べる。

.. _sec-usage-inertia-estimate:

慣性モーメントの見積もり
------------------------

CAD がないときは、次の見積もりを使う。
乾燥質量 :math:`m`、全長 :math:`L`、外半径 :math:`R` の機体を、一様な円柱とみなすと、重心まわりの値は
:math:`I_{xx}=\tfrac12 mR^2`\ （ロール）、:math:`I_{yy}=I_{zz}=m\,(3R^2+L^2)/12`\ （ピッチ・ヨー）である。
機体が薄肉の円筒に近ければ、:math:`I_{xx}=mR^2`、:math:`I_{yy}=I_{zz}=m\,(6R^2+L^2)/12` を使う。

質量が一様でない機体は、部品（ノーズ、胴体、フィン、モータケース、電装など）に分け、部品ごとの質量 :math:`m_i` と乾燥重心からの軸方向の距離 :math:`d_i` から
:math:`I_{yy}=\sum_i\bigl(I_{yy,i}+m_id_i^2\bigr)` と足し合わせる（平行軸の定理）。ロールは :math:`d_i` の項が入らず、:math:`I_{xx}=\sum_iI_{xx,i}` である。
質量の分布が分からないときの見積もりは粗く、ピッチ慣性は質量の偏りで大きく変わる。モンテカルロ解析の ``dry_mass`` で幅を見るほか、値を数割変えた飛翔で結果の変化を確かめる（上の :numref:`tbl-choose-propulsion` のように、ピッチ慣性を半分から 2 倍にしても、サンプルの着地距離は 1 % 未満しか変わらない）。


適用範囲と精度
--------------

* 推力のミスアライメント（傾きと方位）とノズルのオフセットは、設定した一定の値で、燃焼中に時間変化しない。
* 推進剤の消費は推力に比例すると仮定し、ジェットダンピングや質量変化による慣性項 :math:`\dot I` を無視する。
* 推進剤は軸上の一様な円柱で、その重心は燃焼中に横へ動かない。
* 推力の高度依存（背圧の変化）は考えない。

詳しい一覧は :ref:`sec-lim-env` と :ref:`sec-lim-motion` にある。
推力曲線は入力であり、モデルの精度の対象ではない。
一定推力・一定質量の真空中の鉛直飛翔について、頂点高度が解析解と 0.002 % の差で一致する（検証。:ref:`page-vv-verification`）。

選び方
------

推力曲線は実測に基づく値をそのまま使う。選択肢があるのは質量・重心・慣性の入力精度で、上の感度から次のように決める。

* **質量**：着地点と頂点の両方を動かす。10 % の違いで着地距離が約 7 % 変わるので、機体を組み上げた質量を測って入れる。
  モンテカルロ解析では ``dry_mass`` のばらつきの倍率が乾燥質量と乾燥慣性テンソルのすべての要素に同じ倍率で掛かり、慣性を単独ではばらつかせない。
  乾燥重心のばらつき（``cg``）は慣性モーメントを変えない（:ref:`sec-mc`）。
* **重心**：静安定余裕 :math:`(x_{cp}-x_{cg})/d` に直接入る。基準直径 :math:`d` が 0.1 m の機体で、重心の 10 mm の誤差は 0.1 cal の余裕の誤差になる（1 mm で約 0.0075 cal）。
  着地点には効かないが、合否の判定（余裕が 1〜2 cal 以上）には効くので、実測するのが望ましい。
* **慣性モーメント**：着地点への影響は小さい。CAD がなければ上の見積もりで足りる。ロールを励起しない軸対称の機体では ``ixx_dry`` は結果に影響しない。
  ただし、ピッチの慣性が極端に違うとピッチ振動の周期が変わるので、質量の偏りが大きい機体は部品に分けて足し合わせる。
* **ミスアライメントとオフセット**：既定は 0 である。推力軸の傾きは、その機体の組み立て精度から見積もった値を ``motor.misalignment_deg`` に入れるか、モンテカルロ解析で標準偏差を与える。

関連する設定
------------

推力曲線は ``motor.eng`` で与え、全力積と燃焼時間を決める。
``rocket.dry_mass`` は大きいほど頂点が下がり、``rocket.cg_dry`` は後ろへ動かすほど静安定余裕が減る。
``rocket.ixx_dry``、``iyy_dry``、``izz_dry`` はロール・ピッチ・ヨーの慣性でピッチ振動の周期に効く。
``rocket.cg_lateral_dry`` と ``ixy_dry`` を与えると軸対称でなくなり、慣性テンソルの行列で計算する。
``motor.misalignment_deg`` は推力軸の傾きで、既定は 0 である。
各キーの型、既定値、範囲は設定ファイルの章（:ref:`cfg-motor-eng`）にある。
