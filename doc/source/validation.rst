.. _page-vv-validation:

相互比較と妥当性確認
====================

:ref:`page-vv` は、式と数値解法を解析解や理論と比べた。この章は、その先の三つを扱う。
一つは、同じ機体の係数を部品積み上げ法、パネル法、CFD で算出して比べる相互比較である。一つは、同じ機体の飛翔を OpenRocket と RocketPy にも計算させて比べる相互比較である。もう一つは、算出した係数を Basic Finner の実測値と比べる妥当性確認である。
相互比較は手法やプログラムどうしの差の大きさを示すだけで、どの値が実機に近いかを決めない。実機への近さを言えるのは、実測と比べた範囲だけである。
計算時間とメモリは :ref:`page-cost` にある。

.. _sec-vaero-compare:

手法どうしの相互比較
--------------------

同じサンプル機体（:math:`r=0.05` m、全長 1.5 m、4 枚フィン）の係数を、手法どうしで比べた。
三つの手法の比較に加えて、パネル法と部品積み上げ法の比較、STL をそのまま使う CFD と作り直した形状の CFD の比較を示し、係数の差が飛翔の結果に与える影響を感度の例で見る。
どれも相互比較であり、実測との比較ではない。**どの値が実機に近いかは、この比較だけでは決まらない。** 実測との比較は Basic Finner の超音速の範囲に限られる（:ref:`sec-validation`）。

**亜音速の法線力傾斜。** 亜音速の :math:`C_{N\alpha}` はパネル法が約 27 % 大きく（:math:`M=0.3` で 14.84 と 11.69）、圧力中心は 0.03 m（0.3 cal）ほど後ろになる。差は主にフィンと胴体の干渉による。
胴体のみのパネル解は :math:`C_{N\alpha}=1.98` で部品積み上げ法の 2 とほぼ一致するので、差はフィン部分にある。:math:`M=0.3` で、単独のフィン 4 枚分（干渉なし）は :math:`2\times3.633=7.27`、部品積み上げ法は :math:`K_{fb}=1.33` を掛けて :math:`2+1.33\times7.27=11.69` とする。
パネル解が実効的に与える干渉係数は :math:`(14.84-1.98)/7.27=1.77` で、細長体理論の :math:`(1+\tau)^2=1.78` に近い。全体の :math:`C_{N\alpha}` を干渉のない値 :math:`2+7.27=9.27` と比べた比は、パネル法が 1.60、部品積み上げ法が 1.26 である。
この機体（フィンの先端半径が胴体半径の 3 倍で :math:`\tau=1/3`、胴体の影響が大きい）では、部品積み上げ法の干渉係数は低めで、パネル法は胴体の揚力の持ち上げまで含めた値を与えていると考えられる。
ただし、パネル法も細長体理論も非粘性で、境界層やフィン根元の渦を含まないため、実機でどちらが近いかは実測でなければ決まらない。

**遷音速と超音速。** パネル法の :math:`C_{N\alpha}` のピーク（21.9、:math:`M=1.2`）は、遷音速の帯の超音速側の端にあり、局所傾斜法の値である。
低い超音速ではくさびの離脱の角度が小さい（:math:`M=1.2` で 3.9°）のに対し、両凸断面のフィンの前縁の傾きは :math:`2t/c`\ （サンプルの翼端で約 4.6°）で、この角度に近いか超える。離脱に近づく付いた衝撃波の圧力は傾きとともに急に上がり、迎角による圧力差が大きくなる。
:math:`M=1.2` ではこの値が CFD（18.50）より 19 % 大きく、:math:`C_N` は迎角 2〜4° で CFD より 22〜23 % 大きい。部品積み上げ法のピークは :math:`M\approx1.4` で 14.5 とずっと低い。
パネル法では :math:`M=1.2` から 1.5 にかけて 21.9 から 17.7 へ下がる。離脱の角度が Mach 数とともに大きくなり（:math:`M=1.3` で 6.7°、1.5 で 12.1°）、前縁のパネルが付いた衝撃波の側に入るからである。

超音速では、パネル法の :math:`C_{N\alpha}` は :math:`M=2` で 17 %、:math:`M=3` で 10 % 高い（:math:`M=2` で 13.05。Euler の CFD は 13.24）。
:math:`M=2` で胴体を除くフィンの分（パネル法 11.05、部品積み上げ法 9.19）を分けると、干渉のないフィンの荷重はパネル法が 15 % 大きく（7.95 と 6.89）、干渉の倍率はパネル法が 1.39、部品積み上げ法の :math:`K_{fb}` が 1.33 である。
:math:`C_A`\ （燃焼後）はパネル法が 17〜25 % 高い。:math:`M=2` で、パネル法の 0.670 は表面摩擦 0.232、造波抗力 0.132（胴体 0.115、フィン 0.017）、底面 0.125、フィン縁 0.162、追加抗力 0.020 の和で、部品積み上げ法の 0.558 は摩擦 0.182、ノーズ 0.069、底面 0.125、フィン縁 0.162、追加抗力 0.020 の和である。
差の 0.112 は、摩擦（フィンを含む実際の濡れ面積 0.56 m\ :sup:`2` で積分した分）の +0.050 と、造波抗力（胴体とフィンの厚み）の +0.062 に当たる。部品積み上げ法のノーズ項はノーズだけ、パネル法の造波抗力は肩とフィンの厚みも含む。
亜音速（:math:`M\le0.3`）の抗力はパネル法のほうが低い。摩擦が 0.277 と 0.310 で小さく（:math:`M=0.3`）、局所の層流域と粗さの局所値を使うことによると考えられるが、個別の寄与までは切り分けていない。

.. _sec-cfd-val-stl:

STL と再構成
~~~~~~~~~~~~

サンプル機体を、STL をそのまま使うモード（``surface = "stl"``）と、形状を作り直すモード（``"panel_mesh"``）の両方で解き、部品積み上げ法とも比べた。
どちらも Euler、壁面 2 mm、フィンの面は既定の 1 mm、底面の後ろに 6 底面半径のフェアリング、:math:`M=0.8,2.0`、:math:`\alpha=0,4,8^\circ` である。STL モードは :math:`\beta=0,4^\circ` とロール減衰の組（:math:`\hat p=\pm0.01`）も解いた。
STL は自動判定で y = 0 と z = 0 の両方に鏡映対称とされ、1/4 領域から鏡映した全領域のメッシュ（約 279 万セル）を使った。作り直すモードはロール減衰の組を解くため全領域（約 283 万セル）である。
計算時間は、計算機とケースの並べ方が違うので、二つのモードの間では比べられない。

頂点高度が 5 % ほど低いのは、軸力係数が超音速と遷音速で高いためである。最小静安定余裕（小迎角の余裕。どちらもランチャ離脱の時刻で最小）が 0.33 cal 大きいのは、小さな迎角の圧力中心が後ろにあるためである。着地点は頂点高度の低さに応じて 6 % ほど手前になる。
落下分散（サンプルの格子、1〜7 m/s × 8 方位）の弾道落下の最大着地距離は、パネル法で 1616.9 m、Barrowman 法で 1549.6 m で、4 % の差である。どちらも 7 m/s、風向 270° のケースで、横向きに落ちたケース（:ref:`sec-dispersion-broadside`）はない。

大きな迎角の係数は、二つの手法で同じ扱いになる。パネル法の亜音速の列は、迎角 15° から 30° の間で部品積み上げ法の値へ移り、30° から先は部品積み上げ法の法線力と圧力中心である。
サンプルの表では、どちらの手法でも迎角 30° 以上の圧力中心は Mach 0.5 以下で 0.90 m 以上で、燃焼後の重心（0.85 m）より後ろにあるので、頂点のあとの弾道落下が横向きのまま落ちるつり合いは生じない。
大迎角の係数は、どちらの手法でも、フィンの平板の横流れの経験的な近似（:ref:`sec-fin-large-alpha`）と、後ろ向きの流れに前向きの係数を使う折り返しに依っており、実測で確かめていない（:ref:`sec-lim-aero`）。

.. _sec-vv-tools:

他のシミュレータとの相互比較
----------------------------

IgnisYeet の飛翔計算の結果を、OpenRocket と RocketPy が同じ機体、同じ推力、同じ大気と風で計算した結果と比べる。
三つのプログラムのどれも実測を使わないので、この比較は相互比較であり、妥当性確認ではない。**値が近いことは、どれかが正しいことを意味しない。**
比べる範囲はサンプル機体の上昇（頂点まで）である。パラシュート降下は、降下のモデルがプログラムごとに違うので比べない。
最後の小節（:ref:`sec-vv-tools-bf`）だけは、Basic Finner の静的な係数を OpenRocket と RocketPy でも求め、実測と IgnisYeet に並べる。

比べるプログラムと入力
~~~~~~~~~~~~~~~~~~~~~~

比べたのは、IgnisYeet 0.4.0（部品積み上げ法、``aero.method = "barrowman"``）、OpenRocket 24.12 :cite:`niskanen,niskanentech`\ （Java 25 上で、画面なしに Java の API から実行）、RocketPy 1.13.0 :cite:`ceotto2021rocketpy`\ （Python 3.12）である。
OpenRocket は Barrowman 法による空力（抗力を含む）と 6 自由度の飛翔計算を持つ。RocketPy は 6 自由度の飛翔計算を持ち、法線力と圧力中心は Barrowman 法で求めるが、抗力は計算せず、抗力係数の曲線を入力に取る。
機体と条件は、三つで共通に与えた（:numref:`tbl-vv-tools-inputs`）。

OpenRocket には慣性モーメントを直接入力する欄がない。部品の質量を 0 にして、乾燥質量 8.0 kg を 4 個の点質量に分け、重心と :math:`I_{xx}`、:math:`I_{yy}` が上の値になるように置いた。OpenRocket が計算した乾燥状態の値は、質量 8.0 kg、重心 0.850 m、:math:`I_{xx}=0.0200`、:math:`I_{yy}=1.5000\ \mathrm{kg\,m^2}` である。

三つで **共通にできなかった** 入力と、**独立な** 部分がある。

* **追加抗力** ``rocket.extra_cd``：IgnisYeet のサンプルは、ランチャラグなどの抗力として 0.02 を加える。OpenRocket と RocketPy にはこの機体のラグの入力がないので、IgnisYeet でも 0 にして比べる。サンプルの値のままの結果は :numref:`tbl-vv-tools-sens` に示す。
* **フィンの断面**：IgnisYeet のサンプルは前縁が丸く後縁が平ら（``rocket.fin_le = "rounded"``、``rocket.fin_te = "square"``）である。OpenRocket のフィンの断面は、前縁・後縁とも平ら（square）、前縁・後縁とも丸い（rounded）、前縁が丸く後縁がとがる（airfoil）の 3 種で、同じ組み合わせはない。rounded を主として比べ、square と airfoil は幅として示す。
* **抗力**：RocketPy には抗力係数の曲線を与える。(i) OpenRocket の抗力係数（:math:`\alpha=0`、rounded、射点の大気、燃焼中も同じ曲線）と、(ii) IgnisYeet の抗力係数（燃焼後と燃焼中の 2 本）の 2 通りで飛ばした。(ii) の RocketPy と IgnisYeet の差は、抗力を共通にしたときの飛翔計算（質量、推力、重力、大気、ランチャ、数値積分、法線力の扱い）の差を表し、(i) の RocketPy と OpenRocket の差も同じである。
* **独立な部分**：空力（抗力の組み立て、法線力、圧力中心、ピッチ減衰）、重力（IgnisYeet は :math:`g_0=9.80665\ \mathrm{m/s^2}` の逆 2 乗則、OpenRocket と RocketPy は緯度 34.7° の値で、射点の上 500 m で :math:`9.7955\ \mathrm{m/s^2}` と、IgnisYeet より 0.10 % 小さい）、ランチャ離脱の判定、数値積分である。空気の密度は 3 者で 0.03 % 以内（高さ 0.5〜4 km）で一致した。

OpenRocket の時間刻みは 0.01 s で、0.002 s にしても頂点高度は 0.1 m も変わらない。RocketPy は相対許容誤差と絶対許容誤差を :math:`10^{-8}` にした。

この比較が示すことと示さないこと
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

* **示すこと**：同じ機体と条件に対する三つのプログラムの結果が、どの量でどれだけ違うか。抗力を共通にすれば、IgnisYeet の飛翔計算（質量の変化、推力、大気、重力、ランチャ、数値積分）は、頂点高度、頂点時刻、速さについて RocketPy と 0.1 % 以内で一致する。風のある上昇の水平距離は 7.5 % 違う。上昇の結果の差の大部分は、抗力の組み立て（ノーズの造波抗力、フィンの縁の抗力）の差で説明でき、静的な空力の差は :math:`C_{N\alpha}` と圧力中心に現れる。
* **示さないこと**：どのプログラムの値が実機に近いか。OpenRocket と RocketPy の結果は、実機の測定値を使っていない。IgnisYeet と RocketPy の亜音速の一致は、同じ Barrowman の式を使うことの結果で、独立な確認ではない。IgnisYeet と OpenRocket が近い量（摩擦と底面の抗力、フィンの前縁の抗力）も、Niskanen の式 :cite:`niskanen` に共通の源がある。
* **範囲**：サンプル機体 1 つ、風は一様な 4 m/s の 1 条件、頂点まで。パラシュート降下、風の高度分布、ほかの機体は比べていない。OpenRocket は 24.12 版の 1 つの設定（フィン断面 rounded を主）で、RocketPy は 1.13.0 版の 1 つの設定である。別の版や設定では差が変わりうる。
* **未解決**：風のある上昇での RocketPy の水平距離と迎角の振動の違い（:numref:`fig-vv-tools-alpha`）は、原因を切り分けていない。

再計算の手順と入力は ``doc/scripts/xcheck_tools/README.md`` に、結果は ``doc/data/xcheck_tools/`` にある（バージョン、OpenRocket の jar の SHA256、実行日は ``provenance.json``）。

Basic Finner の妥当性確認
-------------------------

空力係数の推算法（部品積み上げ法、パネル法、CFD の Euler と RANS）の値を、Basic Finner の実測値と比べる。実測と比べるので、この節の比較は妥当性確認である。

Basic Finner は、10 口径の円すい・円柱の胴体に矩形フィン 4 枚を付けた標準模型で、超音速の空力の基準として多くの試験に使われてきた。
実測値は、Dupuis と Hathaway の弾道射場の自由飛行試験 :cite:`dupuis1997basicfinner` の Mach 1.08 から 4.30 の値と、Regan の風洞のロール減衰 :cite:`regan1964rolldamping` である。
実測と比べた量は :math:`C_{N\alpha}`、:math:`C_{m\alpha}`、:math:`x_{cp}`、:math:`C_{X0}`、:math:`C_{lp}` で、:math:`C_{lp}` は風洞の値も使う。
亜音速、遷音速の山（Mach 1.25 付近）、Basic Finner 以外の形状、実機の飛翔の係数、ピッチ減衰の実測との比較は行っていない。
射場の係数の確率誤差は :math:`C_{N\alpha}` で 1–4 %、:math:`C_{m\alpha}`、:math:`C_{X0}`、:math:`C_{lp}` で 0–1 % である（当てはめの統計誤差で、発ごとのばらつきや系統誤差を含まない）。

``wall_size`` は胴体の直径に対して決め、サンプル機体（直径 100 mm）の RANS の既定 5 mm と同じ 0.05 口径である。大気は US 標準大気 1976 の海面の値（音速 340.3 m/s）で、射場の空気（音速 343.4–344.0 m/s、密度 1.16–1.20 kg/m\ :sup:`3`）とほぼ同じである。摩擦の項の Reynolds 数は Mach 2.375 で :math:`1.7\times10^7`\ （全長基準）で、射場の範囲に入る。
Euler の行は、行ごとに異なる版のプログラムで解いたものを含む。版による結果の違いは確かめていない。

**軸力の組み立て。** Euler は粘性を含まないので、係数表の :math:`C_{X0}` は、CFD が壁面に積分した圧力の軸力（ノーズ、胴体、フィン）に、部品積み上げ法の摩擦抗力、胴体の底面抗力、フィンの後縁の底面抗力を足したものである（:ref:`sec-cfd-trust`）。
フィンの後縁の底面抗力は :math:`C_{D,base}(M)\,n\,b\,t/S`\ （:math:`C_{D,base}=0.25/M`、:math:`n=4`、スパン :math:`b`、:math:`t` は STEP から取り出した平均の厚さ 1.35 mm）で、Mach 1.83、2.38、3.15 で 0.031、0.024、0.018 になる。
RANS は壁面の圧力と摩擦を CFD で積分し、底面の項を ``rans_base`` で選ぶ。``"model"`` は部品積み上げ法の底面抗力とフィンの後縁の底面抗力、``"cfd"`` は CFD が底面に積分した圧力の力である。RANS の壁面は滑らかな壁なので、部品積み上げ法の粗さ（``roughness`` 2 :math:`\mu\mathrm{m}`）による摩擦の増分を足すが、この粗さでは増分は 0 である。
STEP のモデルでは、底面と同じ面にあるフィンの後縁は、底面と一つの平らな面になる。CFD はこの面全体を底面として扱い力を積分しない。RANS の ``rans_base = "cfd"`` だけは、この面の圧力を含む（後縁の厚さは STEP の 2.4 mm）。
フィンの後縁の底面抗力の項は、``rans_base = "model"`` と Euler で、この面の力の代わりに足す。厚さは取り出した平均値 1.35 mm なので、図面の 2.4 mm より小さい（:ref:`sec-validation-discussion`）。

:math:`C_{X0}` の底面の項とフィンの後縁の項はどちらでも部品積み上げ法の同じ値なので、底面の扱いの選び方は :math:`C_{X0}` の差（実測との差 15–28 %）をほとんど変えない。

.. _sec-validation-discussion:

考察
~~~~

**法線力傾斜** :math:`C_{N\alpha}`

* **部品積み上げ法**\ は Mach 1.83–4.30 で 20–35 %、Mach 1.08 と 1.29 で 31 % 小さい。超音速の不足は、:ref:`sec-lim-aero-supersonic` の内訳で説明できる。部品積み上げ法は胴体を細長体の 2 とし、フィンを平板の Ackeret の傾きに翼端の損失と Barrowman の干渉係数 :math:`1+r/(s+r)` を掛けて求める。
  文献の線形理論の積み上げ（特性曲線法の胴体、くさびの厚みの 2 次の効果、細長体理論の干渉係数）は、Mach 2 で胴体の円筒部の揚力（+0.58）、干渉（+0.29）、フィンの厚み（+0.36）を足し、実測との差を 9–16 % に縮める。残りは線形理論の外（接合部と翼端の三次元の効果、粘性）である。
  Mach 1.08 と 1.29 は翼端の Mach 円すいが根元に届く範囲で、部品積み上げ法の遷音速の補間が実測の高い値（18.3–18.5）を表さない。
* **パネル法**\ は Mach 1.83–4.30 で 18–34 %、Mach 1.08 と 1.29 で 19–20 % 小さい。超音速のフィンは胴体の吹き上げを入れた局所傾斜法で、胴体の円筒部の揚力と胴体の干渉を含まず、フィンの断面は両凸なので、部品積み上げ法との差は 1–3 % にとどまる。
* **Euler** は 3–11 %（平均 7 %）小さく、部品積み上げ法とパネル法の不足の大部分を取り戻す。線形理論で足りなかった非粘性の効果（胴体の揚力、干渉、厚み、三次元の効果）は、Euler の解にすべて入るからである。
  残りの差は、メッシュによる分（1 % 程度）より大きく、確率誤差（1–4 %）の 2–4 倍のことが多い。候補は、粘性（フィンの境界層の排除厚さ、後縁付近のはく離）と、傾きの取り方（Euler は :math:`\alpha=2^\circ` の割線、実測は最大 9° までの運動に :math:`C_{m\alpha}` の 3 次の項とともに当てはめた線形の項）である。Mach 2.375 の実測は前後の Mach 数の傾向より高く、どの手法でも差が大きく出る。

**圧力中心とピッチングモーメント**

* :math:`x_{cp}` はどの手法も実測と 0.3 口径以内（−2.4 から +3.6 %）で合う。部品積み上げ法の :math:`x_{cp}` は −2.4 から +2.4 % に収まるが、:math:`C_{m\alpha}` は :math:`C_{N\alpha}` の不足をそのまま受けて 21–37 % 小さい。パネル法は :math:`x_{cp}` が 1–4 % 後ろ寄りで、:math:`C_{m\alpha}` は 15–28 % 小さい。
* Euler の :math:`C_{m\alpha}` は全 Mach 数で 3–7 % 小さい。:math:`C_{N\alpha}` より合うのは、Euler の :math:`x_{cp}` がわずかに後ろ（Mach 1.83 以上で −0.03 から +0.08 口径）にあり、:math:`C_{N\alpha}` の不足を腕の長さが打ち消すためでもある。
  重心が圧力中心から 1.0–2.9 口径前にあるので、:math:`x_{cp}` の 0.1 口径の差は :math:`C_{m\alpha}` の 3–10 % にあたる。:math:`C_{m\alpha}` の一致は、:math:`C_{N\alpha}` と :math:`x_{cp}` を別々に見て判断する。

**零揚力の軸力** :math:`C_{X0}`

* どの手法も実測より小さい。部品積み上げ法は 23–38 %、パネル法は 25–34 %、Euler は 15–28 %（Mach 3.73 と 4.30 で 15–18 %、それ以外で 23–28 %）である。Euler は部品積み上げ法より 0.03 程度大きい（Mach 1.83–3.15）。
  圧力の軸力（ノーズの造波抗力とフィンの圧力の抗力）が部品積み上げ法のノーズとフィンの項より大きいためで、摩擦、胴体の底面、フィンの後縁の項は同じ部品積み上げ法の値である。
* Mach 2.375 の内訳は、Euler の圧力の軸力 0.131、部品積み上げ法の摩擦 0.089（乱流、:math:`Re_L=1.7\times10^7`）、胴体の底面 0.105、フィンの後縁の底面 0.024（合計 0.349）で、実測の 0.484 より 0.135 小さい。不足の候補は次の四つで、大きさの見積もりを足すと 0.13 になり、不足とほぼ同じになる。

  * **フィンの後縁の厚さ（約 0.02）**：取り出したフィンの厚さは平均 1.35 mm で、後縁の切り落としの本来の厚さは 2.4 mm である。項は厚さに比例するので、2.4 mm では 0.043 になり、0.019 増える。
  * **胴体の底面抗力の過小評価（最大約 0.08）**：部品積み上げ法の底面の項は :math:`0.25/M`\ （Mach 2.375 で 0.105）である。フィンが底面にある機体の自由飛行の底面の圧力係数 −0.185（Mach 2、:cite:`barrowman`）を使うと 0.185 になる。後縁の項と重なる分があるので、最大の見積もりである。
  * **メッシュ（約 0.02）**：圧力の軸力は L2 から細かくすると増え、外挿値は 0.150 である（:ref:`sec-validation-mesh`）。
  * **摩擦（約 0.01）**：Mach 1.832 の RANS の壁面の摩擦（壁面の軸力 0.266 − Euler の圧力の軸力 0.149）は 0.118 で、部品積み上げ法の 0.104 より 0.014 大きい。

  底面の圧力は非粘性の Euler では求まらないので、:math:`C_{X0}` の妥当性確認は、底面を含めて解く RANS と底面抗力の経験式の精度で決まる。Euler の係数表の :math:`C_{X0}` は、どの Mach 数でも実測より 15–28 % 小さく、不足は主に底面（胴体とフィンの後縁）の抗力にある。
* 部品積み上げ法の :math:`C_{X0}` は、Mach 1.83–4.30 で、フィンの厚さを図面どおり 2.4 mm にすると 19–30 % 小さくなる（取り出したフィンでは 23–34 %）。後縁の底面の項が厚さに比例するためである。

**RANS（SU2、Spalart-Allmaras）**

* **収束したのは Mach 1.832 の 2 ケースだけである。** :math:`\alpha=0,2^\circ` が 503 と 402 反復で受け入れの判定を通り、:math:`y^+` の 95 パーセンタイルは 0.81 と 0.83 である。
  Mach 2.375 の 2 ケースは反復の上限（3000）で収束せず、密度の残差が基準のピークから 1.3 桁（:math:`\alpha=0`）と 0.6 桁（:math:`\alpha=2^\circ`）しか下がらず、係数は限界周期で振動した。最後の 500 反復の底面を含む抗力係数 :math:`C_D` は、:math:`\alpha=0` で 0.500–0.545（平均 0.509）、:math:`\alpha=2^\circ` で 0.510–0.570（平均 0.522）で、実測の :math:`C_{X0}`\ （0.484）と比べる値としては使えない。
  Mach 3.147 の :math:`\alpha=0` は 2 回発散し、:math:`\alpha=2^\circ` は反復の上限で収束しなかった。単独の計算でも同じ発散が再現した。そのため、RANS の比較は Mach 1.832 の 1 点に限られる。発散の原因（超音速の底面のうしろの流れか、フィンの後縁の鈍い面のまわりの流れか）は切り分けていない。
* Mach 1.832 の :math:`C_{N\alpha}` は 11.46（実測との差 −2.7 %）、:math:`C_{m\alpha}` は −26.55（+5.1 %）、:math:`x_{cp}` は 7.82 口径（−0.7 %）で、Euler（−4.4 %、+5.3 %、−0.3 %）とほぼ同じである。粘性は静的な係数をこの Mach 数でほとんど変えない（:math:`C_{N\alpha}` は Euler より 1.7 % 大きい）。
* Mach 1.832 の :math:`C_{X0}` は、``rans_base = "model"`` で 0.434（−25.8 %）、``"cfd"`` で 0.648（+10.7 %）である。壁面の軸力は 0.266（圧力 0.149、摩擦 0.118）、CFD の底面の力は 0.381 である。
  底面の力は胴体の底面とフィンの後縁の面（厚さ 2.4 mm）の合計で、``"model"`` の底面の項（胴体 0.136、フィンの後縁 0.031、合計 0.168）の 2.3 倍になる。壁面の値が正しいとすれば、実測と合う底面の抗力は 0.585 − 0.266 = 0.319 で、部品積み上げ法の底面の項はその 53 % であり、RANS の底面の力はその 1.19 倍である。
  底面の圧力を RANS が過大に出すのか、実測の側に別の要因があるのかは、1 点では決められない。

**ロール減衰** :math:`C_{lp}`

* 部品積み上げ法（パネル法も同じ値）は Mach 1.83–3.15 で −8 から +5 %、Mach 3.73 と 4.30 で 13–15 % 小さく、Mach 1.08 と 1.29 で 46–92 % 大きい。フィンの法線力傾斜から作るストリップ理論で、翼端の損失を荷重に一様に掛けるので、翼端の Mach 円すいがフィン全体を覆う低い超音速で、減衰への寄与が大きい外側の荷重の低下を表さない。
* Euler の回転座標系の解（``base_treatment = "fairing"``）は Mach 1.08 と 1.29 で 10–12 % 大きく、Mach 1.83 で 2.5 % 大きく、Mach 2.38–3.15 で −3 から +4 %、Mach 3.73 と 4.30 で 10–11 % 小さい。低い超音速の大きな過大は 1 割程度に縮む。Mach 3.73 と 4.30 の不足は部品積み上げ法と同じ向きである。
  32 ケースのうち 6 ケース（Mach 1.077 のロールの 2 ケース、Mach 1.832 の :math:`\alpha=2^\circ`、Mach 3.734 の 2 ケース、Mach 4.3 の :math:`\alpha=0`）は、反復の上限で係数がわずかに動いたままで、警告が出た（力の範囲が 0.2 % を超える）。粗い ``wall_size``\ （2.1 mm）の影響と合わせて、Mach 3.73 と 4.30 の不足への寄与は確かめていない。
* :math:`C_{lp}` の比較は、無次元化（:math:`pd/(2V)`）と Regan の風洞の値のスパンの換算を、実測との一致から推定したうえでの比較である。そのため独立した妥当性確認ではなく、無矛盾性の確認にとどまる。Regan の風洞の値（換算）は射場の値より 10 % 程度小さく、両者の差は手法の差と同じ程度である。

.. _sec-validation-limits:

限界
~~~~

* **亜音速の静的な係数がない。** 亜音速から Mach 4.5 の射場と風洞の値を含む報告書 :cite:`dupuis2002basicfinner` は入手できなかった。亜音速の :math:`C_{N\alpha}`、:math:`C_{m\alpha}`、:math:`C_{X0}` の妥当性確認はできていない。遷音速の山（Mach 1.25 付近）も射場の試験では捉えていない。
* **超音速の 8 点だけである。** Mach 1.08 と 1.29 は 2–3 発の当てはめで、群の中でも Mach 数が変わる。
* **RANS は Mach 1.832 の 1 点だけである。** Mach 2.375 は収束せず、Mach 3.147 は発散した（:ref:`sec-validation-discussion`）。RANS の :math:`C_{X0}` と静的な係数の誤差を、Mach 数の範囲で評価することはできない。
* **軸力の比較は底面抗力の推算に強く依存する。** 底面とフィンの後縁の圧力は、Euler では求まらず、RANS でも乱流モデルの精度に依存する。
* **減衰の比較は無次元化の推定に依存する。** ロール減衰とピッチ減衰の無次元化は報告書に書かれておらず、推定した（:numref:`tbl-validation-sources`）。
* **形状は 1 種類である。** フィンの後縁が底面と同じ面にある、厚いくさび断面の矩形フィンの機体で、後退角のあるフィンや、底面の前で終わるフィン、ボートテールは含まない。ここで得た誤差の大きさを、形の違う機体にそのまま当てはめることはできない（:ref:`sec-lim-aero`）。
