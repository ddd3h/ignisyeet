STL からの形状抽出
==================

空力係数を計算するには、機体の **胴体の半径分布** :math:`r_b(x)` と **フィンの寸法** が必要である。
本章では、STL（三角形の集合）からこれらを取り出す手順を説明する。
手順は (1) 機軸を決める、(2) 機軸に垂直な断面で切る、(3) 断面ごとに胴体半径とフィンを判定する、の三段階である。

STL ファイルとは
----------------

STL は、立体の **表面を小さな三角形の集まりで表す** ファイル形式である。
もとは 3D Systems 社が光造形（stereolithography）装置のために定めた形式で、
現在は 3D プリンタ向けの標準的な形式として、ほとんどの CAD（Fusion 360、SolidWorks、FreeCAD など）から書き出せる。

.. _fig-stl-mesh:

.. figure:: _generated/plots/stl_mesh.*
   :width: 100%

   付属のサンプル機体の STL（``examples/sample_rocket.stl``、約 1.4 万個の三角形）。
   左は全体、右は尾部の拡大で、細い線が三角形の辺である。胴体は周方向 72 分割の細長い三角形の帯、フィンは各面 2 枚の三角形でできている。

1 つの三角形（ファセット）は、外向きの法線ベクトル 1 本と頂点 3 つの座標で表される。
ファイル全体はこのファセットを並べただけのもので、面のつながり（どの三角形が隣り合うか）、色、材質、**単位** の情報は持たない。
書式にはテキスト形式（ASCII）とバイナリ形式の 2 種類がある。

.. code-block:: text

   solid rocket
     facet normal 0.0 0.0 1.0
       outer loop
         vertex 0.0 0.0 0.0
         vertex 1.0 0.0 0.0
         vertex 0.0 1.0 0.0
       endloop
     endfacet
     ...
   endsolid rocket

バイナリ形式は、80 バイトのヘッダ、三角形の数（4 バイト整数）、続いて三角形ごとに 50 バイト
（法線と 3 頂点の単精度浮動小数点数 12 個と、2 バイトの属性）を並べたものである。
IgnisYeet はどちらの形式も自動で判別して読み込む。

STL には単位がないので、CAD で mm 単位で作った機体なら設定 ``stl_scale = 0.001`` で m に直す。
また、曲面は三角形で近似されているため、ノーズのような曲面は書き出し時の分割の細かさ（許容誤差）に応じて多角形状になる。
本章の手順は、こうした粗い分割や、三角形の向きのそろっていないファイル、内部構造を含むファイルでも安定に動くように作ってある。

前提
----

* 胴体は **軸対称**\ （回転体）であり、フィンは同じ形のものが機軸まわりに等間隔に並ぶ。
* フィンは台形（後退角つき）で近似する。クリップトデルタや楕円フィンも等価な台形として扱われる。
* STL は閉じている必要はない。内部の構造（隔壁やモータ）が含まれていても、各断面で外側の点だけを使うので影響しない。

機軸の決定
----------

三角形 :math:`k` の面積を :math:`A_k`、重心を :math:`\bm{m}_k` とし、面積で重み付けた重心

.. math::

   \bm{c} = \frac{\sum_k A_k\,\bm{m}_k}{\sum_k A_k}

と、頂点 :math:`\bm{v}` の分散行列

.. math::
   :label: eq-pca

   C = \sum_k A_k \sum_{\bm{v}\in k}(\bm{v}-\bm{c})(\bm{v}-\bm{c})^\top

を作る。:math:`C` は対称行列なので Jacobi 法 :cite:`golub` で固有値分解し、**最大固有値に対応する固有ベクトル** を機軸とする（主成分分析 :cite:`jolliffe`）。
ロケットは細長いので、最も広がっている方向が機軸になる。

固有ベクトルには向き（符号）の任意性があるので、どちらがノーズかを次の節の断面情報から決める。
両端それぞれの 1/30 の範囲で胴体半径の和を比べ、**小さい方をノーズ** とする（ノーズは先細りで、後端は太い）。
自動判定がうまくいかない場合は、設定 ``nose_direction`` で向きを指定できる。

断面での切り出し
----------------

機軸方向の全長を :math:`L` とし、:math:`N_s` 枚（既定 600 枚）の断面

.. math::

   x_i = \left(i+\tfrac12\right)\frac{L}{N_s},\qquad i=0,1,\dots,N_s-1

で STL を切る（:numref:`fig-slicing` 左）。
三角形の辺 :math:`\bm{a}\bm{b}` が断面 :math:`x_i` をまたぐとき、交点は

.. math::

   \bm{p} = \bm{a} + (\bm{b}-\bm{a})\,\frac{x_i-a_x}{b_x-a_x}

である。頂点がちょうど断面上にある場合の重複を避けるため、「:math:`x\ge x_i` 側にあるか」で各頂点を二分し、
二分の結果が異なる辺だけを交差とみなす。こうすると一つの三角形からは必ず 0 本か 1 本の線分が得られる。
各三角形は自分の :math:`x` 範囲に入る断面だけを調べるので、計算量は三角形数と断面数の積より十分小さい。

.. _fig-slicing:

.. figure:: _generated/tikz/slicing.*
   :width: 100%

   左: 機軸に垂直な断面で切る。右: 断面上の点。胴体半径は角度ビンごとの最大半径の中央値として求め、
   それより :math:`\delta` 以上外側の点をフィンとみなす。

胴体半径の決定
--------------

断面上の線分の端点を極座標 :math:`(r,\theta)` で表す。
距離 :math:`r` は線分上で凸関数なので、線分上の最大半径は必ず端点で生じる。端点だけを調べれば外形を取りこぼさない。

角度を 72 個のビン（5° 幅）に分け、ビン :math:`j` ごとに最大の :math:`r` を求めて :math:`r_{\max,j}` とする。
断面 :math:`i` の胴体半径は、点を含むビンの :math:`r_{\max,j}` の **中央値** とする。

.. math::
   :label: eq-rbody

   r_{b,i} = \operatorname{median}_{j}\ r_{\max,j}

フィンは数ビンしか占めないので、中央値はフィンの影響をほとんど受けない :cite:`huber`\ （平均や最大値ではフィンに引きずられる）。
また、内部構造の点は同じビンのより外側の点に隠れるので無視される。
全断面での最大値 :math:`r_{\max}=\max_i r_{b,i}` を基準半径とし、基準直径 :math:`d=2r_{\max}`、基準面積 :math:`S=\pi r_{\max}^2` とする。

胴体の諸量
~~~~~~~~~~

断面間隔を :math:`\Delta x=L/N_s` として、空力計算で使う量を次の和で求める。

.. math::

   \begin{aligned}
   S_{\mathrm{wet}} &= \sum_i 2\pi r_{b,i}\,\Delta x\sqrt{1+\left(\frac{\dd r_b}{\dd x}\right)_i^2} &&\text{（胴体の濡れ面積）}\\
   A_p &= \sum_i 2r_{b,i}\,\Delta x,\qquad x_p=\frac{1}{A_p}\sum_i 2r_{b,i}\,x_i\,\Delta x &&\text{（側面投影面積とその図心）}
   \end{aligned}

ノーズ
~~~~~~

先端から見て初めて :math:`r_{b,i}\ge0.999\,r_{\max}` となる断面をノーズの終端とし、その位置をノーズ長 :math:`L_n`、半径を :math:`R_n` とする。
さらにノーズの形を表す量として

* 接合部の半頂角 :math:`\phi_j`\ ：ノーズの最後の 10 % 区間での :math:`r_b` の傾きの逆正接。円錐なら :math:`\arctan(R_n/L_n)`、接線オジブなら 0 に近い。
* 体積比 :math:`v_r=V_n/(\pi R_n^2L_n)`\ ：ノーズ体積と外接円柱の体積の比。円錐は 1/3、接線オジブは約 0.53。

を求め、抗力の計算（:ref:`sec-nose-drag`）で使う。

ボートテール
~~~~~~~~~~~~

後端から見て初めて :math:`r_b\ge0.99\,r_{\max}` となる断面より後ろが 3 断面以上あり、
かつ後端の半径 :math:`r_{\mathrm{base}}` が :math:`0.97\,r_{\max}` より小さいとき、その区間をボートテールとする。

フィンの検出
------------

しきい値を :math:`\delta=0.05\,r_{\max}`\ （設定 ``fin_threshold``）とし、:math:`r>r_{b,i}+\delta` の点を **フィン点** とする。

1. **枚数**：断面ごとにフィン点の角度を並べ、10° 以上離れたところで区切ってクラスタにする（0° と 360° をまたぐ場合は結合する）。
   クラスタ数の最頻値をフィン枚数 :math:`N` とする。
2. **フィン区間**：フィン点を含む断面が連続する区間のうち、フィン高さの和が最大のものを採用する（カナードなどがあっても主翼を選ぶ）。
3. **根元**：胴体表面をまたぐ線分（一端が :math:`r\le r_b+\delta`、他端が外側）を含む断面を「根元が胴体についている断面」とする。
   その最初と最後の断面から根元の前縁・後縁を求める。
4. **スパン**：区間内での最大の :math:`s_i=\max r - r_{b,i}` をスパン :math:`s` とする。
5. **端翼弦**：区間内で :math:`s_i` を積分した面積 :math:`A_f=\sum_i s_i\,\Delta x` が台形の面積 :math:`\tfrac12(a+b)s` に等しいとして、:math:`b=2A_f/s-a` とする。
6. **後退長**：初めて :math:`s_i\ge0.97\,s` となる断面の位置 :math:`x_k` から、:math:`m=(x_k-\Delta x/2-x_{le})/0.97` とする。
7. **厚さ**：各クラスタの中心角 :math:`\varphi` を求め、点を周方向にずらした距離 :math:`r\sin(\theta-\varphi)` の幅を厚さとする。全断面・全フィンの中央値をとる。

前縁・後縁の補正
~~~~~~~~~~~~~~~~

フィン点はしきい値 :math:`\delta` より外側でしか見えないので、後退した前縁では実際の前縁より少し後ろからしか検出できない。
そこで、根元の最初の 2 断面のフィン高さ :math:`s_1, s_2` から高さが 0 になる位置を線形外挿する。

.. math::

   x_{le} = x_1 - s_1\,\frac{\Delta x}{s_2-s_1}

外挿量は :math:`3\Delta x` までに制限し、:math:`s_2\le s_1`\ （前縁が機軸に垂直な場合）は断面の境界 :math:`x_1-\Delta x/2` を使う。後縁も同様に求める。

自動検出がうまくいかない場合
----------------------------

複雑な形状（エアブレーキ、カメラポッド、非対称な突起など）ではフィンの検出を誤ることがある。
``ignisyeet geom`` で ``geometry.json`` と ``profile.csv`` を出力し、``python/plot.py geometry`` で図にして確認してほしい。
誤っている場合は ``[rocket.fin_override]`` で正しい値を与えれば、その値が優先される。
