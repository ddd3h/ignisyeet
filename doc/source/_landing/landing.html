IgnisYeet

ロケットの CAD データから空力特性を推算し、6 自由度で飛ばし、落下分散まで求めるオープンソースの飛翔シミュレータ。

はじめる ドキュメント GitHub

インストール（Linux x86_64 / aarch64、macOS Intel / Apple Silicon）

curl -fsSL https://raw.githubusercontent.com/ddd3h/ignisyeet/main/install.sh | bash
Rust Python
Gmsh Open MPI

動画

YouTube で開く

できること

  • CAD から形状を取り出す

    CAD（STEP / IGES / BREP、STL も可）→ 半径分布、フィン寸法（自動検出）

    形状の取り込みと抽出

  • 空力の推算

    Barrowman / パネル法 / CFD / 外部の係数表。減衰、見かけ質量、Magnus 力、誘導ロール

    空力解析

  • SU2 による CFD

    Euler / RANS（SU2 8.3.0）。収束は残差と係数の変化で判定

    CFD による空力表の作成

  • 6 自由度の飛翔

    ランチャ滑走から着地まで、剛体 6 自由度。地球：平ら・自転　大気：US Standard Atmosphere 1976　風：一定・べき乗則・対数・プロファイル　積分：RK4・RK45・DOP853

    運動方程式

  • 降下とパラシュート

    弾道落下 / 単一のパラシュート / 二段開傘（ドローグとメイン）

    降下方式

  • 落下分散と保安距離

    風の格子、または Monte Carlo。誤差楕円、着地距離のパーセンタイル、保安距離

    落下分散

  • レポート、KML、プロット

    CSV / JSON / HTML レポート / KML（Google Earth）/ プロット

    使い方

  • 再現性と検証

    入力が同じなら係数表を再利用。レポートに設定と飛翔結果のハッシュ。検証・相互比較・妥当性確認

    検証

計算の流れ

make all

  1. CADSTEP / IGES / BREP、または STLrocket.cad
  2. 形状半径分布とフィンの抽出geom
  3. 空力Mach 数と迎角の係数表aero
  4. 飛翔6 自由度、ランチャから着地までsim
  5. 落下分散風の格子または Monte Carlodispersion
  6. レポートHTML、KML、プロットreport

    OpenRocket / RocketPy

    OpenRocket 24.12、RocketPy 1.13.0 と比較。頂点高度の差（IgnisYeet 基準）：RocketPy（抗力を共通）+0.01 %、OpenRocket（独自の抗力）+6.7 %。実機に近いかは決めない
