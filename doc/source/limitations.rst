制約と今後の課題
================

IgnisYeet の結果を使う前に、次の仮定と制約を理解してほしい。
結果の妥当性は、ここに挙げた仮定が対象の機体と飛翔条件で成り立つかどうかに依存する。
空力モデルの制約はここに一か所にまとめ、各章の「注意」からここへ案内する。

座標系と地球
------------

* **平面地球モード**\ （既定）：局所 ENU 座標系を慣性系とみなし、地表の曲率と地球の自転（Coriolis 力）を無視する。
  着地点が射点から 10 km を超えるような飛翔では、高さ方向に数 m 以上の誤差が生じる（:ref:`sec-enu-range`）。
  高高度・長距離の飛翔では ECEF モード（``earth.model = "ecef"``）を使うとよい（:ref:`sec-ecef`）。
* **ECEF モード**：WGS84 楕円体に固定した回転座標系で積分し、Coriolis 力・遠心力・曲率を含む。
  ただし地球の自転速度は一定、地表は射点標高の楕円体面（地形・起伏は考えない）、大気と風は楕円体高と射点標高からの高さの関数であり、
  緯度・経度による変化は考えない。
* ECEF モードの風は、機体の現在位置の局所 ENU で与える。射点の基底との差は、射点からの距離を地球半径で割った角度（55 km で約 0.5°）である。
* 重力は点質量 + :math:`J_2` 項までで、高次の項や地球の重力異常は考えない :cite:`hofmann`。``constant`` と ``inverse_square`` は有効重力（遠心力を含む）の大きさを与え、緯度による変化を含まない。
  ECEF モードでは、有効重力から万有引力を作って遠心項を別に足すので、これらのモデルの正味の重力は有効重力に等しく、水平成分を持たない（:ref:`sec-ecef-gravity`）。
  ``j2`` の正味の重力は、水平成分（赤道向き）をわずかに持つ。
* **地形**：着地は射点標高の面で判定する。山や谷、海面との標高差は扱わない。

運動と空力のモデル
------------------

* 6 自由度の剛体運動を解く。3 軸のまわりの回転、慣性乗積を含む慣性テンソル、重心の横ずれ、推力の傾きとノズルのオフセット、ランチャ上のロール角を扱う（:doc:`dynamics`）。
* 空気力は **6 成分の準定常な係数** :math:`C_X,C_Y,C_Z,C_l,C_m,C_n=f(M,\alpha,\beta)`、**対角の回転減衰**\ （:math:`C_{lp}`、ピッチの :math:`C_{mq}`、ヨーの :math:`C_{nr}`）、
  回転による法線力 :math:`C_{Nq}`、胴体とフィンの見かけの質量による遅れ（:math:`\dot\alpha`）と対流の回転の項、Magnus 力とモーメント、誘導ロールで表す（:ref:`sec-aero-unsteady`）。
  どの項もそのときの状態と加速度だけで決まり、流れの履歴を表す状態量は持たない。
  フィンの揚力の循環の遅れは、R. T. Jones の有限翼の指示関数 :cite:`jones1940` から、サンプルのフィン（アスペクト比 1.33）でフィンの減衰を約 4 % 弱めると見積もり、モデルには入れない（:ref:`sec-quasi-steady`）。
  ピッチ減衰の不確かさは、局所的な迎角の和を ``cmq_scale``、見かけの質量の項（サンプルのピッチ減衰の 16〜29 %）を ``lag_scale`` で見込む（危険区域の計算にはそれぞれ標準偏差 0.1 と 0.25 を勧める。:ref:`sec-mc`）。
  循環の遅れなどの向きの決まった偏りは、平均 0 のばらつきでは表せない（:ref:`sec-quasi-steady`）。
  動的失速、大迎角でのはく離の遅れ、フィンの吹き下ろしの遅れ（単一のフィンの組では前方に揚力面がないので生じない。:ref:`sec-damping`）は扱わない。
* 見かけの質量の項は、小さな迎角の細長い物体の理論による。フィンの断面の見かけの質量は、細長い物体の理論の断面の形を使い、大きさを Barrowman のフィンの法線力の傾きにそろえる（:eq:`eq-lag-fin-section`。サンプルでは細長い物体の理論のままの 1/1.47）。
  超音速では、循環によらない見かけの質量の力はフィンの法線力の傾きに比例して変わるものではないが、静的な力と局所的な迎角の和との整合のため、同じ傾きでそろえる。
  対流の回転の力 :math:`-\tfrac12\rho SL_0(0,-\omega_zu_x,\omega_yu_x)` は加えるが、遅れの項の力 :math:`-\tfrac12\rho SL_0\dot{\bm u}_\perp` は加えない（加速度がこの力自身に依存し、代数的なループになる）。
  その大きさは、機体の横向きの加速度による分では法線力の :math:`\tfrac12\rho SL_0/m` 倍（サンプルで 0.002 程度）、ピッチ振動の迎角の変化による分（:math:`C_{N\dot\alpha}` の力）では法線力の振幅の :math:`L_0\omega_n/(C_{N\alpha}V)` 倍（サンプルで約 3 %、位相は 90° ずれる）である。
  角加速度による付加慣性も加えない。迎角 20° から 30° で滑らかに 0 にする（:eq:`eq-lag-fade`）。
* 実測や強制振動の CFD で得たピッチ減衰 :math:`C_{mq}+C_{m\dot\alpha}` は、遅れと対流の項をすでに含む。その値を使うときは遅れの和を 0 にし、減衰の和に入れる（:ref:`sec-file-v1`）。
* **交差する微係数**：線形の :math:`C_{mp},C_{np},C_{mr},C_{nq},C_{lq},C_{lr}`\ （ある軸の角速度が別の軸のモーメントを作る項）は、軸対称な胴体と十字形のフィンの機体では対称性から 0 で、扱わない。
  非軸対称な形状でこれらが 0 でない機体は、外部の一般表でも表せない（一般表は角速度について対角の減衰の和しか持たない）。
  ロールとピッチ・ヨーの非線形な連成は、Magnus 力とモーメント（ロール角速度と迎角の積に比例）と誘導ロール（迎角の 2 乗に比例）だけを扱う。
  これらの表の列 ``cnpa``、``cmpa``、``cl4`` は、部品積み上げ法、パネル法、CFD のどれも推算せず 0 で、値は外部の表（``method = "table"``）で与える（:ref:`sec-file-axisym`）。
  誘導ロールの :math:`\sin4\phi` の形は十字形（4 枚）のフィンのもので、フィンが 4 枚でない表では使わない。
* ロール共振は、ロール角速度が共振のロール角速度（ピッチの固有振動数をロールの慣性の比で補正したもの）を横切ったことを知らせるだけで、その判定は小迎角の復元の微係数と横の慣性モーメントの平均による（:ref:`sec-roll-resonance`）。
  対称なカントはロールを起こすだけで、トリムの強制とはみなさない。
* 回転減衰は、重心が機軸上にあるとして求める。重心の横ずれがあっても、減衰の係数は軸上の重心の式で求める（:eq:`eq-moment-damp6`）。
* 質量が時間とともに変わることによる慣性テンソルの時間微分の項 :math:`\dot I` は無視する。推進剤は軸上の一様な円柱とし、その重心の横方向の移動は考えない。
* 静的な安定は、軸対称表でも一般表でも、迎角 0 の極限の小迎角の余裕で判定する（:ref:`sec-static-margin-general`）。
  一般表は、ピッチ面とヨー面の静安定余裕（迎角 0 と横滑り角 0 での表の傾き）を別々に求め、小さいほうで判定する。ピッチとヨーの連成と、0 から離れた角度での余裕の変化は考えない。
  どちらの表も、傾きは 0 から最初の格子点までの割線である。既定の一般表は最初の格子点が 2° で、軸対称表（1°）より区間が広いので、同じ機体の軸対称表より余裕が小さく出る（サンプルで約 0.1 cal）。
  落下分散のケースとサンプルも、``sim`` と同じく、その飛翔の各時刻の Mach 数と重心で求めた面ごとの小迎角の余裕で判定する（:ref:`sec-dispersion-unstable`）。
* 部品積み上げ法とパネル法は軸対称な機体の係数を出す。一般表（``aero.table_kind = "general"``）は、これらの軸対称表を展開して作るので、
  軸対称な機体以上の情報（非対称な形状による :math:`C_Y` や :math:`C_l` など）は含まない。非対称な形状の係数は、外部の係数表（``method = "table"``）で与える。

ランチャ滑走と離脱
------------------

* ランチャ上の抗力は、レールに沿った速さだけで求める（風を入れない）。風による迎角と抗力は、ランチャ離脱から入る（:ref:`sec-rail`）。
* ランチャ上では姿勢が変わらず、前方のラグがレールを離れるときの回転（チップオフ）と、レールの摩擦は扱わない。
* ランチャ離脱の静安定余裕は、小迎角の余裕で、離脱直後の風による迎角を含めない。サンプルは 1.99 cal（部品積み上げ法。パネル法は 2.32 cal、展開した一般表は 1.89 cal）で、風速と射角によらない。
  離脱速度が小さいと横風による迎角が大きく、迎角が大きいと胴体揚力で圧力中心が前へ動く。サンプル（風 4 m/s、離脱直後の迎角約 6°）では、その迎角での表示 ``stability_cal`` は 1.58 cal まで下がる（:numref:`fig-flight-states`）。
  この迎角での復元の弱まりは判定に入らないので、離脱速度が小さい機体では、風による迎角の警告（15°。:ref:`sec-config-checks`）と合わせて見る。
* ランチャ離脱と着地の時刻・速度・状態は、1 ステップの中の補間（位置は三次エルミート補間、速度はその時間微分、姿勢などは両端の線形補間）で求める（:ref:`sec-step-events`）。
  ランチャ離脱では、積分を離脱の時刻と状態から自由飛行としてやり直す。サンプルでは、``rk4`` の刻み幅を 0.5 ms から 10 ms にしても、離脱速度は 45.661 m/s から 45.660 m/s に、着地速度は 7.0592 m/s から 7.0593 m/s にしか変わらない。

空力
----

* **実測との比較は限られる**。検証と手法どうしの相互比較のほかは、Basic Finner（10 口径の円すい・円柱に矩形フィン 4 枚の標準模型）の超音速の射場試験 :cite:`dupuis1997basicfinner` との比較（妥当性確認）が ``doc/data/validation/basic_finner`` にあるだけである。どの手法の係数も実機の係数の保証ではない（:doc:`verification_aero`）。
* 空力係数は **経験式を含む部品積み上げ法** による推算である :cite:`barrowman,niskanen`。実測との比較がないので、推算の不確かさを定量的には示せない。
  参考として、サンプル機体の亜音速では、部品積み上げ法の :math:`C_{N\alpha}` は Euler の CFD より 23 から 25 % 小さく、パネル法とは 27 から 32 % 異なる
  （手法どうしの相互比較であり、どちらが実機に近いかを示すものではない。:ref:`sec-vaero-compare`）。特に遷音速（:math:`0.9<M<1.5`）は補間であり、物理的な根拠は弱い。
* 胴体は軸対称、フィンは台形に近似する。エアブレーキ、非対称な突起、ランチャラグなどの形状は自動では扱えない
  （ランチャラグなどは ``extra_cd`` で抗力だけを加える）。
* 摩擦抗力の Reynolds 数は射点高度の大気で固定しており、高度による変化を含まない。
* ロールの係数は、部品積み上げ法の式（ストリップ理論による減衰、フィンの揚力傾斜によるカントの強制）で求める。
  フィンどうしや胴体との干渉、カントによる抗力の変化は含まない。サンプル機体の :math:`M=0.8` では、減衰 :math:`C_{lp}` が SU2 の回転座標系の Euler 計算の値より 4 割ほど大きい（:ref:`sec-barrowman-roll`）。
  カントによる強制は小さい角度の線形近似で、カントの角度が大きいときの非線形性は考えない。
* **部品積み上げ法のフィンの法線力は、この形状では低めである。** 既定の胴体干渉係数 :math:`K_{fb}=1+r_t/(s+r_t)`\ （:eq:`eq-fin-total`）は、
  フィンの揚力が胴体へ伝わる分（フィンから胴体への持ち上げ :math:`K_{B(W)}`）を含まない。
  サンプル機体（:math:`r_t/(s+r_t)=1/3`）で、細長体理論の :math:`K_{W(B)}+K_{B(W)}` は約 1.78、部品積み上げ法の係数は 1.33 で、
  パネル法と CFD の値（:ref:`sec-vaero-compare`）と整合する。このため、サンプルのフィン部分の :math:`C_{N\alpha}` は部品積み上げ法のほうが約 25 % 小さい。
  静安定余裕では、圧力中心が前に出るので安全側である。一方、風見効果と落下点はこの係数に左右される。
  サンプル（北風 4 m/s の弾道落下）の着地点は、パネル法と部品積み上げ法で約 68 m 異なる（部品積み上げ法は西 1073 m・北 380 m、パネル法は西 1043 m・北 441 m）。
  風の格子（1〜7 m/s、36 方位）の最大着地距離は、弾道落下で部品積み上げ法 1561.2 m、パネル法 1625.9 m、パラシュート降下で 14304.2 m と 13471.0 m である（:ref:`sec-dispersion-safety`）。機体のばらつきを重ねたモンテカルロ解析の最大では、差が数 km になる。
  落下分散を保安の判断に使うときは、``aero.method = "panel"`` でも風の格子とモンテカルロ解析を計算して最大値の大きいほうを取り、モンテカルロ解析の ``cn_scale`` にこの差を含む標準偏差を与えるとよい。
  細長体理論の近似 :math:`K_{W(B)}+K_{B(W)}\approx(1+\tau)^2`\ （:math:`\tau=r_t/(s+r_t)`）では、比は :math:`1+\tau` なので、相対的な差 :math:`\tau/(1+\tau)` は胴体半径に比べてフィンが小さい機体ほど大きく、フィンが大きい機体ほど小さい。
* **超音速の部品積み上げ法は、線形理論の一部の項を持たない。** Basic Finner の Mach 1.8〜4.3 で、:math:`C_{N\alpha}` は実測より 20〜35 % 小さく、:math:`C_{X0}` は 23〜34 % 小さい。
  :math:`C_{N\alpha}` の内訳（``doc/data/validation/basic_finner/cna_decomposition.csv``）は次のとおりである。

  * 胴体は細長体の :math:`2\,\dd S/\dd x`\ （ノーズの 2）だけで、ノーズの後ろの円筒部の揚力を含まない。Basic Finner の胴体（半頂角 10° の円すいと円筒、全長 10 口径）の :math:`C_{N\alpha}` は、Sims の特性曲線法で Mach 2 で 2.58、Mach 4 で 3.41 である :cite:`sherer1966`。
  * :math:`K_{fb}=1+r_t/(s+r_t)` は、細長体の :math:`K_{W(B)}`\ （:math:`r_t/(s+r_t)=1/3` で 1.28）に近く、フィンから胴体への持ち上げ :math:`K_{B(W)}` を含まない。後部の胴体がない超音速のフィンでは、持ち上げは根元の前縁からの Mach 円すいの内側に限られ、Mach 2 で約 0.11、Mach 4.3 で 0.04 と小さい :cite:`pnk`。
  * フィンは平板の Busemann の式で、断面の厚みによる揚力傾斜の増加を含まない。Basic Finner のくさび断面（半角 2.3°）では、2 次の Busemann の項が Mach 1.8 で 5 %、Mach 4.3 で 10 % 増やす。
  * フィンの線形理論の項（Ackeret の傾き :math:`4/\beta` と、一つの自由な翼端の損失 :math:`1-1/(2\beta A)`）は教科書の式どおりである（``basic_finner_supersonic_cna_is_the_linear_theory_build_up``）。

  これらを足した線形理論の積み上げでも、実測より 9〜16 % 小さい。残りは線形理論の外（非線形の三次元の効果、粘性）である。
  :math:`C_{X0}` では、底面抗力の :math:`0.25/M` が、フィンが底面にある機体の自由飛行の値（Mach 2 で底面圧力係数 :math:`-0.185`。Barrowman :cite:`barrowman` Fig. 4-8）より小さく、
  フィンの後縁の底面抗力に軸対称の底面の式を使い（二次元の底面の式 :math:`(1-0.52M^{-1.19})/M^2` では Mach 2 で 0.19、軸対称の式では 0.125）、とがった前縁のくさび断面の造波抗力（Mach 2 で 0.019）を含まない。
* 部品積み上げ法のピッチ減衰の和 :math:`S_0,S_1,S_2`\ （:eq:`eq-damping`）には、各部品の法線力傾斜だけを入れ、胴体の横流れ（:math:`\sin^2\alpha` の胴体揚力）の項は入れない。
* 部品積み上げ法のフィンの法線力は、15° までは付着流の理論（Barrowman の線形の式、超音速の Busemann の展開）で、それより大きい迎角では流れに垂直な平板の横流れの値（:math:`90^\circ` で :math:`C_{D,\mathrm{plate}}=1.2`〜1.7）へなめらかに近づける経験的な近似である（:ref:`sec-fin-large-alpha`）。
  失速の角度、はく離の遅れ、フィンどうしと胴体との大迎角での干渉は扱わない。平板の値には文献の幅（亜音速で 1.17〜2.0、超音速で 1.6〜1.8）があり、遷音速のつなぎ方も近似なので、30° を超える大迎角の係数は粗い値と考えてほしい。
  パネル法の亜音速の列も、15° から 30° の間でこのモデルへ移り、30° から先はこのモデルの値である（超音速の列は局所傾斜法のまま。:doc:`panel` の「非線形な法線力」）。
* 係数表は既定で迎角 90° まで（``alpha_max_deg = 90``）を持ち、飛翔計算は全迎角を 90° 以下に折り返して引くので、軸対称表の引き出しは表の範囲に収まる。
  ``alpha_max_deg`` を小さくした表で範囲を超えて引いた結果は、端の区間の外挿で、大きな迎角に見かけの釣り合いを作りうるので、使えないもの（終了ステータス 3）とする（:ref:`sec-exit-status`）。
  表の中でも、30° を超える大迎角の係数は上記の経験的な近似で、頂点付近の失速・回転時の挙動は定性的なものと考えてほしい。
* 尾部を先にした飛翔（全迎角 90° 超）は、前向きの係数を 90° について折り返して使う。後ろ向きの流れに固有の圧力中心の移動（フィンの圧力中心が後縁側へ動くこと）は飛翔に入らない（:ref:`sec-fin-large-alpha`）。
  圧力中心の位置も、前向きの流れの値を 90° について折り返したもの（全迎角 :math:`\alpha` の圧力中心に、:math:`\pi-\alpha` の前向きの値をそのまま使う）で、後ろ向きの流れでの圧力中心は近似である。頂点のあとに回転しながら落ちる弾道落下（タンブリング）では、この近似が姿勢と着地点に効く。
* **横向きの落下**\ ：前向きの表の圧力中心は、迎角が大きいほど前へ動く。迎角 90° 付近の圧力中心が重心より前にある機体では、圧力中心が重心に一致する迎角 :math:`\alpha^*` が 90° より手前にある。
  法線力は :math:`0<\alpha<180^\circ` で同じ向きに働くので、全迎角が :math:`\alpha^*` を越えると機首上げのモーメントが迎角をさらに広げ（前向きの側の :math:`\alpha^*` は不安定なつり合い）、
  折り返した側では、:math:`180^\circ-\alpha^*` より小さい迎角で圧力中心（:math:`\pi-\alpha` の値）が重心より前にあって迎角を広げ、大きい迎角で重心より後ろにあって迎角を戻す。
  このため :math:`180^\circ-\alpha^*` が安定なつり合い（トリム）になり、機体は 90° を少し越えた迎角で横向きのまま、遅く長く流されて落ちる。
  このつり合いは、後ろ向きの流れに前向きの圧力中心をそのまま使う折り返しから生じる。実際の後ろ向きの流れでは、尾部のフィンが流れの上流側になって圧力中心が別の位置へ動くので、このつり合いが実際に起こるかはこのモデルでは決まらない。
  大きな迎角でフィンの法線力を小さく見積もる係数表（大迎角のフィンの横流れを持たない表）では、圧力中心が前へ動きすぎて、このつり合いが起こりやすい。
  頂点のあと全迎角 60° から 120° の間で 10 s を超えて飛んだ弾道落下は、``fell_broadside`` として警告し、落下分散では数を残す（:ref:`sec-dispersion-broadside`）。この検出は、どの係数表にも働く安全のための確認である。
  サンプルでは、部品積み上げ法の表もパネル法の表も、迎角 30° 以上の圧力中心が Mach 0.5 以下で 0.90 m 以上（最も前は迎角 69° の 0.902 m）で、燃焼後の重心 0.85 m より後ろにあるので、このつり合いはない。
  :ref:`sec-dispersion-safety` の計算例（36〜360 方位の風の格子と :math:`10^4` サンプルのモンテカルロ解析）でも、横向きに落ちた弾道落下は 1 つもない（``broadside_time`` は最大 2.8 s）。
* CFD の表の、解いた迎角より大きい範囲は、CFD の値ではなく部品積み上げ法へつないだ値である（:ref:`sec-cfd-table-build`）。
* 係数表は Mach 数の方向には外挿せず、表の端の Mach 数の値で一定とする。表の Mach 数の範囲を超える飛翔（既定の表は 0 から 3）では、超過分の係数は端の値である。
  範囲外の引き出しがあると、``sim`` と ``dispersion`` は回数と最大の Mach 数を警告として表示し、``aero_table_range`` に記録する（:ref:`sec-aero-interp`）。
* **手法の使い分けと信頼度**\ （選び方は :ref:`sec-aero-select`）：
  亜音速の法線力と圧力中心は、パネル法が形状から干渉を計算するので、フィンが大きい機体や胴体が太い機体では部品積み上げ法より物理的な根拠がある。
  ただしパネル法は非粘性で、フェアリングの長さの近似を含む。サンプル機体では両者の差が約 0.3 cal あり、静安定余裕はこの差を不確かさの目安として、小さいほうの余裕で判断するのが安全である。
  遷音速（:math:`0.8\le M\le1.2` 付近）は、どちらも補間であり信頼できない（パネル法は :math:`C_{N\alpha}` のピークが過大になりうる。:ref:`sec-lim-panel`）。
  超音速の法線力では、パネル法の局所傾斜法は翼端や干渉の扱いが粗く、部品積み上げ法との差は 10 % 台である（サンプルの :math:`M=2` で 13.05 と 11.19、Euler の CFD は 13.04）。
  抗力は、パネル法は実際の濡れ面積と形状から造波抗力と摩擦を積分するので形状を変えたときの傾向を追いやすいが、
  底面・フィン縁・追加抗力は部品積み上げ法と同じ経験式であり、亜音速の抗力は局所の層流域の仮定のためにやや低く出ている可能性がある。
  結果の差が大きい量は不確かさが大きいと考え、モンテカルロ解析の ``cn_scale``、``ca_scale``\ （:doc:`dispersion`）に反映するとよい。

.. _sec-lim-panel:

パネル法（``aero.method = "panel"``）
-------------------------------------

* 亜音速の解は **非粘性・渦なしのポテンシャル流** である。境界層、剥離、フィン根元や後縁の渦の巻き上がり、渦放出は含まない。
  迎角が大きいときの横流れの力は経験式（:math:`1.1\,(A_p/S)\sin^2\alpha`）で与える。
* 底面の剥離領域は、固体の尾部フェアリングで置き換える近似である。フェアリングの長さ（``tail_radii``）で :math:`C_{N\alpha}` が変わる（既定の 6 で約 1 %）。
  後流はフィン後縁から :math:`+x` 方向に固定されており、迎角による後流の曲がりや巻き上がりは考えない。
* 圧縮性は Göthert の変換 :cite:`gothert` で、薄い物体の線形理論の範囲（亜音速で :math:`M\lesssim0.8`）に限られる。
* 遷音速（既定は 0.8〜1.2）は両側の値を Hermite 補間でつないだもので、物理的な計算ではない。
  :math:`C_{N\alpha}` のピークは、帯の超音速側の端（既定は :math:`M=1.2`）の局所傾斜法の値である。
* 低い超音速の小迎角では、局所傾斜法の法線力が大きく出る。フィンの前縁付近のパネルの傾きがくさびの離脱の角度（:math:`M=1.2` で 3.9°）に近いか超えるので、迎角による圧力差が大きくなるからである。
  さらに、フィンの荷重は :math:`1/\sqrt{M^2-1}` のように大きくなり、翼端の Mach 円すいがフィン全体を覆って胴体に届くので、円すいの内側の荷重を半分とする翼端の補正が成り立たない。胴体の吹き上げは、この範囲では掛けない（:eq:`eq-pn-upwash-weight`）。
  サンプルでは、:math:`M=1.2` の :math:`C_N` が迎角 2〜4° で Euler の CFD より 23〜24 % 大きい（:math:`C_{N\alpha}` は 21.93 と 18.46。迎角 8° では 2.972 と 2.724 で 9 %。:ref:`sec-vaero-compare`）。
* 超音速は局所傾斜法で、パネル間の干渉（衝撃波どうしの干渉、フィンの後流）は、翼端の Mach 円すいの簡易な補正と、フィンに当たる胴体の吹き上げ（:eq:`eq-pn-upwash`。方法の成り立つ Mach 数だけ）を除いて考えない。
  フィンから胴体への持ち上げ（:math:`K_{B(W)}`）は含まない。
  回転体の迎角による増分は細長体の傾きで足す近似で、円筒部は揚力を持たない。超音速では、ノーズの後ろの円筒部が揚力を持つ（半頂角 10° の円すいと円筒で全長 10 口径の胴体の :math:`C_{N\alpha}` は、Sims の特性曲線法で Mach 2 で 2.58、Mach 4 で 3.41 :cite:`sherer1966`。細長体の値は 2）。
* メッシュは、STL から抽出した **回転体と台形フィン** から作る構造メッシュであり、STL の三角形を直接使うのではない。
  フィン断面は両凸の一種類で、抽出できない形状（エアブレーキ、非対称な突起など）は入らない。
* 密行列を解くので、計算時間は :math:`O(n^3)`、メモリは :math:`O(n^2)` で増える（行列 1 つを LU 分解に使い回して :math:`8n^2+64n` バイト。既定のメッシュで約 278 MB）。パネルを 1 万枚以上にするのは現実的でない。
  必要なメモリがこのプロセスの使えるメモリ（Linux の ``MemAvailable``、cgroup の上限、``ulimit -v``。macOS では物理メモリ）を超えるときは、メモリの予算（``resources.memory_gb``）の有無にかかわらず、計算の前にエラーで止まる（:doc:`panel`）。
* フィン根元の周方向に非常に細いパネルがあるなど、メッシュの質による誤差がある（粗いメッシュと細かいメッシュの差は 0.6 %）。
* 抗力のうち底面・フィン縁・追加抗力は部品積み上げ法の経験式をそのまま使う。
* パネル法の表面摩擦のレイノルズ数は、部品積み上げ法と同じく、設定した大気（``[atmosphere]``。温度差を含む）の射点高度の値で計算し、高度による変化を含まない。
* 部品積み上げ法との差の一部（フィンと胴体の干渉の大きさ、亜音速の抗力）は、どちらが実機に近いかは、風洞試験などの実測でなければ決められない。
  パネル法も細長体理論も非粘性で、境界層やフィン根元の渦を含まない。

.. _sec-lim-cfd:

CFD（``aero.method = "cfd"``）
------------------------------

* 既定は **非粘性の Euler 方程式** で、摩擦、底面、フィン縁、ボートテール、追加抗力は部品積み上げ法の経験式を足している（ノーズの圧力抗力は CFD の値）。
  亜音速の Euler の軸力は、理論値 0 に対して小さな負の値（サンプル機体で :math:`-0.03` から :math:`-0.06`）になり、そのまま合計に入る。
  Euler では底面を尾部フェアリングで置き換えるので、底面抗力も経験式による。
* RANS（``model = "rans"``）は、作り直した形状（``surface = "panel_mesh"``）でフィンの配置が :math:`y=0` について対称なときと、CAD のモデル（``surface = "step"``）で使える。STL の壁面、``panel_mesh`` の :math:`y=0` について非対称な配置、ロール減衰のケースは解けない。
  :math:`z` 対称メッシュは使えず、``alpha_mode = "mirror"`` では負の迎角も解く。``panel_mesh`` のフィンの前縁と後縁は、プリズム層のために少し鈍くする（縁の厚さは最大の厚さの約 8 %）。
* RANS の 1 ケースのメモリは大きい（実測で節点あたり約 10 kB、余裕を含めた見積もりで約 12 kB。サンプル機体の半モデルで ``wall_size`` 3 mm は約 23 GB、5 mm は約 9.5 GB）。最初の層の高さは平板の摩擦の式による見積もりで、受け入れたあとに壁面の :math:`y^+` を確かめる。
  RANS の検証の項目と結果は :ref:`sec-cfd-rans` にある。そこで確かめていない量や条件の結果は、検証されたものとして扱わない。
* RANS で検証したのは、付着した流れの摩擦（平板、円すい、フィンなし胴体）と、サンプル機体の :math:`M=0.8`\ 、2、:math:`\alpha=\pm4^\circ` の係数（メッシュの収束と Euler との相互比較）である。実測との比較（妥当性確認）はない。

  * 亜音速の :math:`\alpha=0` で、底面の後流の非対称な解のために :math:`C_N` が残る（サンプル機体の :math:`M=0.8` で 0.011〜0.034、メッシュで符号も変わる）。係数表では ``alpha_mode = "mirror"`` で取り除く。
  * :math:`M=0.3` では :math:`\alpha=0` と負の迎角のケースの残差が周期的に振動して収束せず、係数の平均を受け入れる。サンプル機体の係数表（4 Mach 数、20 ケース）で収束したのは 75 % である。
  * 底面の流れ（``rans_base = "cfd"`` の底面の力）は確かめていない。:math:`\alpha=8^\circ` と :math:`M=0.3,1.2` は、Euler の表との比較だけでメッシュの収束を確かめていない。
  * RANS の壁は滑らかで、設定の粗さは部品積み上げ法の摩擦の増分として足す。フィンの縁は作り直した形状の、弦長の 2 % で鈍くした縁の値で、設定の ``fin_le``\ 、``fin_te`` は RANS の軸力に入らない。
    そのためサンプル機体の :math:`M=1.2` と 2 の燃焼後の軸力は、Euler の表（部品積み上げ法のフィンの項を含む）より 11〜23 % 小さい（粗さの増分を後から足した再計算。:ref:`sec-cfd-rans-table`）。
* **メッシュ収束は確認できていない**。:math:`M=2` の :math:`C_N` は、最も細かいメッシュ（1.8 mm）でもまだ増えており、収束の次数の当てはめ（:math:`p=2.65`）による外挿値は、データが漸近範囲にないので、収束値として確定できない。
  GCI は、細かい二つのメッシュの格子幅の比が約 1.06 と小さく、粗い目安にとどまる。:math:`M=0.8` は単調に収束しない（3.5 mm の 1.2259 から 1.8 mm の 1.2021 まで減る）。
  既定の 2 mm の :math:`C_N` は、1.8 mm の値と 0.6〜0.8 % 異なる。粗い 5 mm では :math:`M=2` で 1.8 mm の値より 5.7 % 低い（:ref:`sec-vaero-cfd-mesh`）。
* 壁面は、抽出した胴体とフィンを作り直した形状（``surface = "panel_mesh"``）か、STL そのもの（``surface = "stl"``）か、CAD のモデル（``surface = "step"``）である。
  前者はレールボタンや非対称な突起を含まない。後者は重なった閉じた殻を manifold3d で和にする。和の表面が鏡映対称と確かめられれば 1/4 または半領域のメッシュで解き、
  そうでなければ全領域（サンプルの 2 mm で約 200 万セル）を解く。検査は幾何だけで、明示した対称性が検査に通らなければエラーである。
* STL モードと ``step`` では、フィンの前縁と後縁の面が CFD の壁面にあるので、部品積み上げ法のフィン縁の抗力は足さない（``panel_mesh`` では足す）。
  STL モードの軸力は、角の立った厚いフィンの Euler の圧力抗力を、そのまま使う。
* CAD のモデル（``surface = "step"``）について。

  * CAD のモデルは ``rocket.stl`` と同じ機体でなければならない。飛翔計算の形状と、CFD で補う部品積み上げ法の項（摩擦、底面）は STL から求めるので、CAD だけにある細部の摩擦抗力は入らない。
  * ``rocket.stl`` との位置合わせの許容は :math:`\max(2\,` ``wall_size`` :math:`,\,0.01L)` で、単位、向き、別の版のような大きな食い違いを見つけるためのものである。これより小さい形の違い（フィンの厚さや翼形の違いなど）は見つけない。
  * 鏡映対称の検査は CAD の曲面の上の約 6000 点で行い、許容は全長の :math:`10^{-6}` 倍か、曲面に射影し直したときの誤差の 4 倍の大きいほうである。点の間にある小さな非対称は見落としうる。
  * ランチラグやレールボタンのように鏡映対称でない細部があると全領域を解き、セル数は半領域の約 2 倍、ケースも負の迎角のぶん増える。細い面（ランチラグの管の壁など）があると、最小の要素が ``wall_size`` の 1/8 まで小さくなる。
  * 1/4 領域を CAD の形状から切り出せないときは、半領域をメッシュにして負の迎角も解く。
  * 読み込みのときの形状の修復は、表面のメッシュができないときにしかかけない。修復でも直らないモデルは、CAD の側で直す。
  * RANS では CAD の縁を鈍くしないので、鋭い縁や狭いすき間でプリズム層が検査に通らないことがあり、そのときは Euler を使うか CAD で縁を丸める。
    ``surface = "step"`` の RANS は、メッシュの検査（不正なプリズムがないこと、層の上面の大きさの比）までを試験し、SU2 で解いた結果は確かめていない。
* STL を Euler で解くには ``base_treatment`` が必要である（CAD のモデルも同じ）。``"fairing"`` は入力の STL を変更し、``"flat"`` は形状を保つが、Euler の解は収束しないことがある（サンプルの STL では収束しなかった）。
  形状の忠実度（CFD の壁面と入力の距離）はサンプリングによる距離の推定で、ごく薄いフィン縁のような細い特徴のずれを見落とすことがある。
* 横滑りを含む 6 成分の係数表（一般表）を作れるが、解いた迎角と横滑り角の範囲（CFD の領域）の外側の値は CFD の結果ではなく、部品積み上げ法の展開値を境界に合わせて延ばしたモデルによる補完である。軸対称な形状の展開なので、非対称な形状の外側では当てにならない。
* ロール減衰 :math:`C_{lp}` は回転座標系の Euler の解から得る。粘性の寄与は含まず、メッシュを変えたときの値の変化は十分に確かめていない。ピッチとヨーの減衰 :math:`C_{mq}`、:math:`C_{nr}` は定常計算では得られず、
  部品積み上げ法（またはパネル法）の和のばらつきに CFD の傾きと重心を合わせた近似である。交差する微係数は CFD からも得られず、扱わない。
* ケースの結果（``done.json``）は SU2 の設定とメッシュのハッシュで判定するので、SU2 の設定やメッシュの作り方が変わるコードの更新のあとは、作業ディレクトリ（``workdir``）を消して計算し直す。
  係数表のキャッシュは、プログラムの版と空力モデルの版を含み、資源とパスの設定を含まない。
* CFD の係数表は Mach 数の方向に外挿せず、解いた最小・最大の Mach 数の外では端の値で一定である（``cfd_report.json`` の ``mach_clamped_above`` と ``mach_clamped_below``）。
* 動作は Linux と conda-forge の SU2 8.3.0、gmsh、Open MPI、pip の manifold3d（3.5.4）で確かめた。他の環境では確かめていない。
* **STL の鏡映対称の検査は和の表面の幾何だけ**\ で、全長の :math:`10^{-6}` 倍（サンプルで 1.8 μm）の許容で行い、許容は変えられない。
  STL の三角形分割が曲面を鏡映の関係にない平面で近似していれば、人の目に対称でも検査に通らず、全領域を解く。
  鏡像として補う係数は、検査に通った平面についてだけ使う。
* STL のメッシュの作成は実行ごとに同一にならず、``wall_size`` 5 mm の :math:`C_N` はメッシュごとに数 % 変わることがある（:ref:`sec-vaero-cfd-symmetry`）。
  半領域と全領域の比較は、同じメッシュから作ったものどうしでなければ意味を持たない。
* ``multigrid`` は、この実装のメッシュでは粗い格子が作られず、設定しても効果がない（既定は 0。:ref:`sec-cfd-multigrid`）。
* 計算コストが大きい。既定の行列（10 Mach × 6 迎角）を 2 mm で解くと大量のメモリと時間を使う（メモリの見積もりは :eq:`eq-cfd-mem`）。
  粗い 5 mm は 4 から 5 分の 1 の時間で済むが、:math:`M=2` で :math:`C_N` が 1.8 mm の値より 5.7 % 低い（当てはめ値に対しては 7.1 %）。
  横滑り角や負の迎角を解くと、ケース数がそのぶん増える。半領域・全領域のセル数は、上の壁面と対称性の項に挙げた。
  サンプルでは 1 ケースあたり数 GB のメモリと数分から数十分がかかる。

推進
----

* 推力のミスアライメント（傾きと方位）とノズルのオフセットは、設定した **一定の値** で、燃焼中に時間変化しない。推力の大きさは推力曲線のとおりである。
* 推進剤の消費は推力に比例すると仮定し、ジェットダンピングや質量変化による慣性項 :math:`\dot I` を無視している。
* 推力の高度依存（背圧の変化）は考えない。

回収
----

* パラシュートは瞬時に開き、機体を質点として扱う。ドローグとメインの二段開傘は扱える（``main_cd_s`` と ``main_altitude``。:ref:`sec-dual-deploy`）が、
  どちらの開傘も瞬時で、開傘衝撃と開傘までの過渡的な挙動、ドローグの切り離しの動きは扱わない（これらの扱いは :cite:`knacke` を参照）。
  メインはドローグの抗力面積を置き換えるだけで、三段以上の開傘や、開傘高度が風や頂点で変わる動作（気圧や加速度による開傘装置の誤作動）は扱わない。
* パラシュート降下中の抗力はパラシュートの :math:`C_DS` だけで、機体（胴体）の抗力は入れない。サンプルでは機体の :math:`C_DS` は約 0.004 m\ :sup:`2`\ （:math:`C_{D0}\approx0.49`、基準面積 0.00785 m\ :sup:`2`）で、パラシュートの 3.5 m\ :sup:`2` の約 0.1 % なので、着地点への影響は小さい（数 m の程度）。

風
--

* 風は水平方向だけで、時間によらない定常な風である。突風や乱流は考えない。
* べき法則と対数則は大気境界層（数百 m まで）の近似 :cite:`stull` であり、上空の風速を過大に見積もりやすい（:ref:`sec-wind`）。
  頂点が地上 1000 m を超えると、これらのモデルが上空へ外挿されることを警告する（:ref:`sec-config-checks`）が、結果は修正しない。
  高度別の表（``profile``）を使えば高層観測や数値予報の風を与えられるが、表の範囲外は端の値で一定とし、
  時刻や水平位置による変化は表現できない。

大気
----

* 標準大気の温度差は、高度によらず一定の値を加えるだけである（逆転層や湿度は考えない）。
* 係数表の入力ハッシュは ``[atmosphere]`` の設定（温度差を含む）を含むので、大気を変えると係数表は作り直される。

数値計算
--------

* 刻み幅制御付きの ``rk45`` :cite:`dormand` と ``dop853`` :cite:`princedormand` は、許容誤差を極端に小さくすると、刻み幅が下限（:math:`10^{-6}` s）を下回ってエラーになることがある。
  既定の許容誤差では起きない。空力係数表が区分的に線形なので、``dop853`` でも刻み幅は大きくできず、サンプルでは ``rk45`` より評価回数が多い（:ref:`sec-integrators`）。

不確かさの評価
--------------

* モンテカルロ解析は、推力・燃焼時間・乾燥質量・重心・空力係数・射角・風・パラシュートの 11 項目と、
  設定したときだけ有効になるロールと非対称の 6 項目（推力の傾き、ノズルのオフセット、フィンのカント、乾燥重心の横ずれ、ロールの係数、ロール減衰）を **互いに独立な正規分布** でばらつかせる。
  項目どうしの相関、一様分布などの別の分布、機体形状そのもの（フィンの寸法など）のばらつきは扱わない。
  標準偏差は利用者が決める必要があり、既定値は目安にすぎない。
* 空力係数のばらつきは、係数表の値に一律の倍率を掛けるだけで、Mach 数や迎角による誤差の違いは表現できない。
  :math:`C_Y,C_Z,C_m,C_n` は法線力の倍率 ``cn_scale`` を共通に受けるので、軸ごとに独立にはばらつかない。
* 誤差楕円は着地点を正規分布とみなした要約である。分布が歪むときは、最大着地距離やパーセンタイル、散布図そのものを見てほしい（:ref:`sec-mc`）。
* ``sim.max_time`` までに着地しない飛翔や、失敗したサンプルは、統計に入らない。1 件でもあると統計は不完全（``complete = false``）で、最大着地距離は下限になり、
  真のばらつきは報告された値より大きいか不明である（:doc:`dispersion`）。``max_time`` を延ばしても着地するとは限らない。
* 着地点の平均は着地したサンプルが 1 つ以上、標準偏差・共分散・誤差楕円は 2 つ以上のときだけ求まる。足りないときは ``null`` で、サンプル数が少ない統計は信頼できない。
* 静的な安定は、迎角 0 の極限の静安定余裕（圧力中心と重心の距離）の符号だけで判定する（一般表ではピッチとヨーの余裕の小さいほう。:ref:`sec-static-margin-general`）。``dispersion`` は、公称の飛翔（設定した風での弾道落下）の判定に加えて、風の格子のケースとモンテカルロのサンプルのうち余裕が 0 cal 未満のものと、一般表で余裕を求められず判定できないものを降下モードごとに数え、終了ステータス 3 にする。
  これらは統計に残し、除かない（転倒を含む飛翔が着地距離に入る）。余裕が 0 cal 以上でも小さいケースは数えない（:ref:`sec-dispersion-unstable`、:ref:`sec-exit-status`）。
  余裕は迎角 0 と横滑り角 0 の付近の傾きから求め、大きな迎角での釣り合いは調べない。
* 積分が発散した飛翔は、エラーにして止める。モンテカルロ解析では、そのサンプルを失敗として数える（:ref:`sec-integrators`）。
* 空力係数の不確かさそのもの（推算法の誤差）は、``cn_scale``、``ca_scale``、``cl_scale``、``clp_scale``、``cmq_scale``、``lag_scale``、``magnus_scale`` に利用者が見積もった値を入れる必要がある。
