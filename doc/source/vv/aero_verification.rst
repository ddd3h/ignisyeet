空力モデルの検証
==================

この章は、部品積み上げ法、係数表、パネル法の実装を、解析解、手計算、文献の関係式と比べた検証の結果をまとめる。
CFD の検証は :ref:`sec-vaero-cfd` と :ref:`sec-cfd-rans` に、手法どうしの比較は :ref:`sec-vaero-compare` に、実測との比較は :ref:`sec-validation` にある。
各項目は ``cargo test --release`` で再現できる。

.. list-table:: 空力モデルの検証の結果
   :header-rows: 1
   :widths: 20 40 40

   * - モデル
     - 比べる相手
     - 結果
   * - 部品積み上げ法
     - 細長体理論、Barrowman の手計算 :cite:`barrowman`、ロール微係数の数値積分
     - 胴体 :math:`C_{N\alpha}` は 2 に 0.02 以内。サンプル機体の :math:`C_{N\alpha}` と :math:`x_{cp}` は手計算と 4 桁で一致
   * - 係数表
     - 軸対称表と展開した一般表、保存と読み込みの往復
     - 係数は :math:`10^{-8}` 以内で一致。頂点高度の差 0.05 m
   * - パネル法
     - 球、長球、細長体理論、Helmbold、Taylor–Maccoll :cite:`taylormaccoll`、斜め衝撃波、Prandtl–Meyer
     - 表面 :math:`C_p` の最大誤差 0.012（球）と 0.0007（長球）。矩形翼の :math:`C_{L\alpha}` は Helmbold に対して :math:`-3.1` %

.. _sec-vaero-barrowman:

部品積み上げ法
----------------

胴体の法線力傾斜、サンプル機体の手計算との一致、遷音速での連続性、ロールの微係数の順に示す。ロール減衰を SU2 の計算と比べた結果は相互比較であり、:ref:`sec-vaero-barrowman-su2` で区別して述べる。

**胴体の法線力傾斜。** ノーズと円筒からなり後端が平らな胴体では、細長体理論 :cite:`munk` より :math:`C_{N\alpha}^{\mathrm{body}}=2` である。
抽出した半径分布（600 区間の円すい台）から計算した値は 2 との差が 0.02 以内であり、圧力中心は接線オジブの理論値 :math:`0.466\,L_n` :cite:`barrowman` と 10 mm 以内で一致する。

**Barrowman の手計算との比較。** サンプル機体の設計寸法（:math:`d=100`、:math:`a=200`、:math:`b=100`、:math:`s=100`、:math:`m=80`、:math:`x_{le}=1300` mm、4 枚）を古典的な Barrowman の式 :cite:`barrowman` で手計算すると、次の値になる。

.. math::

   \ell_f = \sqrt{s^2+\left(m+\tfrac b2-\tfrac a2\right)^2}=0.1044\ \mathrm{m},\qquad
   K_{fb} = 1+\frac{d/2}{s+d/2} = 1.333,

.. math::

   C_{N\alpha}^{\mathrm{fins}} = K_{fb}\,\frac{4N(s/d)^2}{1+\sqrt{1+\left(\dfrac{2\ell_f}{a+b}\right)^2}} = 9.617,\qquad
   x_f = 1.3744\ \mathrm{m}

ノーズ（:math:`C_{N\alpha}=2`、:math:`x=0.466L_n=0.1398` m）と合わせて :math:`C_{N\alpha}=11.617` /rad、:math:`x_{cp}=1.1619` m である。
STL から計算した値（:math:`M=0`）は :math:`C_{N\alpha}=11.617`、:math:`x_{cp}=1.1620` m で、よく一致する。

**遷音速での連続性。** :math:`M=0.5` から 2.5 まで 0.005 刻みで :math:`C_N`\ （迎角 2°）と :math:`C_{D0}` を評価すると、隣り合う値の差はそれぞれ 2 % 未満、3 % 未満である。遷音速の補間区間の両端で値と傾きが一致するよう Hermite 補間を使っているためである。

**ロールの微係数。** サンプル機体（4 枚フィン）の :math:`M=0.8` で、カントによる強制 :math:`C_{l\delta}` は正、ロール減衰 :math:`C_{lp}` は負である。
フィンを 3 枚にすると :math:`C_{lp}` はちょうど 3/4 倍になる。:math:`C_{lp}` は、ストリップ積分を 20000 区間の数値積分で別に計算した値と相対誤差 :math:`10^{-6}` で一致する。
遷音速の補間区間（:math:`M=0.899` と 0.901）の前後で、:math:`C_{lp}` の差は 1 % 未満である。

.. _sec-vaero-barrowman-su2:

SU2 との相互比較
~~~~~~~~~~~~~~~~~~

ロール減衰を、CFD の回転座標系の計算と比べた。サンプル機体の :math:`M=0.8` で、無次元ロール角速度 :math:`\hat p=\pm0.01` の Euler 計算から :math:`C_{lp}=-21.6` が得られた。
:math:`\hat p=\pm0.005` でも同じ傾きで、ロール角速度に対して線形である。フィンのない胴体では :math:`C_{lp}\approx-0.001` である。

.. list-table:: :math:`M=0.8` のロール減衰 :math:`C_{lp}`
   :header-rows: 1
   :widths: 60 40

   * - 手法
     - :math:`C_{lp}`
   * - SU2（Euler、回転座標系）
     - −21.6
   * - 部品積み上げ法（3 次元の揚力傾斜を使う式）
     - −29.9
   * - 2 次元の揚力傾斜 :math:`2\pi/\sqrt{1-M^2}` を使う式
     - −155

3 次元の傾斜を使う式は SU2 の値より 4 割ほど大きいが桁は一致し、2 次元の傾斜を使う式は 7 倍ほどになる。
これは 2 通りの推算の相互比較であり、実機や風洞の実測との比較（妥当性確認）ではない。SU2 の値は非粘性の Euler 計算で、このメッシュではメッシュ依存性を確かめていない。
部品積み上げ法のロール減衰は、フィンどうしの干渉と胴体の影響を含まない近似である（:ref:`sec-lim-aero`）。
Basic Finner の実測との比較は :ref:`sec-validation-results` にある。

.. _sec-vaero-barrowman-roll-flight:

ロールの飛翔への影響
~~~~~~~~~~~~~~~~~~~~~~

カントを 1° としたサンプル機体の飛翔では、ロール角速度は燃焼終了の直前（:math:`t=2.95` s、Mach 1.54）に最大の約 88 rad/s になる。
この時刻の表の値（:math:`C_{l\delta}=16.7`、:math:`C_{lp}=-34.4`）と対気速度 519 m/s から定常ロールの式で見積もった値も約 88 rad/s で、飛翔計算と一致する。
ロール角速度の予測は :math:`C_{l\delta}` と :math:`C_{lp}` の不確かさに強く依存するので、幅はモンテカルロ解析の ``cl_scale`` と ``clp_scale`` で見積もる。

係数表
--------

係数表の検証は、展開した表が軸対称表と同じ内容を持つこと、保存して読み込んでも値が変わらないこと、角度の定義が一貫していることである。

* **軸対称表の展開**：軸対称表を :math:`\alpha\in[-180^\circ,180^\circ]`、:math:`\beta\in[-90^\circ,90^\circ]` の一般表に展開し、格子点で次の関係を確かめた。
  :math:`\beta=0` の純粋なピッチでは :math:`C_Z=-C_N`、:math:`C_Y=0`、:math:`C_m=x_{cp}C_Z/d`、:math:`C_X=-C_A`。:math:`C_Y` は :math:`\beta` について奇関数で :math:`C_n=-x_{cp}C_Y/d`、:math:`C_Z` は :math:`\alpha` について奇関数である。
  :math:`\alpha=180^\circ` の後ろ向きでは軸力の向きが反転する。一般表を保存して読み込むと、中間の点の 18 個の係数が :math:`10^{-8}` 以内で一致する。
* **古い列数の表**：8 列の CSV と ``format_version`` のない付随ファイルは、ロール項が 0 の軸対称表として読め、:math:`C_N` が元の表と :math:`10^{-9}` で一致する。列数の少ない軸対称表と一般表は、足りない列を 0 として読める。
* **角度の定義**：:math:`(\alpha,\beta)` から対気速度の方向ベクトルを作って :math:`(\alpha,\beta)` に戻すと :math:`10^{-12}` で一致する。角度の軸は :math:`-180^\circ` から :math:`180^\circ` まで単調に増える。
* **読み込みの規則**：軸対称表の迎角の格子が 0 から始まらない表と、一般表の格子が 0 を含まない表は、読み込みでエラーになる。格子の座標に ``inf`` がある行は、行と列を示してエラーになる。
  最初の格子点（5°）より小さい迎角の引き出しは、範囲外として数える。
* **一般表の外挿の符号**：端に向かって小さくなる :math:`C_Y,C_Z,C_m,C_n` を格子の外（40°）へ外挿しても符号は反転せず 0 で止まる。反転の手前（22°）では線形外挿の値のままである。
* **フィンのない閉じた胴体**：尾部が点に閉じたフィンのない胴体でも、表のすべての値が有限で、迎角 0 の圧力中心がノーズ先端になる。
* **展開した表での飛翔**：軸対称表を展開した一般表は新しい情報を加えないので、飛翔もほぼ一致する。サンプルでは、頂点高度が軸対称表で 4440.48 m、一般表で 4440.52 m（差 0.05 m）である。
  最小静安定余裕は、軸対称表で 1.99 cal、一般表で 1.89 cal である。どちらも最初の迎角の区間の割線の傾きから求めるが、その区間が軸対称表では 0〜1°、一般表では 0〜2° なので、一般表の余裕が約 0.1 cal 小さい（:ref:`sec-static-margin-general`）。

**メッシュの収束と遷音速の連続性。** サンプル機体の :math:`C_{N\alpha}`\ （:math:`M=0`）は、粗いメッシュ（軸方向 60、周方向 32、フィン 16 × 10）で 14.622、細かいメッシュ（軸方向 120、周方向 64）で 14.711 となり、差は 0.61 % である。
:math:`M=0.6` から 1.6 を 0.02 刻みで走査すると、隣り合う Mach 数の間の :math:`C_N` の変化は最大 6.0 %、:math:`C_A` は最大 3.1 % で、跳びがない。
:math:`C_N` の変化が大きいのは帯のすぐ上（:math:`M=1.2` から 1.3）で、フィンの前縁付近のパネルがくさびの離脱の角度（:math:`M=1.2` で 3.9°）をまたぎ、付いた衝撃波の圧力が急に上がるからである（:ref:`sec-vaero-compare-panel`）。
遷音速の帯（:math:`M=0.8` から 1.2）の中では、各 Mach 数と迎角の :math:`C_N`、モーメント、:math:`C_{N\alpha}` が、帯の両端の値の間に収まる（行き過ぎない）。これは変化量の上限であり、:math:`C_N` はピーク付近で実際に Mach 数とともに速く変わる。

開口のままでは、胴体のみで :math:`C_{N\alpha}=1.05`\ （細長体理論では 2）、圧力中心が機体の前方に出るという非物理的な結果になる。フェアリングを長くすると 2 に近づく。

.. _sec-vaero-panel-wake:

フィンの後流
~~~~~~~~~~~~~~

後流の長さ ``wake_length`` が 2 L 以上であれば、:math:`C_{N\alpha}` はほぼ変わらない（:math:`2L` と :math:`50L` で 14.681 と 14.684、差 0.02 %）。
後流を置かない（``wake_length = 0``）と Kutta 条件が働かず、同じ形状で :math:`C_{N\alpha}=4.15` になる。
