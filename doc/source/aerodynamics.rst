空力モデルの全体像
==================

本章は、IgnisYeet が機体に働く空気力をどう扱うかの地図である。
機体の形から空気力の係数を求める三つの方法（部品積み上げ法・パネル法・CFD）と外部の表があり、
どの方法で求めた係数も **係数表** という同じ形式にまとめられる。
飛翔計算はこの表を内挿して使うだけなので、表がどの方法で作られたかを区別しない。
本章では、この全体の流れ、軸対称表と一般表の違い、三つの方法の考え方と選び方、表の内挿と外挿を述べる。
係数の定義と座標系は :doc:`aero_coefficients` で、各方法の詳細は部品積み上げ法を :doc:`barrowman`、パネル法を :doc:`panel`、CFD を :doc:`cfd` と :doc:`cfd_internals` で述べる。
各方法の結果の確かめ方は :doc:`verification_aero` にまとめる。

この章の読み方
--------------

この章は、設定 ``aero.method`` で何を選ぶか、表がどのように作られるかを知りたい読者に向ける。
式は少なく、図と文章だけで全体がつかめるようにしてある。
係数の式や符号を確かめたいときは :doc:`aero_coefficients` に進む。

本章に出る主な記号を、一行の説明で示す。定義と符号は :doc:`aero_coefficients` で述べる。

.. list-table:: 本章に出る主な記号
   :header-rows: 1
   :widths: 22 78

   * - 記号
     - 意味
   * - :math:`M`
     - Mach 数。係数表の第一の引数
   * - :math:`\alpha_t`
     - 全迎角。機軸と対気速度のなす角（0 から 180°）。軸対称な機体は向きによらずこの角だけで決まる
   * - :math:`\alpha,\ \beta`
     - 機体座標での迎角と横滑り角。:math:`\alpha_t` と違い符号と向きを持ち、一般表の引数になる（:ref:`sec-aero-angles`）。:math:`\beta` は、圧縮性の因子 :math:`\sqrt{|1-M^2|}` や衝撃波角にも同じ文字を使う（式のある章で断る）
   * - :math:`C_N,\ C_A`
     - 機軸に垂直な法線力と、機軸方向の軸力の係数。軸対称表が持つ
   * - :math:`C_X,C_Y,C_Z`
     - 機体座標 :math:`x_b,y_b,z_b` 方向の力の係数。一般表が持つ。軸力は :math:`C_X<0` が抗力の向きで、:math:`C_N` は :math:`C_Y,C_Z` の合成に当たる
   * - :math:`C_l,C_m,C_n`
     - :math:`x_b,y_b,z_b` まわりのロール、ピッチ、ヨーのモーメントの係数。ノーズ先端まわりで定義する
   * - :math:`x_{cp}`
     - 圧力中心。法線力の作用点（ノーズ先端から後方へ測る）。軸対称な機体で意味を持つ
   * - CG（:math:`x_{cg}`）
     - 重心。静安定余裕は :math:`x_{cp}` と :math:`x_{cg}` の差で決まる
   * - :math:`C_{lp},\ C_{mq},\ C_{nr}`
     - ロール、ピッチ、ヨーの角速度に対する減衰の微係数

見分けるべき対が四つある。:math:`\alpha` と :math:`\alpha_t` は、符号を持つ座標面内の角と、機軸からの総ずれである。
:math:`C_N` と :math:`C_Z` は、機軸に垂直な力の大きさと、機体座標の一成分である。
:math:`x_{cp}` と :math:`C_m` は、力の作用点の位置と、ノーズ先端まわりのモーメントである。
:math:`C_A` と :math:`C_X` は、符号が逆で、軸力は抗力の向きを正とする。
どれも :doc:`aero_coefficients` で対応を示す。

.. _sec-aero-flow:

空力解析の流れ
--------------

空力解析は、STL から飛翔計算に渡す係数表を作るまでの段階である。
STL から機体の寸法（半径分布、フィンの平面形、機体軸）を取り出して形状情報（``geometry.json``）にし、
設定 ``aero.method`` で選んだ方法がこの形状情報（または STL そのもの）から係数を求めて、``aero_table.csv`` に書く
（:numref:`fig-aero-flow`）。
外部の表だけは形状を使わず、読み込んだ表をそのまま使う。
飛翔計算（6 自由度の剛体運動の計算）と落下分散は、表の内挿と外挿だけを行う。

.. _fig-aero-flow:

.. figure:: _generated/tikz/aero_flow.*
   :width: 100%

   空力解析の流れ。形状情報から四つの方法のどれかで係数表を作り、飛翔計算は表だけを使う。

なぜ係数表を先に作るのか
~~~~~~~~~~~~~~~~~~~~~~~~

飛翔計算は時間刻みごとに何度も係数を必要とする。一方、係数は形状と気流の条件だけで決まり、飛翔の途中で形状は変わらない。
そこで、係数を格子上で一度だけ計算しておき、飛翔計算では表の内挿だけを行う。
こうすると、空力モデルの計算の重さと飛翔計算の重さが切り離され、重い方法に置き換えても飛翔計算側は変わらない。
理由の詳しい説明は :doc:`overview` にある。

手法の選び方
------------

どの方法も同じ形式の表を作るので、手法は計算時間と信頼したい範囲で選べる。実測との比較はまだないので、どの手法も風洞試験や飛翔試験の代わりにはならない。
次の順に進めることを勧める。

1. **まず部品積み上げ法を使う。** 計算が速く、外部プログラムも要らない。形状を変えながら設計を進める段階に向く。
2. **パネル法で比べる。** 仮定が部品積み上げ法と独立なので、両者の差を推算の不確かさの目安にできる。
   静安定余裕は、両者のうち小さいほうで判断するのが安全である。
3. **遷音速・超音速や、重要な条件は CFD で確かめる。** 部品積み上げ法やパネル法の結果を独立な方法で確かめるのにも向く。
   計算資源と時間がかかるので、Mach 数と迎角の点を絞って解き、その間は表で補う。

手法ごとの信頼の目安は次のとおりである。

* **亜音速の法線力・圧力中心**：パネル法は形状から干渉を計算するので、フィンが大きい機体や胴体が太い機体では部品積み上げ法より物理的な根拠がある。
  ただし非粘性で、フェアリングの長さの近似を含む。一方、部品積み上げ法は経験式の範囲内で安定した値を返す。
  静安定余裕の評価では、両者の差（サンプル機体で約 0.3 cal）を不確かさの目安とし、小さいほうの余裕で判断するのが安全である。
* **遷音速（Mach 0.8〜1.2）**：部品積み上げ法もパネル法も補間であり、信頼できない。パネル法はとくに :math:`C_{N\alpha}` のピークが過大になりうる（サンプルの :math:`M=1.2` で CFD より 19 % 大きい）。
* **超音速の法線力**：パネル法の局所傾斜法は円すい・くさびの厳密な関係に基づく一方、翼端や干渉の扱いが粗い（干渉はフィンに当たる胴体の吹き上げだけ）。部品積み上げ法との差は 10 % 台である（サンプルの :math:`M=2` で、パネル法は CFD と 0.1 % 以内、部品積み上げ法は 14 % 小さい）。
* **抗力**：パネル法は実際の濡れ面積と形状から造波抗力と摩擦を積分するので、形状を変えたときの傾向は追いやすい。ただし底面・フィン縁・追加抗力は部品積み上げ法と同じ経験式である。
  亜音速の抗力は、局所の層流域を仮定するためにやや低く出ている可能性がある。
* **CFD**：Euler 方程式（既定）は非粘性で、摩擦抗力や底面抗力は部品積み上げ法の項で補う。RANS は摩擦抗力も CFD から得るが、使える形状に制約があり、検証の項目と結果（:ref:`sec-cfd-rans`）を確かめてから使う（:doc:`cfd`）。
  解いた領域の外側の値は CFD の結果ではなく、モデルによる補完である。

差の大きい量は不確かさが大きいと考える。その大きさは、モンテカルロ解析の ``cn_scale``, ``ca_scale``\ （:doc:`dispersion`）に反映するのがよい。
サンプル機体での三つの手法の比較は :ref:`sec-vaero-compare-three` にまとめる。そこでは、亜音速の法線力傾斜は CFD とパネル法が近く、部品積み上げ法が小さく出ている。

.. _sec-aero-methods:

三つの手法
----------

三つの方法は、機体のまわりの流れをどこまで物理方程式で解くかが違う。
部品積み上げ法は流れを解かず、部品ごとの経験式と細長体理論の和で係数を作る。
パネル法は機体の表面だけで流れを解き、CFD は機体のまわりの空間全体で解く。
解く範囲が広いほど干渉や衝撃波が自然に入るが、計算の時間と準備が増える。
外部の表は、これらの代わりに実験などで得た係数をそのまま与える。

部品積み上げ法（``method = "barrowman"``、既定、:doc:`barrowman`）
   機体をノーズ・胴体・フィン・ボートテールといった部品に分ける。部品ごとの法線力と圧力中心を細長体理論や経験式で求め、\ :eq:`eq-cp-sum` で足し合わせる :cite:`barrowman,niskanen`\ 。
   抗力も部品ごとの経験式の和である。計算は一瞬で終わり、経験式の範囲内では安定した値を返す。
   一方で、使うのは抽出した寸法（半径分布とフィンの平面形）だけで、表面の形そのものは使わない。フィンと胴体の干渉は一つの係数で表す。

パネル法（``method = "panel"``、:doc:`panel`）
   抽出した形状から閉じた表面メッシュを作り、その上で流れを解く。
   亜音速では、非粘性・渦なしのポテンシャル流を Morino の定式化 :cite:`morino` で解き、Göthert の変換 :cite:`gothert` で圧縮性を入れる。
   超音速では、各パネルの傾きから圧力を決める局所傾斜法を使う。
   フィンと胴体の干渉やノーズの形は、表面の形から自然に入る。粘性は扱わず、遷音速は両側の値の補間である。

CFD（``method = "cfd"``、:doc:`cfd`、:doc:`cfd_internals`）
   機体のまわりの空間を体積メッシュで覆い、圧縮性 Euler 方程式（または RANS 方程式）を外部プログラムの SU2 :cite:`su2` で解く。
   衝撃波や遷音速の流れ、フィンと胴体の干渉を、物理方程式から直接得られる。
   形状は、抽出した寸法から作り直すか、STL をそのまま使う（重なった殻は manifold3d で和にする）。
   全領域で横滑りとロールのケースも解き、6 成分の一般表を作れる。
   ただし、1 ケースに数十秒から数分かかる（表全体はケース数に比例する）。SU2・gmsh・Open MPI（STL ではさらに manifold3d）の準備も要る。
   Euler では、摩擦抗力や底面抗力を部品積み上げ法の項で補う。RANS では、壁面にプリズムの境界層を置いたメッシュで摩擦抗力も解く（作り直した形状だけ）。

外部の表（``method = "table"``）
   風洞試験などで得た係数表を読み込む。形状の抽出と空力モデルの計算は行わない（:ref:`sec-aero-external`）。

三つの手法の違いを :numref:`tbl-aero-methods` にまとめる。計算時間は桁の目安で、「表全体」と「1 ケース」を区別して書く。
計算時間とセル数は :ref:`sec-vaero-timing` にある。

.. _sec-aero-table:

軸対称表と一般表
----------------

係数表には、軸対称表と一般表の 2 種類がある。
軸対称表は、機体が軸対称であることを前提に、Mach 数と全迎角 :math:`\alpha_t` だけで係数を引く表である。
一般表は、機体座標の 6 成分の力とモーメントを、Mach 数・迎角 :math:`\alpha`・横滑り角 :math:`\beta` の関数として持つ。
一般表は 6 成分の準定常空力（:math:`C_X,C_Y,C_Z,C_l,C_m,C_n` を :math:`(M,\alpha,\beta)` の関数として持つ）であり、
角速度によるモーメントの変化は、減衰の項で別に加える。非定常な空力をすべて表すものではない。
どちらの表を使うかは、設定 ``aero.table_kind``\ （既定は ``"axisymmetric"``）で選ぶ（:numref:`fig-aero-tables`）。

.. _fig-aero-tables:

.. figure:: _generated/tikz/aero_tables.*
   :width: 100%

   軸対称表（左）と一般表（右）。部品積み上げ法とパネル法の一般表は、軸対称表を展開して作る。

軸対称表は、既定では Mach 数 0 から 3、全迎角 0 から 90° の格子を持つ。
全迎角が機体の軸からのずれの大きさだけを表すので、機体が軸対称なら十分である。
飛翔計算では、全迎角に対して :math:`\alpha_t'=\min(\alpha_t,\pi-\alpha_t)`、つまり 0 から 90° の範囲で表を引く。
既定の ``alpha_max_deg = 90`` で、頂点のあとの弾道落下で現れる大きな迎角（機体が横向きになる 90° 近く）も表の範囲に収まる。
``alpha_max_deg`` を 90 より小さくした表でその範囲を超えて引くと、結果を使えないものとして終了ステータス 3 で終わる（:ref:`sec-aero-interp`）。
後ろ向きに飛ぶ（:math:`\alpha_t>90^\circ`）ときは、前向きの係数を引いて軸力の向きを反転する（:ref:`sec-aero-forces`）。

一般表は、迎角 :math:`-180^\circ` から :math:`180^\circ`、横滑り角 :math:`-90^\circ` から :math:`90^\circ` の全範囲を格子で覆う。
後ろ向きの飛行も表の一部として持つ。部品積み上げ法とパネル法は軸対称な機体の係数しか出さないので、一般表はそれを展開して作る。
全迎角は :math:`\cos\alpha_t=\cos\alpha\cos\beta`\ （:ref:`sec-aero-angles`）から求め、軸対称表を :math:`\alpha_t'` で引いて、
:eq:`eq-coeff-6-axisym` で 6 係数にする。
したがって、展開した表の飛翔は軸対称表の飛翔とほぼ一致する。展開した表は軸対称な機体以上の情報を持たない。
非対称な機体の係数は、CFD の一般表（:doc:`cfd`）か外部の一般表から与える。
一般表の Mach 数の刻みは、設定 ``aero.general_mach_step``\ （既定 0.05）が決める。この設定が効くのは、部品積み上げ法で一般表にするときだけである。
パネル法と外部の表は、それぞれ軸対称表の刻みで展開する。CFD の一般表は、``aero.cfd.general_mach_step``\ （既定 0.1、0 のとき ``aero.mach_step``）で決める。
軸対称表の :math:`\alpha_t'` と :math:`C_N,x_{cp}` の関係、6 成分の定義は :doc:`aero_coefficients` で述べる。

表のファイル（CSV と、同名で拡張子が ``.json`` の付随ファイル）の列、付随ファイルの項目、バージョンは :ref:`sec-aero-table-format` に書いてある。
軸対称表の CSV の ``alpha_deg`` は :math:`\alpha_t`、一般表では :math:`\alpha` である。

カントの基準
~~~~~~~~~~~~

フィンにカントがあると、ロールのモーメントが生じる。表のロールの強制項が、どのカントの値で作られているかを、付随ファイルの ``fin_cant_ref_deg``\ （:math:`\delta_{\mathrm{ref}}`、既定は 0）に書く。
飛翔計算は、設定したカント :math:`\delta` が :math:`\delta_{\mathrm{ref}}` と違うときだけ、その差の分を足す。式は :eq:`eq-cl-total` である（:ref:`sec-roll-moment`）。
部品積み上げ法とパネル法は設定したカントで表を作るので :math:`\delta_{\mathrm{ref}}=\delta` で、強制項を二重に数えることはない。

.. _sec-aero-interp:

係数表の内挿と外挿
------------------

飛翔計算は、飛翔中の条件が表の格子点の間に入ったとき、近くの格子点の値から重み付きの和で係数を求める。
軸対称表は :math:`(M,\alpha_t)` の二次元、一般表は :math:`(M,\alpha,\beta)` の三次元の線形内挿で、軸が不等間隔でも使える。
格子の範囲の外では、迎角と横滑り角は端の区間の傾きをそのまま延ばす線形外挿が既定で、端の値で一定とすることもできる。
Mach 数は、設定にかかわらず、表の端の値で一定とする。

双線形内挿
~~~~~~~~~~

軸対称表の飛翔中の :math:`(M,\alpha_t)` が格子の区間 :math:`[M_i,M_{i+1}]\times[\alpha_j,\alpha_{j+1}]` にあるとき（:numref:`fig-table-interp`）、

.. math::

   t_M = \frac{M-M_i}{M_{i+1}-M_i},\qquad t_\alpha=\frac{\alpha-\alpha_j}{\alpha_{j+1}-\alpha_j}

として、四隅の値 :math:`c_{00},c_{10},c_{01},c_{11}` から

.. math::
   :label: eq-bilinear

   c(M,\alpha) = (1-t_M)(1-t_\alpha)\,c_{00} + t_M(1-t_\alpha)\,c_{10} + (1-t_M)\,t_\alpha\,c_{01} + t_M\,t_\alpha\,c_{11}

を求める。

圧力中心 :math:`x_{cp}` は、それ自体を内挿しない。法線力 :math:`C_N` と、ノーズ先端まわりのモーメント :math:`C_Nx_{cp}` をそれぞれ :eq:`eq-bilinear` で内挿し、

.. math::
   :label: eq-xcp-interp

   x_{cp}(M,\alpha)=\frac{\bigl(C_Nx_{cp}\bigr)(M,\alpha)}{C_N(M,\alpha)}

とする。飛翔に効くモーメント :math:`C_Nx_{cp}` は内挿したモーメントそのものになり、同じ格子に展開した一般表（:math:`C_Z` と :math:`C_m` を別々に内挿する）と一致する。
内挿した :math:`C_N` が 0 のとき（迎角 0）は、迎角 0 の傾きについて同じ比 :math:`\bigl(C_{N\alpha}x_{cp}\bigr)/C_{N\alpha}` を使い、:math:`C_{N\alpha}` も 0 なら表の :math:`x_{cp}` をそのまま内挿する。

   :width: 70%

   係数表の双線形内挿と、範囲外の扱い。迎角（一般表では横滑り角も）の範囲外は端の区間の線形外挿で、Mach 数は範囲外でも表の端の値にクランプし、外挿しない。

三線形内挿
~~~~~~~~~~

一般表は、:math:`(M,\alpha,\beta)` が入る格子の直方体の 8 隅の値から三線形内挿で求める。
:math:`\beta` 方向の分率を :math:`t_\beta` として、\ :eq:`eq-bilinear` の :math:`c_{00},\dots,c_{11}` を :math:`\beta_k` と :math:`\beta_{k+1}` の値の線形内挿
:math:`(1-t_\beta)c_{ij}^{(k)}+t_\beta c_{ij}^{(k+1)}` に置き換えればよい。
区間は軸が不等間隔でも、軸の値の並びから探す。

外挿
~~~~

**Mach 数** は、設定にかかわらず、表の最小値より小さいときは最小値の、最大値より大きいときは最大値の係数を使う（端の値で一定）。
遷音速や超音速の係数の傾向は、表の範囲の外で直線的には続かないので、Mach 数の方向には外挿しない。
端の値で一定とした係数は飛翔の Mach 数の係数ではないので、範囲外の引き出しがあった飛翔の結果は使えないものとする（下記）。

**迎角と横滑り角** が表の格子の外にあるときは、設定 ``extrapolation`` に従う。
CFD の表の、解いた迎角より大きい行は、この外挿ではなく部品積み上げ法へのつなぎで埋める（:ref:`sec-cfd-table-build`）。``extrapolation`` が効くのは、表の格子の外の引き出しだけである。
``"linear"`` は、最も近い端の区間を使い、:math:`t_\alpha` が :math:`[0,1]` を外れたまま :eq:`eq-bilinear` を評価する（端の区間の傾きをそのまま延長する **線形外挿**）。
``"clamp"`` は :math:`t_\alpha` を :math:`[0,1]` に制限し、端の値で一定とする。
下降中の機体は大きな迎角をとるので、既定は ``"linear"`` である。

線形外挿した値は、物理的に妥当な符号と範囲に制限する。端の値（外挿しない値）を基準に、次のとおりとする。

* 法線力係数 :math:`C_N`、ノーズ先端まわりのモーメント :math:`C_Nx_{cp}`、迎角 0 のモーメントの傾き :math:`C_{N\alpha}x_{cp}`、軸力係数 :math:`C_A`\ （推力あり・なし）、ロールの強制項 :math:`C_{l\delta}` は、端の値の符号を保つ（符号が反転する分は 0 にする）。
* 法線力係数の傾き :math:`C_{N\alpha}` と、ピッチ減衰の三つの和は 0 以上とする。
* 外挿した値から :eq:`eq-xcp-interp` で求めた圧力中心 :math:`x_{cp}` は、機体の内側（ノーズ先端から全長まで）に収める。
* ロール減衰 :math:`C_{lp}` は、外挿の有無にかかわらず、正にしない（0 以下）。

一般表では、端の値の符号を保つ規則を、軸力、横力 :math:`C_Y`、法線方向の力 :math:`C_Z`、モーメント :math:`C_m` と :math:`C_n`、ロールの強制項（基準のカント角での :math:`C_l` と :math:`C_{l\delta}`）、減衰の和（ピッチとヨーの各 3 個）に適用し、減衰の和は 0 以上とする。端に向かって小さくなる横方向の力とモーメントを外挿しても、符号が反転しない。:math:`C_{lp}` は 0 以下に制限する。
:math:`\alpha,\beta` の軸が全範囲を覆うので、一般表で外挿が起こるのは、表の軸が全範囲に満たないときだけである。

表の範囲外の引き出しは、数えている。数えるのは、全引き出しの回数、Mach 数が最小値未満・最大値超の回数、迎角または横滑り角が格子の外（最後の格子点より大きい側と、最初の格子点より小さい側の両方。格子点が 1 つの軸ではその値以外）の回数、要求された最大の Mach 数と最大の迎角である。
最大の迎角は、軸対称表では引いた全迎角、一般表では :math:`\alpha` と :math:`\beta` から求めた全迎角 :math:`\arccos(\cos\alpha\cos\beta)` で、ピッチ面の迎角だけではない
（``AeroTable::out_of_range_stats``）。
Mach 数の範囲外の引き出しは、結果を使えないものとする。表が飛翔の Mach 数より手前で終わると、端の値で一定とした係数で上昇全体の抗力と安定が変わるからである。
1 回でもあれば ``sim`` と ``dispersion`` は ``RESULTS NOT USABLE: N of M lookups beyond the aero table's Mach range (max Mach … > mach_max …): coefficients are held at the edge; build the table up to at least Mach …`` の行を書いて終了ステータス 3 で終わり、``aero_table_range`` の ``machs_in_range`` を ``false`` にする（:ref:`sec-exit-status`）。
迎角（一般表では迎角または横滑り角）の範囲外の引き出しも、警告ではなく、結果を使えないものとする。
端の区間からの外挿は、表にない大きな迎角の係数を端の区間の傾きから作るので、圧力中心を重心より前へ動かして見かけの釣り合い（トリム）を作るなど、弾道落下の経路を変えうる。外挿の結果が表の範囲内の結果に近いかどうかは、機体と条件によって決まり、事前には分からない（サンプルの例は :ref:`sec-exit-status`）。
そのため、1 回でもあれば ``sim`` と ``dispersion`` は ``RESULTS NOT USABLE: … lookups beyond the aero table's angle range (max |alpha| … deg > alpha_max … deg): the descent uses extrapolated coefficients; build the table up to 90 deg`` の行を書いて終了ステータス 3 で終わり、``aero_table_range`` の ``angles_in_range`` を ``false`` にする。
表の上限を 90° 以上にして作り直せば、軸対称表では範囲外の引き出しは起きない（飛翔計算は全迎角を :math:`90^\circ` 以下に折り返して引く）。
範囲外の引き出しがなくても、``summary.json``、``dispersion_meta.json``、``dispersion_summary.json`` の ``aero_table_range`` に、全引き出しの回数などを記録する（:ref:`sec-file-summary`）。

.. _sec-aero-external:

外部の係数表
------------

風洞試験や他の解析で得た係数は、``aero.method = "table"`` で読み込める。
形状の抽出と空力モデルの計算は行わず、``sim`` と ``dispersion`` は読み込んだ表をそのまま使う。
表の形式は、このソフトが書く ``aero_table.csv`` と同じである（列と付随ファイルの項目は :ref:`sec-aero-table-format`）。
軸対称な外部の表を ``table_kind = "general"`` で一般表に展開することも、外部の表がすでに一般表ならそのまま使うこともできる。

表のロール項（:math:`C_{l\delta}` と :math:`C_{lp}`）がすべて 0 のときは、現在の STL から抽出したフィンの寸法で部品積み上げ法のロール項を求めて表に書き込む
（:ref:`sec-barrowman-roll`）。このとき端末に注意書きを表示する。形状を抽出できなければ、注意書きを表示してロール項は 0 のままになり、機体はロールしない。
フィンがなければ書き込む値も 0 である。ロール項を含む表は、そのまま使う。

確認済み
--------

* 展開した一般表の飛翔が、軸対称表の飛翔とほぼ一致することを確かめた。
* 係数表の読み込みと内挿・外挿は、軸対称表と一般表の両方で確かめた。
* 三つの手法の係数を同じ機体で比べ、差の傾向を確かめた（相互比較であり、実測との比較ではない）。

結果は :doc:`verification_aero` に、手法どうしの比較は :ref:`sec-vaero-compare` にまとめる。

注意
----

* 実測（風洞試験・飛翔試験）との比較は行っていない。どの手法も、実機の係数の保証ではない。
* 遷音速の係数は、部品積み上げ法とパネル法では補間値である。
* 展開した一般表は、非対称な機体の係数を含まない。
* 一般表は 6 成分の準定常空力であり、完全な非定常空力ではない。

詳しくは :ref:`sec-lim-aero` を参照。
