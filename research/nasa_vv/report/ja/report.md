# NASA の検証と妥当性確認の手順を IgnisYeet の空力計算に適用する

NASA Glenn の WIND/NPARC チームが公開する検証と妥当性確認の手順（AIAA G-077-1998 に沿う）を、IgnisYeet の空力計算に当てはめた結果を述べる。

## 要旨 {#summary}

この報告は、NASA のチュートリアルの六つの段階を IgnisYeet の SU2 による空力計算に当てはめ、結果を、それを支える強さのまま述べる。確定していることは次のとおりである。

- **空力係数に付けられた数値不確かさの帯は、ごく限られる。** サンプル機体の Euler で計算できた GCI は、M = 2 の CNα の 10.6 %（節点数）と 16.3 %（壁寸法、漸近域の外）だけである。次数は 0.533 と 0.199 で、2 次精度の理論値 2 よりはるかに低く、h の定義で値が大きく動く。サンプル機体の他の量は、振動、収束しない、使えない GCI のいずれかである。Basic Finner の Euler の 4 段の格子は、信頼できる GCI を与えない。Basic Finner の RANS（M = 1.832）の GCI は得られず、α = 2° の解が 3 段すべてで未収束である。
- **GCI は、真の誤差を押さえないことがある。** 厳密解がある層 0 で、GCI を求めた 12 行のうち 5 行が最細格子の真の誤差を押さえなかった。押さえなかった 2 行（円すいの Cp）を、次数の検査は 2 行とも見つけず、窓の安定性は 1 行しか見つけなかった。厳密解のない層 2 の GCI も、同じように誤差を過小評価しうる。
- **製品の格子は、相似に細かくならない。** 壁とフィンのセル寸法を変えても外側の寸法は固定され、セル数は相似な細分（2.74 倍）に届かない（サンプル機体で 1.74 倍と 1.77 倍）。GCI は h の二つの定義で求め、二つは問いを挟むだけである。
- **層 1。** 製品の鎖で解いた円すいの最細格子は未収束で、層 1 の GCI も、3 次元非構造格子の生成を含むパイプラインの誤差の寄与も、得られていない。
- **一貫性。** サンプル機体の既定のメッシュの CN(0) = 0 は、メッシュの対称性により満たされ、ソルバを確かめない。z 鏡映のないメッシュは、偽の法線力を持つ。M = 0.3 の |CA| は格子とともに縮むが、0 に収束することは示していない。
- **反復誤差。** 同じ格子の同じ量で、反復誤差が GCI を上回った行はない。
- **時間収束。** CFD は定常なので当てはまらない。6 自由度の積分器のサンプルでは観測次数が得られず、次数 4 は制御の実験でだけ観測された。
- **妥当性確認。** Euler の CNα は、実測より 2.9 から 10.5 % 低く、どの Mach 数でも差が確率誤差を上回る。Mach 2.375 では、この差は観測した格子の感度では説明できない。RANS の CNα（Mach 1.832）は確率誤差の内にあるが、RANS には数値不確かさの帯がない。CX0 は CFD に帯がなく、判断できない。
- **製品についての所見。** 公表された RANS の格子収束（V6）の M = 0.8 の GCI は、未収束の解を使って求められている。製品が書く表面の出力ファイルは、停止時に切れることがある。RANS の Basic Finner は、フィンのセル寸法を小さくすると、gmsh が異常終了して止まる。

## 1. 目的と読み方 {#s1}

### 1.1 目的 {#s1-1}

空力係数に数値不確かさの帯を付け、その帯を実測の誤差と並べて示すことが目的である。帯のない比較は、数値の差と実測の差のどちらが大きいかを決められない。

### 1.2 六つの段階 {#s1-2}

NASA のチュートリアルは、次の六つの段階を順に踏むことを求める。この報告は、各段階の結果か、その段階が当てはまらない理由を述べる。

| 段階 | 問い | 節 |
|---|---|---|
| 1. プログラムの点検 | プログラムそのものが、式どおりに動くか | [4.1](#s4-1) |
| 2. 反復収束 | 反復の打ち切りによる誤差は十分小さいか | [4.2](#s4-2) |
| 3. 一貫性 | 物理が要求する関係が、計算結果で成り立つか | [4.3](#s4-3) |
| 4. 空間（格子）収束 | 格子を細かくすると、解は収束するか。その不確かさは | [4.4](#s4-4) |
| 5. 時間収束 | 時間刻みを小さくすると、解は収束するか | [4.5](#s4-5) |
| 6. 検証と妥当性確認 | 高精度解、ほかのモデル、実測と比べて、どれだけ合うか | [4.6](#s4-6) |

### 1.3 用語 {#s1-3}

次の三つを別の名前で呼び、混ぜない。

| 名前 | 意味 | 比較の相手 |
|---|---|---|
| 検証（verification） | 式を正しく解いているか。格子や時間刻みの収束の調査を含む | 厳密解、高精度解、格子の列 |
| 相互比較（cross-comparison） | 手法やプログラムの差 | 別の手法、別のプログラム、別のモデル |
| 妥当性確認（validation） | 実機に近いか | 実測値 |

Euler と RANS の比較や、他のプログラムの結果との比較は相互比較であり、妥当性確認ではない。妥当性確認にあたるのは、Basic Finner を DREV-TM-9703 の実測値と比べる [4.6.2 節](#s4-6-2)だけである。

### 1.4 三つの層 {#s1-4}

| 層 | 実行するもの | 確かめる対象 | 格子 |
|---|---|---|---|
| 0 | SU2 8.3.0 を IgnisYeet の数値設定で直接実行 | ソルバと数値設定 | 2 次元と軸対称の構造格子 |
| 1 | IgnisYeet の鎖（CAD、gmsh、SU2、係数抽出）全体 | 鎖の全体 | 3 次元の非構造格子（半モデル） |
| 2 | サンプル機体と Basic Finner に、六つの段階を適用 | 実用条件での誤差と、実測との差 | 3 次元の非構造格子（半モデル） |

IgnisYeet の鎖が扱えるのは CAD または STL のロケット形状だけで、平板やくさびは作れない。層 0 はそのために SU2 を直接動かす。したがって層 0 が検証するのは、ソルバと数値設定であり、IgnisYeet のパイプラインではない。

層 0 と層 1 は、同じ厳密解（半頂角 10° の円すいの Taylor–Maccoll 解）を使う。両者の差は、**パイプラインの誤差（3 次元の非構造メッシュ生成を含む）** を表す。メッシュ生成の誤差だけを切り出したものではない。

### 1.5 不確かさの求め方 {#s1-5}

不確かさは、3 段の格子の解から Richardson 外挿と格子収束指標（GCI）で求める。最も細かい格子の値を f₁、次を f₂、最も粗い格子の値を f₃ とする。安全率は 1.25 である。

- 細分比 r が一定の格子（層 0。r = 2）には、チュートリアルの式を使う。観測次数は p = ln((f₃ − f₂)/(f₂ − f₁))/ln r、GCI は 1.25 |ε|/(r<sup>p</sup> − 1) である。ε は f₂ と f₁ の相対差である。
- 細分比が一定でない格子（層 1 と層 2）には、Celik ら（2008）の反復解法を使う。
- 代表格子寸法 h は、3 次元の非構造格子では節点数 N から N<sup>−1/3</sup>、2 次元の構造格子ではセル数から（セル数）<sup>−1/2</sup> とする。

GCI を求める前に、各格子の解に次の入口の条件を課す。

- 解が収束していること。ソルバが収束と判定したか、残差が 3 桁以上落ちていること。製品の「早期終了（accepted）」の解は、判定を主張せず、残差の落ち幅で決める。この条件を満たさない格子を含む列は、GCI を求めず、理由を書く。
- 3 段の差が単調であること。差が符号を変える振動収束では、極限へ単調に近づくという外挿の前提がデータと合わない。この場合は次数も GCI も帯も付けない。Celik らの論文には振動収束の計算法があるが、この研究は採らない。細かい側の 2 段の差が粗い側の 2 段の差以上に大きい場合も、収束していないとして帯を付けない。
- 観測次数が 0.5 から 4 の間にあること。2 次精度の方法の理論値 2 の 1/4 を下回るか 2 倍を上回る次数は、漸近域にないしるしであり、その GCI は信頼できないと注記する。

数値の後ろに付けた `…csv` は、その数値を読んだ結果の表である（付録 A）。

## 2. 層 0：SU2 を厳密解で検証する {#s2}

### 2.1 算例と設定 {#s2-1}

| 算例 | Mach 数 | 厳密解 | 比べた量 |
|---|---|---|---|
| 15° のくさび | 2.5 | 斜め衝撃波の θ–β–M 関係式 | 壁面の p/p∞、衝撃波角 |
| 半頂角 10° の円すい（軸対称） | 2.35 | Taylor–Maccoll | 壁面の Cp、壁面の Mach 数 |
| 15° の膨張 | 2.5 | Prandtl–Meyer | 壁面の p/p∞、壁面の Mach 数 |
| 層流平板 | 0.2 | Blasius | Cf、速度分布から求めた排除厚さと運動量厚さ |
| 乱流平板（SA） | 0.2 と 2 | 格子収束だけを調べた | Cf |

くさび、円すい、膨張の 3 算例には、点数が方向ごとにちょうど 2 倍ずつ違う 3 段の入れ子の構造格子（65×49、129×97、257×193 節点）を使う。粗い格子の節点がすべて細かい格子の節点になるので、細分比はちょうど 2 である（`layer0.csv`）。入口、出口、上の境界は遠方境界（超音速の流入と流出）で、下の境界を Euler 壁とした。波はすべて出口から出る。上の境界の |p/p∞ − 1| の最大は 7.3×10⁻¹⁰ だった（12 回の計算のすべてで確認。`layer0.csv`）。

数値設定は、`ignisyeet aero` が書いた Euler の設定ファイルから写した。対流項の離散化、2 次精度の再構成、制限関数、勾配の求め方、CFL、線型ソルバ、打ち切りの条件、気体のモデルは、試験でその設定ファイルと一致することを確かめている。層 0 の設定が製品の設定と違うのは、次の点だけである。

- 境界の割り当て（遠方境界、壁、軸）と、円すいの `AXISYMMETRIC`。
- 出力ファイルの種類。解を文書として読むために、再開ファイルを文字形式にし、表面の出力を加えた。
- 反復の打ち切り。製品の設定にある残差の目標（密度の残差の対数が −14）はそのまま使い、反復回数の上限を 20000 回とした。製品の実行制御（ケースごとの収束の判定）は層 0 にはない。
- 質量流束を調べた計算では、各境界の質量流束を履歴に出力する。

12 回の計算（円すいは軸の境界の割り当てを変えた 2 通りを含む）はすべて、残差の目標に達して止まった。残差の落ち幅は 12.7 から 13.9 桁、反復回数は 132 から 230 回である（`layer0.csv`）。

### 2.2 円すいの参照値：NPARC の表の不整合 {#s2-2}

NPARC の検証アーカイブにある円すいの算例（cone10、M = 2.35、半頂角 10°）の表は、この研究の Taylor–Maccoll の解と、Mach 数 M₃ を除いて合わない。

| 量 | NPARC の表 | Taylor–Maccoll | 差（%） |
|---|---|---|---|
| 衝撃波角 β [°] | 27.1843 | 26.7367 | −1.646 |
| 円すい表面の Mach 数 M₃ | 2.1469 | 2.14683 | −0.0032 |
| p₃/p∞ | 1.4234 | 1.37394 | −3.475 |
| T₃/T∞ | 1.1063 | 1.09508 | −1.014 |
| ρ₃/ρ∞ | 1.2867 | 1.25464 | −2.491 |

出典：`cone10_reference_check.csv`。差は（Taylor–Maccoll − NPARC）/ NPARC である。

M₃ だけが 4 桁まで合う。同じ表の T₃/T∞ は、M₃ とも合わない。衝撃波の前後で全温は変わらないので、T₃/T∞ = (1 + 0.2 M∞²)/(1 + 0.2 M₃²) が成り立つ。M₃ = 2.1469 からは 1.0950 が、表の T₃/T∞ = 1.1063 からは M₃ = 2.124 が出る。表の中の値どうしが食い違っている。

どちらの衝撃波角が正しいかを、この研究のコードに頼らずに確かめた。

| 資料 | 衝撃波角 [°] | 半幅 [°] | 読み方 |
|---|---|---|---|
| Sims, NASA SP-3004 (1964), Table 11 | 26.7366 | 0.02 | 表の値を M = 1.75〜3.5 から 1/M の 4 次 Lagrange 補間 |
| NACA Report 1135 (1953), Chart 5 | 26.80 | 0.15 | 図を画素で読み、1/M の 3 次補間（γ = 1.405 の図） |
| パネル法の Taylor–Maccoll（別の実装） | 26.7367 | 0.001 | 衝撃波角を二分法で求めた |
| この研究の実装 | 26.7367 | — | 射撃法 |
| NPARC cone10 | 27.1843 | — | 表の文字 |

出典：`cone_shock_angle_sources.csv`。

Sims の表の 10° の列は、補間なしに、M = 2.0 の値 0.54464827 rad を与える。この研究の実装は、この表の格子点（M = 2.0）で、補間をせずにこの値に合う。NACA の図の読みには、表で校正した約 +0.07° の読みの偏りがある。補間と読みの誤差を含めても、27.18° を支持する資料はない。

この確認の強さには限りがある。Sims の表と NACA の図は、データと実装は独立だが、同じ Taylor–Maccoll の方程式を同じ理想気体のモデルで解いたものである。パネル法の実装も同じ理論である。ここで言えるのは、NPARC の表が、同じ理論の他の三つの値と合わないことであり、理論そのものの誤りは検出できない。

この結果として、NPARC cone10 の β、p₃/p∞、T₃/T∞、ρ₃/ρ∞ は、どの試験の目標値にも使わない。円すいの比較は、M₃ と Cp に限る。

読み取れることは次のとおりである。

- **くさびの誤差は、格子を 2 倍に細かくするたびにほぼ半分になる**（誤差の比 1.95 と 2.17）。壁面圧力の次数は、壁の窓を動かしても 0.84 から 1.04 の範囲にとどまる。壁面圧力の誤差は、衝撃波の背後の離散化誤差と読めるが、誤差が純粋な冪乗則に従わないので、次数は 1 を下回る。衝撃波角の誤差は、捕獲した衝撃波の位置の誤差（数セルにまたがる）と整合する。当てはめた衝撃波の直線が前縁（x = 0）で y = 0 からずれる量が、格子とともに小さくなる。どちらも原因を分離する試験はしていない。衝撃波角の誤差は、最細格子で 0.0138° である。
- **円すいの最細格子の誤差は、壁面 Cp で −0.19 %、壁面 Mach 数で −0.80 % である。** 円すいの軸を対称境界にして、先端の節点を軸と円すいの 2 つの境界が共有する設定にすると、誤差は壁面 Cp で −0.75 %、壁面 Mach 数で −2.98 % になる。軸と円すい表面を一つの Euler 壁にすると、先端の節点は正則になる（M = 2.23、p/p∞ = 1.17）。対称境界を使う設定では、先端の節点が停滞点（u = v = 0、M = 0、p/p∞ = 2.76）になり、これは 3 段の格子で同じである。境界の割り当てだけを変えて消える差なので、原因は接合点の扱いである。2 つの境界の法線速度の拘束が合わさって速度を 0 にする、という機構を考えた。この機構は、拘束が 1 つだけになる設定（軸と円すい表面を一つの境界にする）で先端が正則になるはずだ、という予測として試験し、予測は成り立った。ほかの説明を排除する試験まではしていない。層 0 の円すいの結果には、一つの Euler 壁の設定を使い、対称境界の設定は、先端の影響を示す感度の記録として残す。
- **膨張の壁面 Mach 数は、格子を細かくしても厳密解に近づかない。** 3 段の誤差は −3.57、−3.56、−3.55 % で、次数も GCI もない。壁面圧力の誤差は 0.0097 % で、影響を受けない。次節で述べる。

### 2.4 壁面のエントロピーと接合点 {#s2-4}

壁面の節点は、くさび、円すい、膨張のどれでも、厳密解より大きなエントロピーを持つ。上流の壁では s/s∞ が 1 に一致し、壁から 10 行離れた位置では厳密解の値に一致する。

| 算例 | 厳密解 | 壁面（粗、中、細） | 壁から 10 行離れた位置（粗、中、細） |
|---|---|---|---|
| くさび | 1.0299 | 1.0583、1.0581、1.0580 | 1.0261、1.0302、1.0302 |
| 膨張 | 1 | 1.0785、1.0784、1.0783 | 1.0013、1.0015、1.0015 |
| 円すい（一つの Euler 壁） | 1.0001 | 1.0376、1.0199、1.0107 | 1.0002、1.0003、1.0003 |

出典：`layer0.csv`。

くさびと膨張の壁面の偏りは、3 段の格子で変わらない（くさびで約 2.7 %、膨張で約 7.8 %）。円すいの偏りは、格子とともに小さくなるが、細格子でも 0 にならない。これは、角や先端で生じたエントロピーが壁面の流線に沿って流れてくることと整合する。ただし、これは解釈であり、証明ではない。くさびの前縁も一つの角である。

膨張の壁面 Mach 数が収束しない理由は、この偏りが 3 段の格子で一定だからである。膨張の壁から 3 行離れた位置でも Mach 数は厳密解より低く、壁面の層は 3 行より厚いか、ほかの原因も働いている。

製品への意味は、次のとおりである。Euler の力は壁面の圧力の積分なので、この偏りは力に直接は入らない。壁面の Mach 数、密度、温度から作る量には入りうる。層 0 は 2 次元と軸対称の構造格子であり、製品の 3 次元の非構造格子が同じ影響を受けるかどうかは、層 0 からは分からない。

もう一つの観察を、問いとして残す。膨張の下の境界を角の位置で 2 つの Euler 境界に分けると、角の節点が停滞点（u = v = 0、p/p∞ = 3）になり、密度の残差は 20000 回の反復で約 −1.5（対数）に留まった。一つの境界にすると収束する。製品のメッシュにも境界の接合点（壁と底面など）があるが、3 次元の非構造格子であり、層 0 からは製品が同じ影響を受けるかどうかは分からない。この点は試験していない。

### 2.5 GCI は真の誤差を押さえたか {#s2-5}

厳密解が分かるのは、層 0 と層 1 だけである。層 0 では、GCI が最細格子の真の誤差を押さえたかどうかを、直接確かめられる。GCI の役目は、真の誤差を押さえることである。

結果は、**GCI を求めた 12 行のうち、7 行で押さえ、5 行で押さえなかった** である（`layer0_gci.csv`）。内訳は、くさび、円すい、膨張の 7 行で 5 行が押さえ、2 行が押さえなかった。層流平板の 5 行（[2.6 節](#s2-6)）で 2 行が押さえ、3 行が押さえなかった。平板の 2 行は、誤差の符号が入れ替わる点でだけ押さえており（後述）、平板の 5 行は互いに独立ではない（排除厚さと運動量厚さが、補正の有無で 2 回ずつ入る）。この 12 行は、独立な検査の数ではない。

押さえなかったのは、円すいの壁面 Cp（GCI 0.059 % に対し真の誤差 0.19 %。約 3 倍の過小評価）と、軸を対称境界にした円すいの壁面 Cp（0.708 % に対し 0.748 %）である。

「押さえた」ことは、見積もりが締まっていることを意味しない。膨張の壁面圧力の GCI は真の誤差の約 8 倍、円すいの壁面 Mach 数は約 3 倍、軸を対称境界にした円すいの壁面 Mach 数は約 1.5 倍である。

層 2 の問題は、厳密解がないところで、この過小評価を見つけられるかである。層 0 の 7 行で、見つける手段を比べた。

|---|---|---|---|

- 窓の安定性は、円すいの壁面 Cp を見つけ、軸を対称境界にした円すいの壁面 Cp を見つけない。
- 厳密解との比較は 2 行とも見つけるが、層 2 では使えない。

したがって層 2 では、使える二つの検査のどちらも十分ではない。**次数がもっともらしく、窓も安定していても、GCI が真の誤差を過小評価することがある。** 窓の安定性は、GCI が離散化誤差を見積もるための必要条件であって、十分条件ではない。

### 2.6 層流平板（Blasius） {#s2-6}

#### 設定 {#s2-6-1}

M = 0.2、単位長さあたりの Reynolds 数 10⁵ の平板で、Blasius 解と比べた。格子は 85×49、169×97、337×193 節点（セル数で 84×48、168×96、336×192）の入れ子で、細分比は 2 である。x = 0.5 の第 1 節点の高さを y⁺ にすると 0.975、0.471、0.232 で、境界層（u/U ≦ 0.99）の内側に 14、27、54 節点が入る。壁は断熱の滑りなしの条件である（`layer0_plate.csv`）。

**IgnisYeet には層流のモードがない**（流れのモデルは Euler と RANS の 2 つだけである）。この計算は、製品の RANS の離散化と気体のモデルを使い、乱流モデルだけを外して Navier–Stokes を解く。したがって検証しているのは、乱流モデルを切った RANS の離散化であり、製品が書く設定ではない。

製品は 1 次精度の立ち上げの段階を経てから 2 次精度に進むが、この計算は 2 次精度で冷たい状態から始めた。定常解が経路に依存しないことは、**試験していない。** 3 段の計算はすべて残差の目標に達し、落ち幅は 9.4 から 10.4 桁である。

## 3. 層 1：円すいを製品の鎖で解く {#s3}

### 3.1 設定 {#s3-1}

半頂角 10°、底面半径 0.05 m の円すい-円筒（円すいの長さ L = 0.28356 m）を、M = 2.35、迎え角 0 の Euler で、IgnisYeet の鎖（CAD 形状、gmsh、SU2、係数の抽出）の全体を通して解いた。メッシュは 3 次元の非構造格子（四面体、半モデル）である（`layer1_cone.csv`）。層 0 と同じ厳密解（Taylor–Maccoll）と比べる。厳密解との比較は検証であり、層 0 と層 1 を互いに比べるのは、二つのモデルの相互比較である。

格子は 3 段で、壁のセル寸法は 3.92 mm、2.8 mm、2 mm（比 1.4）、節点数は 28887、45258、75796、セル数は 132328、209052、350868 である。セル数は 1.58 倍と 1.68 倍にしか増えない。壁の寸法を 1.4 倍ずつ縮めたとき、相似な細分ならセル数は 1.4³ = 2.74 倍になるはずである。[4.4.1 節](#s4-4-1)で述べた、製品の格子が相似に細かくならない性質が、ここでも現れている。したがって GCI は h の二つの定義（節点数の −1/3 乗と、壁寸法の 1.4 倍の比）の両方で求める。この物体にフィンはなく、設定できる寸法は壁のセル寸法だけである。

Cp は、円すい表面の壁の節点（半径が x tan 10° から 1 % 以内のもの）を、x/L の 0.1 ごとの区間に分けて平均した。層 0 の比較窓（壁の節点の 0.4 ≦ x ≦ 0.9）と同じ位置にあたるのは、x/L が 0.4 から 0.9 の区間で、これを比較に使う。x/L が 0.2 から 0.9 の平均と、先端に最も近い区間（0.2 から 0.3）は、層 0 に対応する量がない。

層 0 と層 1 は、次の点で違う。

- メッシュの種類（2 次元と軸対称の構造格子と、3 次元の非構造四面体）。
- 領域の形。層 0 の円すいは先端から x = 1 まで続く裸の壁で、円筒も尾部もない。層 1 の物体は、円すいのあとに円筒、底面、Euler 用の尾部整形（長さ 0.3 m）が続く。製品は物体を抽出した断面から組み直すので、円すいと円筒の接合点が 0.02 % 短くなる。
- SU2 の設定ファイルを書く経路。
- 壁の Cp の取り出し方。
- 一様流の状態（層 1 は高度 20 m の標準大気、p = 101084.97 Pa、T = 288.02 K。層 0 は 101325 Pa、288.15 K）。Mach 数と比熱比は同じである。
- 先端の誤差の影響が、セルの大きさに対してどこに現れるか。層 0 の円すいの Cp の誤差は、先端の過渡が支配的である（[2.3 節](#s2-3)）。

### 3.3 製品の出力ファイルが途中で切れる {#s3-3}

観測した製品の挙動を、原因を推測せずに記す。ランナーが SU2 を止めたとき、SU2 が最後に書く表面の出力ファイルが、途中で切れることがある。

- 中の格子の最初の実行では、`surface_flow.vtk` の Pressure_Coefficient の欄が途中で切れ、Cp を読めなかった。同じ設定の再実行で得たファイルを使った。その vtk でも、Velocity の欄は 15468 点のうち 816 点分しか完全でなかった。
- 細かい格子では、`surface_flow.vtk` は 200 反復目の周期的な書き出しで、履歴は 210 反復まである。`surface_flow.csv` は 28265 行のうち完全な行が 1255 行で、1 行が途中で切れていた。csv の行はより後の状態を持つので、最終反復の完全な Cp の出力はない。両方のファイルが持つ円すい壁の 213 節点では、csv の Cp と vtk の Cp の差は平均 5.8×10⁻⁶（Cp の平均に対して 6×10⁻⁵）だった。これは描写であり、試験ではない。

層 1 の Cp に使った vtk の Cp の欄は、どの格子でも完全だった。切れ方の原因は、書き込みが停止時に切れること以上には、確かめていない。

### 3.4 層 1 が示すこと {#s3-4}

層 1 から言えるのは、製品の鎖が与える円すいの壁面 Cp が、どの格子でも厳密解より低く、格子を細かくすると差が小さくなる、という記述までである。細かい格子が収束しないので、層 1 の GCI も、パイプラインの寄与も得られていない。格子ごとに並列分割が違う影響は、試験していない。

## 4. 層 2：サンプル機体と Basic Finner に六つの段階を適用する {#s4}

対象は、サンプル機体（Euler、Mach 0.3、0.8、2）と Basic Finner（Euler、Mach 2.375。RANS-SA、Mach 1.832）である。

### 4.1 第 1 段階：プログラムの点検 {#s4-1}

この段階は、プログラムそのものを調べる段階であり、この研究では新しい計算をしない。製品の既存の試験と、この研究が足した試験を引く。

**製品の試験。** 製品のドキュメントの「[テスト](../../testing.html)」の章に、試験の内容と、確かめていないことが述べてある。式の実装は、閉じた式で答えが分かる問題で確かめている。たとえば、Mach 2 のくさび角 10° の斜め衝撃波の角度と圧力係数、Prandtl–Meyer 角、半頂角 10° の円すいの圧力係数（Taylor–Maccoll を直接解いた値）と比べる。時間積分の次数は、刻みを半分にしたときの誤差の縮み方で確かめている。DOP853 は次数 7.5 から 8.5 を、Lie 群積分の RK4 は 4 ± 0.3 を、DP5 は 5 ± 0.4 を許容し、測った値は 4.096 と 4.921 である。

一方、製品のテストに、メッシュの収束の次数を測るものはない。CFD のソルバを実際に走らせるテストは CI で実行されず、SU2 の出力の値は CI が検査しない。この章のテストの記述に同じことが書いてある（[「テストが確かめていないこと」](../../testing.html#sec-testing-limits)）。CFD の格子収束の記録は、製品のドキュメントの[検証の章](../../verification.html#page-vv-cfd-verification)にあり、テストにはない。

**この研究が足した試験。** 格子収束の計算に使うモジュールは、公開されている例題を再現する試験を持つ。

- NASA のチュートリアルの例題（Pr = 0.97050、0.96854、0.96178、r = 2）。倍精度の期待値は、観測次数 1.786170、外挿値 0.97130、GCI₁₂ = 0.103083 %、GCI₂₃ = 0.356249 %、漸近域の比 0.997984 である。NASA の VERIFY の出力は単精度で、5 桁目から食い違うので、これには相対 10⁻⁴ の許容差を掛ける。
- 細分比が一定でない例題として、Celik ら（2008）の表 1 の 1 列目と 2 列目。論文の p = 1.53 と 0.75、外挿値 6.1685 と 10.8801、GCI 2.2 % と 1.1 % に合う。
- 論文の表 1 の 3 列目は、差が符号を変える振動収束で、論文は s = −1 を使って p = 1.51、外挿値 6.0269 を示す。この研究のモジュールは振動収束の列を拒否し、帯を付けない。この論文の数値は再現しない。

この表 1 の 2 列目には、論文の他の値と合わない値がある。論文は e_ext21 を 0.9 % と印刷するが、論文自身の外挿値 10.8801 と φ₁ = 10.7880 からは 0.85 % になる。この欄は試験に使っていない。[2.2 節](#s2-2)の NPARC cone10 の表とあわせて、公開されている二つの検証の資料のそれぞれに、資料自身の他の値と合わない値がある。

厳密解の実装は、NPARC のくさびと Prandtl–Meyer の公開値、NASA SP-3004 の Taylor–Maccoll の表、Blasius の相似解（f″(0) = 0.332057）と照合する試験を持つ。層 0 の設定が製品の数値設定と一致することも、試験で確かめている（[2.1 節](#s2-1)）。

**製品ドキュメントの円すいの計算についての所見。** 製品のドキュメントが円すいの参照解に使っている Taylor–Maccoll の計算は、円すいの半頂角が付着の限界を超えると、衝撃波が剥がれて解がないのに、探索区間の端の値を衝撃波角として警告なしに返す。ドキュメントの円すいは半頂角 10° で、この影響を受けない。この研究の実装は、同じ場合に衝撃波の剥離を報せて停止する。付着する範囲では、両者が一致することを数点で確かめた。

### 4.2 第 2 段階：反復収束 {#s4-2}

チュートリアルは、残差が 3、4 桁以上落ちること、係数が平坦になること、反復打ち切りによる誤差が格子収束の GCI より十分小さいことを求める。

**層 0。** 厳密解を持つ計算は、すべて残差の目標に達して止まった。落ち幅は、くさび、円すい、膨張で 12.7〜13.9 桁、層流平板で 9.4〜10.4 桁である（`layer0.csv`、`layer0_plate.csv`）。

**入口の条件。** 格子収束の計算は、各格子の解が収束していることを要求する（[1.5 節](#s1-5)）。チュートリアルは、残差の落ち幅と、係数の平坦さの両方を求める。製品の RANS の判定は、収束でない解を二つに分ける。停滞は残差が下がりきらず係数が平らな解、振動は残差が十分下がり係数が小さな幅で振動する解で、どちらも「未収束」として警告に載り、窓の平均が係数に使われる（製品の[CFD の章](../../cfd.html#sec-cfd-int-rans-accept)）。したがって、製品の「未収束」の解は、残差の落ち幅の条件か係数の平坦さの条件の、少なくとも一方を満たさない。

**製品ドキュメントの RANS 格子収束（V6）。** サンプル機体の RANS の 3 段の格子（3 mm、4.8 mm、8 mm）の記録を入口の条件にかけると、4 つの族がすべて拒否される。

| 条件 | 量 | 拒否の理由 |
|---|---|---|
| M = 0.8、α = 0 | CN(0) | 4.8 mm と 8 mm の α = 0 の解が未収束 |
| M = 0.8、α = 4° | CN、CA、xcp | 8 mm の α = −4° の解が未収束 |
| M = 2、α = 0 | CN(0) | 4.8 mm と 8 mm の α = 0 の解が未収束 |
| M = 2、α = 4° | CN、CA、xcp | 3 mm の α = −4° は直接の再計算で、収束の判定も残差の落ち幅も記録がない |

出典：`gci_existing.csv`。α = 4° の値は、+4° と −4° の解を鏡映して組み合わせるので、両方の解の収束が要る。

製品のドキュメントは、この V6 から M = 0.8 の CN の GCI が 0.44 %、M = 2 の CN の GCI が 0.47 % と述べ、「どの量も単調に収束し、GCI は基準を満たす」と書く（[検証の章](../../verification.html#sec-cfd-rans-mesh)）。ドキュメントは、α = 0 の 8 mm と 4.8 mm が未収束であることは記すが、M = 0.8 の α = −4° の 8 mm が未収束であることは記していない。**所見は次のとおりである。** 公表された M = 0.8 の GCI は、粗い格子の α = −4° の解が「未収束」と記録されたまま、求められている。この解は、停滞なら残差の落ち幅の条件を、振動なら係数の平坦さの条件を満たさない。記録はどちらかを区別しない。どちらであっても、チュートリアルの第 2 段階の前提（収束した解）を、この GCI は満たしていない。公表値が誤りだとは主張しない。値は近いかもしれない。M = 2 の 3 mm の解は、未収束の記録があるのではなく、証拠が記録されていない（`gci_existing.csv` の備考によれば、600 反復で係数が 400 反復目から 10⁻⁴ 以内で安定した、という記述だけがある）。

拒否した 4 つの族のどれについても、**残差の落ち幅は記録されていない。** 記録にあるのは、解ごとの収束の判定と、α = 4° の反復回数（402 から 453 回）だけである（`gci_existing.csv`）。拒否した族の値は表にあるが、帯は付けない。

**層 2 の反復誤差と GCI の比。** 反復誤差は、停止した反復の値と収束した値の差（収束した値に対する %）で、GCI（細）に対する比で判定する。比が 0.1 未満なら反復誤差は格子収束の議論を乱さず、同じ格子の同じ量で比が 1 を超えるなら、その GCI は成り立たない（`iterative.csv`）。

- **同じ格子、同じ量の行で、比が 1 を超えるものはない。**
- 比が 0.1 から 1 の行もない。比が 0.1 未満の行は 5 行である。GCI が数値を持たない（拒否、振動収束、収束していない、使えない）ために比を付けられない行は 28 行である。格子収束が示されない理由は、これらの条件では反復ではない。
- 使える GCI は M = 2 の CNα（節点数の −1/3 乗を h とした 10.6 %）だけである。細かい格子の CN（4°）の反復誤差は 3.3×10⁻⁴ % で、比は 3.2×10⁻⁵ である。
- サンプル機体の 3 段の格子の反復誤差は、停止した反復と、停止後に SU2 が書いた最後の反復の差で測った。最大は 0.039 %（M = 0.8、細かい格子の CA）で、CN（4°）では 0.016 % 以下である。収束した値として最後の反復を使うので、これは反復誤差の下限である。M = 0.3 の CA（0.03〜0.06）が 0 でないことは、反復誤差では説明できない（細かい格子で 0.0015 %）。
- 製品のドキュメントの収束の深さの調査（M = 0.8、α = 4°、CN、壁寸法 2 mm、メッシュは細かい格子と別）では、残差が 10⁻⁶ に達した時点で止めると、CN は収束した値（1.20218）より 0.55 から 1.42 % 低い（始め方による）。深く収束させた解の差は 0.0075 % である。M = 0.8 の CN には GCI がないので、比は付けていない。
- 製品の「早期終了（accepted）」は、判定を主張せず、残差の落ち幅が 3 桁以上であることで通した（サンプル機体の中の格子の M = 2、α = 4° など）。

**乱流平板の 5 行は参考である。** 製品のドキュメントの乱流平板の抗力 CD は、受け入れの停止時に、最後の反復の値と、M = 0.2 の 3 つの格子で 0.12、0.62、1.89 %、M = 2 の 137×97 と 273×193 で 0.082、0.66 % 違う。Cf の GCI（0.038 % と 0.079 %）に対する比は 3.1、16.6、50.4（M = 0.2）と 1.03、8.34（M = 2）で、1 を超える。ただし、反復誤差は CD、GCI は Cf の量で、比べる量が違う。**平坦な読み方はこうである。停止時の CD は、Cf の格子不確かさより大きく動く。これは Cf の GCI を無効にはしないが、CD の GCI は存在せず、同じ量での検査はできていない。** Cf の GCI は、最後の反復の値（残差の落ち幅 5.8〜8.1 桁）から作ったものであり、受け入れ規則で止めた計算のものではない。

層 0 には、反復ごとの値の記録がなく、反復の誤差を % では測れない。残差の落ち幅だけが記録にある。

### 4.3 第 3 段階：一貫性 {#s4-3}

物理が要求する関係が、計算結果で成り立つかを調べる。新しい CFD は走らせず、既存の結果から読んだ（`consistency.csv`）。ここで調べるのは検証であり、妥当性確認ではない。

**CN(α = 0) = 0。** 形状は対称なので、迎え角 0 の法線力は 0 のはずである。判定の許容差は、同じ行の CN の奇関数部分（(CN(+4°) − CN(−4°))/2）の 1 % とした。

- 製品の既定のメッシュ（z 対称メッシュ。+α と −α を鏡映の関係で扱う）では、サンプル機体の CN(0) は Mach 0.3、0.8、1.2、2 で −1.4×10⁻⁷、1.5×10⁻⁵、−4.6×10⁻⁷、−2.6×10⁻⁶ である。すべて許容差内だが、これは**メッシュの対称性により 0 になる値であり、ソルバについては何も確かめていない。**
- 製品の既定ではない半モデルのメッシュ（`consistency.csv` が引く既存の調査）では、CN(0) の絶対値は 0.013 から 0.091 に及び、基準の配置、フィンを 45° 回した配置、JST、残差の目標を下げた配置の 12 行のすべてが許容差（0.0073〜0.0120）を超える。製品のドキュメントは、このずれを、フィンの表面の解像度がフィンの厚さより粗いことに帰している（フィンの表面だけを 0.75 mm にすると −0.007 に下がる）。この研究はその原因を再び試験してはいない。z 対称メッシュの 3 行は、鏡映によって 0 になる値で、これも解の検査にならない。

**CN(−α) = −CN(α)。** 迎え角 4° の偶関数部分は、α = 0 のずれと同じ大きさになる（半モデルの 12 行で −0.060 から +0.085）。これは α = 0 のずれと同じ原因による一定のずれが載っているのであり、独立な所見ではない。ずれは ±α の組合せで消える。z 対称メッシュの 3 行は、−α が +α の厳密な鏡映なので、ほぼ 0 になる（構成による）。

**d'Alembert の逆説。** Mach 0.3 の Euler の CA は 0 のはずで、サンプル機体の既存の計算では −0.0314 である（`consistency.csv`）。

**d'Alembert の逆説（細かい格子）。** M = 0.3、α = 0 の CA（サンプル機体、Euler）は、粗、中、細の格子で −0.0628、−0.0455、−0.0305 である（`consistency.csv`）。|CA| は格子を細かくすると縮む（28 % と 33 %）が、最細格子でも 0 から遠い。3 段の外挿は +0.045（節点数）、+0.065（壁寸法）で、0 の向こう側に出る。GCI は 309 % と 393 % で、使えない（`gci_sample_euler.csv`）。格子は相似に細かくならないので、この縮み方は 3 つの格子の傾向であり、収束の次数ではない。**この結果は、CA が離散化誤差であることと整合するが、0 に収束することは示していない。**

**CN(−α) = −CN(α)（z 対称にしないメッシュ）。** 中の格子を z 鏡映なしで作り、+4° と −4° の両方を解いた。偶関数部分は、M = 0.3 で −0.0388、M = 0.8 で −0.0201 で、許容差（0.0114 と 0.0118）を超える。M = 2 では +0.0015 で、許容差（0.0093）内である。この値は、同じメッシュの α = 0 の CN（−0.0404、−0.0219、+0.0016）とほぼ同じ大きさで、z 鏡映のないメッシュが全迎え角に持つ偽の法線力と読める。フィンの面をフィンの厚さの 1/3 強（1.4 mm）にした格子でも、M = 0.3 と 0.8 には残る。M = 0.3 の −4° の解と M = 2 の 0° と −4° の解は、製品の判定が「早期終了」で、書かれたまま組に入れた。

**遠方境界の質量流束。** 層 0 の 12 回の計算で、閉じた検査面（すべての境界）で、流入と流出の質量流束の相対差を調べた。チュートリアルは、約 10⁻³ を一貫していると見なす。

| 算例 | 粗 | 中 | 細 | 比（粗→中、中→細） |
|---|---|---|---|---|
| くさび | 1×10⁻⁹ 以下 | 1×10⁻⁹ 以下 | 1×10⁻⁹ 以下 | — |
| 膨張 | 1×10⁻⁹ 以下 | 1×10⁻⁹ 以下 | 1×10⁻⁹ 以下 | — |
| 円すい（一つの Euler 壁） | 6.616×10⁻⁴ | 1.766×10⁻⁴ | 4.336×10⁻⁵ | 3.75、4.07 |
| 円すい（軸を対称境界） | 3.429×10⁻⁴ | 1.029×10⁻⁴ | 2.577×10⁻⁵ | 3.33、3.99 |

出典：`massflux.csv`。

10⁻³ を超える行はない。ただし、読み方に限りがある。

- 平面の算例（くさび、膨張）は、履歴の有効桁（約 10 桁）の下限まで釣り合う。収束した解で保存形のスキームが与える値であり、これは収束と流束の集計を確かめる検査で、離散化誤差を確かめる検査ではない。下限以下の行では、格子による傾向は主張しない。
- 円すいの流束には 2πr の重みが載る（SU2 は全周の流束を返す）。このため収支は恒等式にならず、どの格子でも 0 でない。細かくするたびに 3.3 から 4.1 分の 1 になり、これは 2 次精度の離散化誤差（比 4）と整合するが、3 段では観測であって観測次数ではない。重みが原因だというのは、数値と整合する解釈であり、証明ではない。
- 軸を対称境界にした円すいの不均衡は、同じ格子で、一つの Euler 壁の 0.52 から 0.59 倍である。この差は説明できていない。
- これは層 0 の 2 次元と軸対称の計算の収支であり、製品の 3 次元の非構造格子の収支ではない。

### 4.4 第 4 段階：空間（格子）収束 {#s4-4}

#### 製品の格子は相似に細かくならない {#s4-4-1}

格子収束指標は、格子が幾何学的に相似に細かくなることを前提とする。製品が作る格子は、この前提を満たさない。壁面とフィンのセルの寸法（`wall_size` と `fin_size`）を変えても、外側のセルの最大寸法は変わらず、遠方境界の半径の 1/10 に固定されている（利用者が設定できない）。細かくなるのは壁の近くだけである。

Basic Finner の Euler の 4 段（L1〜L4）では、壁とフィンのセルの寸法を 1.4 倍ずつ縮めた。相似な細分なら、セル数は 1.4³ = 2.74 倍ずつ増えるはずだが、実際は 345736、586094、1035278、1891652 セルで、増え方は 1.70、1.77、1.83 倍である（`gci_existing.csv`）。

遠方境界を縮めると別の問題を解くことになり、外側の寸法を設定する手段は製品にない。そこで、製品の格子から求める GCI は、h の定義に条件づく。この研究は、**二つの定義の両方**で GCI を求め、両方を報告する。一つは節点数やセル数から求める h（セル数の −1/3 乗）、もう一つは壁の寸法の比である。この二つで細分比が違う（前者は 1.19 から 1.22、後者は 1.40）。外側の寸法が固定された格子では、どちらも実効的な格子寸法ではない。両者は問いを挟むもので、解決するものではない。二つの差を、不確かさの一部として扱う。この差は、真の GCI の上限ではない。

#### Basic Finner、Euler、Mach 2.375 {#s4-4-2}

### 4.5 第 5 段階：時間収束 {#s4-5}

**CFD の計算は定常なので、時間収束は当てはまらない。** SU2 の計算に時間刻みはない。非定常の算例は、この研究の範囲に含めない。

IgnisYeet の時間に依存する部分は、6 自由度の飛翔の積分器である。そこでこの段階の趣旨を、積分器の刻み幅の収束に当てはめた。

#### 設定 {#s4-5-1}

サンプル機体（パラシュート降下、風 4 m/s）を、積分法 RK4 と刻み幅 0.008、0.004、0.002、0.001 s で解いた。各量に、刻み 0.001/0.002/0.004 s の 3 段（結果）と、0.002/0.004/0.008 s の 3 段（粗い側の確認）の二つの組を作った。細分比は 2、安全率は 1.25 である。比べた量は、頂点高度と時刻、着地距離、飛翔時間（着地時刻）、レール離脱の時刻と速度、t = 1 s と 10 s の高度と速度である。頂点、レール離脱、着地、主傘の展開は、刻みの中で補間して求める（Hermite 補間と二分法）ので、刻みの端に寄らない。

#### 結果 {#s4-5-2}

**サンプルそのものでは、どの量にも観測次数が得られなかった。** 2 組（粗い側と細かい側）の 24 行のすべてが、振動収束（差が符号を変える）か、出力の分解能の限界で、次数も GCI も付かない（`temporal.csv`）。

| 着地距離 [m] | 7735.523 | 7735.526 | 7735.510 | 7735.542 | 0.032 |

刻みを 8 倍変えても、頂点高度は 0.018 m（相対 4×10⁻⁶）、着地距離は 0.032 m、飛翔時間は 0.0024 s しか動かない。次数が観測できないので、この差は誤差の見積もりには使えず、観測した変動の幅を示すだけである。

#### 原因の切り分け {#s4-5-3}

サンプルの推力曲線は、0 N から始まり 0.05 s で 2300 N に達する。レールのモデルは、推力が重量を下回る間、機体を静止させる。このため、約 2.3 ms に加速度の折れが生じ、積分器はこれを探さない。折れは刻みの端に対する位置が刻みごとに違う。原因をこの折れだと考える根拠は、入力を変えた制御の実験である。制御は、推力曲線の最初の値だけを変えた複製を使い、製品の入力は変えていない。

- **最初の値を 300 N にした制御**（重量約 108 N を超える。ランプは残す）。レールでの保持だけを除く。0.008 s と 0.004 s のレール離脱の速度の差は、サンプルでは 4.5×10⁻⁴ m/s、この制御では 4.1×10⁻⁸ m/s になる。**保持がレール離脱のばらつきの主な原因であることを支持する。** ただし、この制御の粗い側の頂点高度はなお単調でない（0.004 と 0.002 の差 −1.1×10⁻⁴ m、0.008 と 0.004 の差 +4.2×10⁻⁴ m）。小さな第 2 の寄与は排除できない。
- **最初の値を 2300 N にした制御**（保持とランプの両方を除く）。粗い側の 3 段で、頂点高度の次数が 4.01、飛翔時間が 3.96 となり、RK4 の次数 4 と合う。t = 10 s の水平距離は 5.33 で、次数 4 から 1 以上離れるので旗が付く。
- 制御の細かい側の 3 段は、相対 10⁻⁹ から 10⁻⁸（頂点高度で約 10⁻⁵ m）で、振動するか収束しなくなる。この床は、刻みの端がすべての推力曲線の節に合う入れ子の掃引でも残るので、刻みの端の不整合では説明できない。**この床の原因は特定していない。** 保持とランプを除いた制御の頂点時刻の次数 4.75 は、差（2.2×10⁻⁹ s と 6.0×10⁻⁸ s）がこの床より小さく、同じ計算の頂点高度は振動するので、次数 4 の証拠ではない。

なお、刻みが推力曲線の節（0.05、2.9、3.1 s）を割り切らない場合は、刻みを節で切り詰めるので、4 つの計算の刻みの格子は入れ子にならない。

**まとめ。** サンプルの RK4 の刻み幅の収束には、観測次数が得られない。次数 4 は、保持とランプを除いた制御の粗い 3 段でだけ観測できる。刻みを 8 倍変えたときの結果の変動は、頂点高度で 0.018 m にとどまる。これは積分法の次数の検証（[4.1 節](#s4-1)の製品の試験）を補うもので、実測との比較ではない。

#### 4.6.2 妥当性確認（実測との比較） {#s4-6-2}

Basic Finner の係数を、DREV-TM-9703 の実測値（射場の自由飛翔、Table IX の 6 自由度の当てはめ）と比べる。比べる量は CNα と CX0 で、CFD の側には [4.4 節](#s4-4)の帯を付ける。

**実測の誤差棒。** 実測の誤差棒は、Table IX の確率誤差から引く（`measured.csv`）。

- CNα は 8 つの Mach 数のすべてに確率誤差があり、1〜4 % である。
- CX0 は、確率誤差が表にあるものが 0（0.5 % 未満の意味）の 4 点（Mach 1.077、1.293、3.734、4.3）と、当てはめで固定した値で確率誤差のない 4 点（Mach 1.832、2.375、2.718、3.147）である。
- 確率誤差が空の量には**誤差棒を描かず、誤差が不明であると書く。誤差を推定して補わない。** 値が 0 の行は、誤差 0 ではなく 0.5 % 未満の意味なので、中が白い菱形に 0.5 % の上限を三角で示す。

**製品ドキュメントの既存の図についての所見。** 製品のドキュメントの Basic Finner の実測との比較の図は、確率誤差が空の量に長さ 0 の誤差棒を描く。確率誤差が 0 の行（0.5 % 未満）にも、長さ 0 の棒を描く。どちらも、棒がない（誤差が 0 に見える）図になり、誤差が不明であることと、0.5 % 未満であることを区別できない。この図は直さず、所見として報告する。この研究の図は、上の規則で描く。

**CFD の帯。** 図 1 は、Basic Finner の CNα と CX0 を、実測と CFD（Euler、RANS）で並べたものである。

- **Euler の CNα は、8 つの Mach 数のすべてで、実測より低く、差が実測の確率誤差を上回る。** 差が確率誤差に最も近いのは Mach 1.832（−4.4 % に対し 4 %）と 2.718（−2.9 % に対し 2 %）である。Mach 2.375 では、差（−10.5 %）は、箱（±0.17 %）と、メッシュの段の間で観測した CN の変化（0.47 %）の、どちらよりもはるかに大きい。**この差は、この格子の列が示す感度では説明できない。** ただし、格子は相似でなく、真の離散化誤差の上限は得られていないので、数値誤差では説明できないとまでは言えない。
- **Mach 1.832 の RANS の CNα は、実測の確率誤差（4 %）の内にある（−2.7 %）。** RANS の数値不確かさの帯がないので、この一致が数値誤差を含めても成り立つかどうかは、判断できない。
- **CX0 は、CFD に帯がなく、重なりの判断ができない。** Euler の差は 15 から 28 % で、実測の確率誤差（0.5 % 未満の 4 点）の外にある。確率誤差のない 4 点は、実測の側が不明で、判断できない。CX0 は CFD の CA にモデルから求めた項を足した値なので、CFD の格子不確かさだけでは帯にならない。
- RANS の CX0 は、底面の項の取り方で −25.8 % から +10.7 % に動く。この違いは、モデルの扱いの違いであり、数値誤差ではない。実測の誤差棒がないので、どちらが近いかは言えない。

どの結論も、実測との差を、手法のどの要素に帰するかは述べない。

## 5. この研究が示していないこと {#s5}

- 層 0 は、ソルバと数値設定の検証であり、IgnisYeet のパイプラインの検証ではない。
- 層 0 の GCI は、12 行のうち 5 行で最細格子の誤差を押さえなかった。層 2 の GCI も、同じように誤差を過小評価しうる。
- Basic Finner の Euler の 4 段の格子は、信頼できる GCI を与えない。製品の格子は相似に細かくならず、h の二つの定義は問いを挟むだけである。
- サンプル機体の RANS の格子収束（V6）は、入口の条件で 4 つの族がすべて拒否された。公表値の誤りは主張しないが、帯もない。
- 層流平板は、乱流モデルを切った RANS の離散化であり、製品が書く設定ではない。起動の段階の違いが定常解を変えないことは、試験していない。
- 壁面のエントロピーの偏りと、境界の接合点の停滞点が、製品の 3 次元の非構造格子に及ぶかどうかは、試験していない。
- 層 1 の細かい格子は未収束で、層 1 の GCI も、3 次元非構造格子の生成を含むパイプラインの誤差の寄与も、求めていない。製品が書く表面の出力ファイルが、停止時に切れることがあった。原因は確かめていない。
- サンプルの飛翔の積分器には、観測次数が得られていない。次数 4 は制御の実験でだけ観測された。
- 妥当性確認は Basic Finner の 1 つの実測データ（DREV-TM-9703）に限る。

- サンプル機体の Euler の GCI は、M = 2 の CNα だけで、次数が理論値よりはるかに低い。M = 0.3 の CA が 0 に収束することは示していない。
- Basic Finner の RANS には、GCI がない。判定の入れ替わりの原因は分かっていない。細かいフィンのセル寸法での gmsh の異常終了は、製品の欠陥である。
- 反復誤差の検査は、GCI が得られた 1 条件（M = 2 の CNα）でしか成り立たない。乱流平板の 5 行は、量が違うので参考である。
- 妥当性確認で、RANS の CNα が確率誤差の内にあることは、数値不確かさの帯がないので、数値誤差を含めた一致とは言えない。CX0 は帯がなく、判断できない。
