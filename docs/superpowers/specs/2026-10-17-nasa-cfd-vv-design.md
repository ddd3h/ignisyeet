## 1. 目的

NASA のチュートリアルが定める検証と妥当性確認の手順を、IgnisYeet の空力計算に対して実施する。
手順は次の 6 段階からなる。

1. プログラムの点検
2. 反復収束
3. 一貫性
4. 空間（格子）収束
5. 時間収束
6. 高精度解との比較（検証）／実測との比較（妥当性確認）

目的は、IgnisYeet が出す空力係数に **数値不確かさの帯を付けること**、およびその帯を実測の誤差と
並べて示すことである。帯のない比較は、どちらが正しいかを決められない。

## 2. 用語の規律

この研究では、次の三つを別の名前で呼び、混ぜない。

| 名前 | 意味 | 比較の相手 |
|---|---|---|
| 検証（verification） | 式を正しく解いているか | 厳密解、高精度解 |
| 相互比較（cross-comparison） | 手法やプログラムの差 | 別の手法、別のプログラム |
| 妥当性確認（validation） | 実機に近いか | 実測値 |

CFL3D や FUN3D の結果との比較は相互比較であり、妥当性確認ではない。
層 0 と層 1 が検証、層 2 の第 6 段階だけが妥当性確認にあたる。

## 4. 層 0: 厳密解を持つ算例

NPARC 検証アーカイブの算例のうち、解析解を持つものを選ぶ。

| 算例 | M | 厳密解 | 比較量 |
|---|---|---|---|
| 15° くさびの斜め衝撃波 | 2.5 | θ–β–M 関係式 | 衝撃波角 β、p2/p1、M2 |
| 半頂角 10° の円すい | 2.35 | Taylor–Maccoll | 円すい表面 Cp、衝撃波角 |
| 15° の Prandtl–Meyer 膨張 | 2.5 | Prandtl–Meyer 関数 | p2/p1、M2 |
| Blasius 層流平板 | 0.2 | Blasius 解 | Cf(x)、速度分布 |
| 乱流平板 | 0.2 | Cf 相関、CFL3D の参照解 | Cf(x)、u⁺ vs y⁺ |

層流平板は NPARC の `fplam` が M = 0.1 を使うが、ここでは **M = 0.2 で解く。**
IgnisYeet の設定は Roe 法であり、低マッハ数の前処理を持たない。M = 0.1 では
圧縮性の解法の精度が落ち、見ているものが Blasius 解との差なのか低マッハ数の
数値誤差なのか分けられない。乱流平板が M = 0.2 なので、条件も揃う。
Blasius 解は非圧縮の解なので、M = 0.2 での圧縮性の寄与を見積もって報告に添える。

乱流平板（`doc/scripts/rans_flatplate.py`）はすでに計算済みで、
`doc/data/cfd/rans_flatplate.csv` に 3 段の `h` と `cf_x097` がある。
新たに解かず、この既存データから観測次数と GCI を求める。

層 0 は 2 次元と軸対称の構造格子、層 1 と層 2 は 3 次元の非構造格子（半モデル）を使う。
よって層 0 と層 1 の差には、3 次元の非構造メッシュ生成そのものの寄与も含まれる。
報告では「パイプラインの誤差（3 次元の非構造メッシュ生成を含む）」と書き、
メッシュ生成だけを切り出したとは書かない。

### 4.0 円すいの参照値についての未解決点

NPARC の `cone10` の表は、それ自身で矛盾している。確認した内容は次のとおりである。

| 量 | NPARC の表 | リポジトリの Taylor–Maccoll | NPARC の β から導いた値 |
|---|---|---|---|
| 衝撃波角 β | 27.1843° | 26.7367° | — |
| 円すい表面 M3 | 2.1469 | 2.146831 | — |
| p3/p1 | 1.4234 | — | 1.3735 |
| T3/T1 | 1.1063 | — | 1.0950 |
| ρ3/ρ1 | 1.2867 | — | 1.2543 |

NPARC の M3 はリポジトリの実装と小数 4 桁まで一致する。
一方、同じ表の p3/p1、T3/T1、ρ3/ρ1 は、その M3 とも NPARC 自身の β とも整合しない。
NPARC の T3/T1 = 1.1063 に整合する M3 は 2.1240 であって 2.1469 ではない。

**NPARC の p3/p1、T3/T1、ρ3/ρ1、β を受け入れ試験の目標値にしない。**
衝撃波角は NACA 1135 の円すい流れの表など、独立した資料で確かめる。
確かめがつくまで、円すいの試験は M3 と Cp だけに掛ける。
この矛盾は、報告に所見として書く。

### 4.1 厳密解

`research/IY-TR-2026-01/nasa_vv/exact/` に Python で実装する。数値は実装が計算し、文献から転記しない。

- 斜め衝撃波: `tan θ = 2 cot β (M₁² sin²β − 1) / (M₁²(γ + cos 2β) + 2)` を弱解側で解く。
- Taylor–Maccoll: 円すい流れの常微分方程式を衝撃波面から表面へ積分し、衝撃波角を射撃法で合わせる。
- Prandtl–Meyer: `ν(M) = √((γ+1)/(γ−1)) arctan √((γ−1)(M²−1)/(γ+1)) − arctan √(M²−1)`。
- Blasius: 相似解を積分して `Cf = 0.664 / √Re_x`。
- 乱流平板: Cf の相関式と、NASA Turbulence Modeling Resource が公開する参照解。

各実装に、独立した出典の値との照合試験を付ける。

### 4.2 格子

gmsh で構造格子を作り `.su2` で書き出す。各算例に 3 段の入れ子格子を用意し、
方向ごとの点数を厳密に 2 倍にする。細分比 r = 2 が厳密に定まるので、
チュートリアルの定数 r の式がそのまま使える。

円すいは迎角 0 なので軸対称として解く（SU2 の `AXISYMMETRIC`）。

### 4.3 数値設定

SU2 の設定は `crates/cfd/src/su2cfg.rs` が書くものに合わせる。

「IgnisYeet の設定で解いた」という主張自体に試験を掛ける。
`ignisyeet aero` の Euler のケースが実際に書いた `.cfg` を取り、基準のファイルとして置く。
層 0 の設定が、その数値計算に関わる項目を**そのまま**使っていることを試験で確かめる。
対象は、対流項の離散化、MUSCL、制限関数、勾配の求め方、CFL、線型solver、打ち切り条件である。

異なってよい項目は、次の二つだけとする。報告にも明記する。

- 境界の指定（marker）
- `AXISYMMETRIC`

次元は設定ファイルではなくメッシュファイルの `NDIME` で決まる。SU2 8.3.0 に `NDIM` という設定項目はなく、書くと実行が止まる。

既存の `doc/scripts/rans_flatplate.py:146` は、この設定を Python で書き写したものである。
RANS のみを対象とし、Rust 側の出力と突き合わせる試験を持たない。
層 0 の設定は、この写しをそのまま信用せず、上の試験を通す。

## 6. 層 2: チュートリアルの 6 段階

対象はサンプル機体（`examples/sample.toml`）と Basic Finner（`examples/basic_finner/`）。

### 6.1 プログラムの点検

新しい計算は行わない。既存の単体試験と `doc/source/testing.rst`、`doc/source/verification.rst` の
該当箇所を引く。GCI モジュールは新規なので、第 7 節の受け入れ試験を持つ。

### 6.2 反復収束

既存の走行が残す残差履歴と係数履歴を使う。示すものは次の三つ。

- 残差が 3〜4 桁以上落ちること。
- CN、CA、Cm が平坦になること。
- 反復を打ち切ったことによる誤差が、格子収束の GCI より十分小さいこと。

最後の一つを数値で示す。反復誤差が GCI と同じ桁なら、格子収束の議論は成り立たない。

### 6.3 一貫性

物理が要求する関係が成り立つかを確かめる。

| 検査 | 期待 | 備考 |
|---|---|---|
| M = 0.3 の Euler の CA | 0（d'Alembert の逆説） | 現在の値は −0.031 |
| CN(α = 0) | 0 | 形状の対称性 |
| CN(−α) | −CN(α) | 反対称性 |
| 遠方境界の質量流束 | 流入と流出が釣り合う | 閉じた検査面で |

M = 0.3 の CA については、格子を細かくして `|CA|` が縮むかを調べる。縮むなら離散化誤差、
縮まないなら定式化か境界条件の問題であり、どちらかを報告で述べる。

### 6.4 空間（格子）収束

3 段の格子で GCI を求める。gmsh の非構造格子では細分比が一定にならないので、次のように扱う。

- 代表格子寸法: `h = N^(-1/3)`。N は節点数である。SU2 は節点中心の離散化を使うので、
  検査体積は節点に対応し、計算領域の大きさを固定すれば `(ΣΔV_i / N)^(1/3)` と同じ比を与える。
  既存の V6 の結果（`doc/data/cfd/rans_mesh_study.csv`）も同じ定義を使っており、揃う。
- 実効細分比: `r21 = h2/h1`、`r32 = h3/h2`。目標は `r ≥ 1.3`。
- 観測次数 p: Celik (2008) の反復解法（第 7.2 節）。定数 r の閉じた式は層 0 にだけ使う。
- 振動収束の判定: `ε32/ε21 < 0` のとき振動収束とし、その旨を明記する。
- セルの寸法の指定は一括で縮小する。`wall_size`、`fin_size`、RANS の第 1 層高さを
  すべて同じ比で変える。一部だけ変えた格子列は相似ではなく、GCI の前提を満たさない。
  既存の 6 段の Euler の格子列（`doc/data/cfd/mesh_convergence.csv`）は `fin_size` を 1 mm に
  固定したまま `wall_size` だけを変えており、この条件を満たさない。よって作り直す。
- **計算領域の大きさは変えない。** 遠方境界の位置を縮小すると別の問題を解くことになる。
  変えるのはセルの寸法だけである。

対象の量は CNα、CA、xcp。計算する条件は次に固定する。

| 対象 | Mach | 迎角 | モデル | 格子 | 元データ |
|---|---|---|---|---|---|
| サンプル機体 | 0.3 | 0°, 4° | Euler | 3 段 | 新規に計算する |
| サンプル機体 | 0.8 | 0°, 4° | Euler | 3 段 | 新規に計算する |
| サンプル機体 | 2.0 | 0°, 4° | Euler | 3 段 | 新規に計算する |
| Basic Finner | 2.375 | 0°, 2°, 4° | Euler | 4 段 | `mesh_check.csv`（計算済み） |
| Basic Finner | 1.832 | 0°, 2° | RANS-SA | 3 段 | 新規に計算する |

M = 0.8 は遷音速で、観測次数がもっとも乱れると見込まれる条件である。
M = 2.0 は超音速の代表である。M = 0.3 は第 6.3 節の `CA → 0` の検査に要る。

Basic Finner の Euler は `doc/data/validation/basic_finner/mesh_check.csv` に 4 段の結果がある。
`wall_size` と `fin_size` を 1.4 倍ずつ揃えて細分しており、相似の条件を満たす。
新たな計算を行わず、この既存データから GCI を求める。L1–L3 と L2–L4 の二組を計算し、
得られる p が互いに合うかどうかを、それ自体一つの検査とする。

Basic Finner の RANS は **M = 1.832、α = 2 とする。** M = 2.375 では RANS が収束しない
（3000 反復の上限で残差が 1.3 桁と 0.6 桁しか落ちず、リミットサイクルに入る。M = 3.147 は発散する。
`doc/source/validation.rst:706-708`）。収束が確かめられている点は M = 1.832 だけであり
（`doc/data/validation/basic_finner/cfd_rans.csv`）、この点には DREV-TM-9703 の実測もある。
CNα は既存の Basic Finner の約束に合わせて CN(2°)/2° で求める。

RANS の格子収束はもっとも重いので、粗い格子から順に回す。ある段が収束しない場合は、
残差の落ち幅を添えて「RANS の GCI は得られなかった」と報告する。
RANS の収束性を直す作業は行わない（第 14 節）。

超音速では衝撃波があるので、観測次数 p は理論値から外れ、格子列によって乱れる。
Richardson 外挿は不連続面の近くでは成り立たない。この点はチュートリアル自身が述べており、
得られた p をそのまま報告し、理論値に合うよう調整しない。

### 6.7 妥当性確認

Basic Finner の係数を DREV-TM-9703 の実測と比べる。

- 実測の誤差棒は `doc/data/validation/basic_finner/measured.csv` の `probable_error_pct` から引く。
  この列が空の量には **誤差棒を描かず**、誤差が不明であると書く。誤差を推定して補わない。
  値が `0` の行は「0.5 % 未満」を意味する（`doc/source/validation.rst:580`）。誤差 0 ではない。
  この行には 0.5 % の上限の棒を、ほかと区別できる描き方で描く。
  既存の `doc/scripts/make_plots.py:1610` は `fillna(0.0)` を使っており、誤差が不明な点に
  長さ 0 の誤差棒を描いてしまう。研究の図では、この描き方を使わない。
  既存の図を直すかどうかは、この研究の範囲外とし、所見として報告する。
- CFD 側には第 6.4 節の GCI の帯を描く。
- 両方の帯が重なるかどうかで判断を述べる。重ならない場合、差が数値誤差では説明できないと述べる。

## 7. GCI モジュール

`research/IY-TR-2026-01/nasa_vv/gci/` に Python パッケージとして実装する。試験を先に書く。

### 7.1 定数の細分比（チュートリアルの式）

```
p      = ln((f3 − f2) / (f2 − f1)) / ln(r)
f_h0   = f1 + (f1 − f2) / (r^p − 1)
GCI    = Fs · |ε| / (r^p − 1) × 100 [%]
比     = GCI23 / (r^p · GCI12)        ≈ 1 なら漸近域
```

安全率 Fs は、格子 2 段のとき 3.0、3 段以上のとき 1.25。

### 7.2 変化する細分比（Celik 2008）

```
ε21 = f2 − f1,  ε32 = f3 − f2,  s = sign(ε32 / ε21)
p   = |ln|ε32/ε21| + q(p)| / ln(r21)
q(p)= ln((r21^p − s) / (r32^p − s))            （p について不動点反復）
f_ext21 = (r21^p · f1 − f2) / (r21^p − 1)
e_a21   = |(f1 − f2) / f1|
e_ext21 = |(f_ext21 − f1) / f_ext21|
GCI21   = 1.25 · e_a21 / (r21^p − 1) × 100 [%]
```

`s = −1` のとき振動収束であり、結果にその印を付ける。

漸近域の比は、NASA の `verify.f90:120` に合わせて次の向きで計算する。

```
ratio = r21^p · GCI21 / GCI32
```

逆向きに取ると逆数になり、NASA の出力と合わない。

### 7.3 受け入れ試験

NASA のページが示す例題を、そのまま試験にする。
入力は Pr = 0.97050、0.96854、0.96178（細かい順）、r = 2。期待する出力は次のとおり。

| 量 | 倍精度の期待値 | NASA の VERIFY の出力 |
|---|---|---|
| 観測次数 p | 1.786170 | 1.78618479 |
| 外挿値 f_h0 | 0.97130 | 0.971300304 |
| GCI12（Fs = 1.25） | 0.103083 % | 0.103080 % |
| GCI23（Fs = 1.25） | 0.356249 % | 0.356244 % |
| 漸近域の比 | 0.997984 | 0.997980 |

`verify.f90` は `REAL` を宣言しており単精度である。差し引きで桁落ちが起きるため、
その出力は倍精度の値と 5 桁目から食い違う。よって試験は二段にする。
倍精度の期待値には厳しい許容差を、`verify.f90` の出力には相対 1e-4 の許容差を掛ける。

この例題は `r21 = r32` なので `q(p) = 0` となり、**変化する細分比の経路を試験しない。**
よって Celik et al. (2008) の論文の表 1 にある、細分比が一定でない例題も試験に加える。
値は論文から取る。記憶から書かない。

ほかに次の場合の試験を置く。

- 振動収束（`ε32/ε21 < 0`）。印を付けて返すこと。`None` を返して落とさないこと。
- `ε21 = 0`。
- 不動点反復が収束しない場合。

この試験が通るまで、実データには適用しない。

- コミットは本体が行う。`git commit -a` は使わず、パスを明示して staging する。
- 作業者の出力は、取り込む前に本体が確認する。

## 11. 計算資源
