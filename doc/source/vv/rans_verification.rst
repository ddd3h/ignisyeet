RANS の検証
=============

.. _sec-cfd-rans:

RANS の検証の方針
-------------------

``model = "rans"``\ （SA-neg、プリズム層つきのメッシュ、1 次精度の起動の段と 2 次精度の段）を、平板の摩擦の基準解と相関式、円すいの理論解、フィンなし胴体の摩擦の見積もり、サンプル機体のメッシュ収束、Euler の CFD と Barrowman 法との相互比較で確かめた。
V1〜V4、V6 は検証（基準解、相関式、理論解、収束との比較）、V7 と V8 の Euler との比較は相互比較である。比べる相手はどれも計算、相関式、理論であり、実測との比較（妥当性確認）は含まない。
計算には SU2 8.3.0、gmsh 4.15.2、Open MPI 5.0.11 を使い、Intel Core i7-12700（20 スレッド、メモリ 30 GB、ほかの計算と共用）で行った。
判定の一覧と数値は ``doc/data/cfd/rans_verification.json`` に、各項目のデータは ``doc/data/cfd/rans_*.csv`` にある。

結果から、RANS の結果は次の範囲で使える。

* **付着した流れの摩擦**：平板では基準解と 1 % 以内、相関式と 1.5 % 以内で、円すいとフィンなし胴体の摩擦の軸力も平板の見積もりと 2.5〜7.4 % で一致する。壁面の :math:`y^+` は既定の ``yplus = 1`` で 95 パーセンタイルが 1 未満になる。
* **サンプル機体の** :math:`M=0.8` **と** :math:`M=2`、:math:`\alpha=\pm4^\circ`：:math:`C_N`、:math:`C_A`、:math:`x_{cp}` はメッシュに対して単調に収束し、GCI は 2 % 以内（:math:`x_{cp}` は 1.3 mm 以内）である。:math:`C_N` と :math:`x_{cp}` は Euler の CFD と 5.1 % と 4 mm 以内で一致する（形状の違いを含む相互比較）。

次の条件と量は、確かめていないか基準を満たさない。

* **亜音速の** :math:`\alpha=0` **の非対称**：:math:`M=0.8` の半モデルで :math:`C_N(0)` が 0.011〜0.034 残る（底面の後ろの剥離した流れの非対称な解）。係数表では ``alpha_mode = "mirror"`` が :math:`\pm\alpha` の組合せで取り除く。
* **低い亜音速**：:math:`M=0.3` の :math:`\alpha=0,-4^\circ,-8^\circ` は、残差が周期的に振動して収束しない（V8）。
* **大きな迎角と遷音速**：:math:`\alpha=8^\circ` と :math:`M=0.3,1.2` は、係数表どうしの比較（V8）だけで、メッシュ収束を確かめていない。
* **底面の流れ**：底面の圧力（``rans_base = "cfd"``）は確かめていない（V5 は実施していない）。既定の ``rans_base = "model"`` では底面抗力は部品積み上げ法の値である。
* **CAD のモデル**：``surface = "step"`` の RANS は、メッシュの検査までを確かめ、SU2 の解は確かめていない。
* **軸力の粗さとフィンの縁**：RANS の壁は滑らかで、設定の粗さの効果は部品積み上げ法の摩擦の増分として足す。作り直した形状のフィンの縁は弦長の 2 % で鈍くしたもので、設定の ``fin_le``、``fin_te`` の効果は部品積み上げ法のフィンの縁の項から求めた増分として足す。どちらもモデルの項で、CFD の解ではない。
* **メモリ**：1 ケースのメモリは節点あたり約 10 kB（:ref:`sec-cfd-rans-cost`）で、細かいメッシュはメモリで制限される。

平板（V1、V2）
----------------

NASA Turbulence Modeling Resource（TMR）の 2 次元の平板（2DZP）の格子 69×49、137×97、273×193 を、CFD モードと同じ設定（SA-neg、Roe、1 次精度の起動の段、MUSCL と Van Albada の制限関数）で解いた。
単位長さあたりの Reynolds 数 :math:`5\times10^6`、温度 300 K、断熱壁で、:math:`M=0.2` と :math:`M=2` を解き、残差を 8 桁下げた（:math:`M=2` の 137×97 だけは 20000 反復の上限で 5.8 桁）。
:math:`x=0.97` の摩擦係数 :math:`c_f` を、:math:`M=0.2` では TMR の CFL3D と FUN3D の SA の解（545×385 の平均、:math:`2.7055\times10^{-3}`）と、:math:`M=2` では van Driest II の相関式（Kármán–Schoenherr の式、回復係数 0.89）と比べた。

受け入れの判定が止める反復での平板の抗力は、8 桁まで解いた値と、6 つの格子と Mach 数の組で最大 0.29 % しか違わない。

円すいの圧力（V4）
--------------------

半頂角 10° の円すいと円筒（全長 0.5836 m、半径 0.05 m、平らな底面）を、:math:`M=2`、:math:`\alpha=0`、海面の自由流（単位長さあたりの Reynolds 数 :math:`4.65\times10^7`）で、RANS（``wall_size`` 2 mm、半モデル、105 万節点、45 層）で解いた。
ケースは 402 反復で収束と判定され、:math:`y^+` の 95 パーセンタイルは 0.55 である。円すいの面の節点の :math:`C_p` を円すいの長さ :math:`L_c` で区切った区間で平均し、Taylor–Maccoll の解（0.10447）と比べた。

摩擦（V3）
------------

壁面の力のうち摩擦による軸力を、壁面の摩擦応力から積分し、同じ濡れ面積の上で積分した平板の見積もりと比べた。見積もりは、先端から乱流の境界層を仮定した局所の van Driest II（断熱壁、回復係数 0.89、Kármán–Schoenherr の式）である。
円すいでは、Taylor–Maccoll の解の境界層の外縁の状態と、乱流の Mangler の変換を使う。フィンなし胴体（サンプル機体の胴体、``wall_size`` 5 mm、58 万節点）は :math:`M=0.8` と 2、円すい（2 mm）は :math:`M=2` で、どれも :math:`\alpha=0` の収束したケースである。

--------------------

係数は一定の値になり、力は底面の手前の胴体とその横のフィンに載る。底面の後ろの剥離した流れが :math:`y=0` について非対称な解になったもので、メッシュによって符号も変わるので、メッシュを細かくしても消えない（:ref:`sec-cfd-val-asym`）。
係数表では、``alpha_mode = "mirror"`` が :math:`+\alpha` と :math:`-\alpha` の組合せでこのずれを取り除き、上の :math:`\alpha=4^\circ` の値もそうして求めた。
:math:`\alpha=0` のケース自体は、8 mm と 4.8 mm では残差が下がりきらず、3 mm で収束した。

1 段の計算時間（6 ケース）は、8 mm で 0.75 時間、4.8 mm で 2.5 時間、3 mm で 2.8 時間である。

Euler との相互比較（V7）
--------------------------

V6 の 3 mm の結果を、Euler の CFD（既定の設定。2 mm、フィンの面 1 mm、142 万セル）と Barrowman 法と比べた（``doc/data/cfd/rans_vs_euler.csv``）。
二つの CFD は形状が少し違う。RANS はフィンの縁を弦長の 2 % で鈍くし、底面は平らなままである。Euler はフィンの縁が鋭い両凸断面で、底面の後ろに尾部フェアリング（底面半径の 6 倍）を置く。

   * - 0.8

RANS の :math:`C_N` は Euler より 5.0 % と 3.3 % 大きく、圧力中心は 3.3 mm と 0.2 mm 後ろにある（基準は 8 % と 30 mm）。差の原因（底面の扱い、フィンの縁、粘性）は切り分けていない。
どちらの CFD も、Barrowman 法より :math:`C_N` が大きく、圧力中心が後ろにある（:ref:`sec-vaero-compare-three`）。摩擦の軸力は :math:`\alpha=0` のケースの壁面の摩擦応力の積分（底面を除く）で、粗さ 0 の Barrowman 法の摩擦の項と比べた。

サンプル機体（V8）
--------------------

``examples/sample_cfd.toml`` に ``model = "rans"`` を指定し、RANS の既定（``wall_size`` 5 mm、73.5 万節点）のまま、:math:`M=0.3,0.8,1.2,2` と :math:`\alpha=0,\pm4^\circ,\pm8^\circ` の 20 ケースを解いた（4 ランク、2 ケースずつ同時）。全体の計算時間は 4.4 時間（ケースの時間の合計は 8.6 時間）である。
収束と判定されたケースは 15（75 %）で、基準の 90 % に届かない。残りの 5 ケースは係数の窓の平均を受け入れた状態（``unconverged``）で、失敗したケースはない。
:math:`M=0.3` の :math:`\alpha=0,-4^\circ,-8^\circ` と :math:`M=0.8` の :math:`\alpha=0` は残差と係数が周期的に振動し（リミットサイクル）、:math:`M=2` の :math:`\alpha=0` は残差の低下が止まった。同じ Mach 数の :math:`+4^\circ` と :math:`+8^\circ` は収束している。振動の原因は調べていない。
:math:`M=0.3` の表の値は、振動するケースの平均を含む。全ケースのデータは ``doc/data/cfd/rans_table_cases.csv`` と ``rans_table.csv`` にある。

:math:`C_N` は Euler より 0.7〜6.3 % 大きく、圧力中心の差は 13.1 mm（:math:`M=0.3` の :math:`8^\circ`。振動する :math:`-8^\circ` と組み合わせた値）以内、それ以外は 10 mm 以内である。5 mm の :math:`C_N` は 3 mm の値（V7）より :math:`M=0.8` で 1.2 %、:math:`M=2` で 0.7 % 大きく、メッシュ収束（V6）の傾向と合う。

**軸力。** 保存した燃焼後の軸力 :math:`C_A` は、壁面の :math:`C_{Fx}(\mathrm{wall})`\ （滑らかな壁の摩擦と、作り直した形状の圧力）に、部品積み上げ法の底面抗力と ``extra_cd`` を足した値で、粗さとフィンの縁の項を含まない。
Euler の表（設定の粗さ 60 μm の摩擦とフィンの縁の項を含む）より 27〜37 %（:math:`M\ge0.8`）小さい。作り直した形状の RANS の軸力には、部品積み上げ法から求めた二つの増分、すなわち粗さの増分（設定の粗さの摩擦と滑らかな壁の摩擦の差）と、フィンの縁の増分（設定の縁に対するフィンの縁の項から、弦長の 2 % で鈍くした縁がすでに持つ割合 7.8 % を引いたもの）を、迎角の係数をかけて足す。

再計算した RANS の軸力は、Euler の表に対して :math:`M=0.3` で 8〜16 %、:math:`M=0.8` で 3〜8 %、:math:`M=1.2` で 1〜4 % 大きく、:math:`M=2` では :math:`-1`〜:math:`+1` % である（:math:`\alpha=0,4,8^\circ` の範囲）。差は Mach 数が低いほど大きく、どの Mach 数でも迎角とともに小さくなる。
これは二つのモデルの相互比較で、差の原因は切り分けていない。Euler の側には、亜音速の圧力の軸力が非粘性の理論値 0 より小さくなる性質がある（:math:`M=0.3` で :math:`-0.03`〜:math:`-0.05`。:ref:`sec-lim-cfd`）。

.. _sec-cfd-rans-base:

底面（V5）
------------

底面の後流は、Herrin と Dutton の :math:`M=2.46` の円柱の底面圧力の測定と比べる予定であったが、実施していない。
この比較には、測定された底面の手前の境界層（ノーズのない風洞の後胴）を入口に与える必要があるが、CFD モードは STL のノーズつきの機体をメッシュにし、軸対称やくさび形の領域を持たないためである。
したがって、底面の圧力の積分（``rans_base = "cfd"``）は確かめておらず、既定の ``rans_base = "model"`` は部品積み上げ法の底面抗力を使う。Basic Finner の RANS の底面の力は :ref:`sec-validation-discussion` にある。

.. _sec-cfd-rans-cost:

メモリと時間
--------------

SU2 の RANS のケース（両方の段）の各ランクの使用メモリを 1 秒ごとに測った（``doc/data/cfd/rans_memory.csv``）。ランクの合計のピークから 1 ランクあたり 40 MB を引いて節点数で割ると、サンプル機体（8 mm と 4.8 mm）、フィンなし胴体、円すいで 10.1〜10.5 kB（平均 10.25 kB）である。
メモリの見積もりは、これに約 15 % の余裕を足したものである。サンプル機体の半モデルでは、3 mm（184 万節点）で約 22 GB、既定の 5 mm（73.5 万節点）で約 9 GB で、細かいメッシュで同時に解けるケースの数はメモリで決まる（:ref:`sec-cfd-rans-use`）。
1 ケースの計算時間は、5 mm の暖機起動で約 15〜30 分、冷えた起動で 30〜60 分である（4 ランク、2 ケースを同時。``doc/data/cfd/rans_table_cases.csv``）。
