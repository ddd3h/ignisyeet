降下方式
========

頂点のあとの降下を、弾道落下、単一のパラシュート、二段開傘（ドローグとメイン）のどれで飛ばすかが、着地点を最も大きく左右する。
弾道落下は約 1 分で着地するが、パラシュート降下は約 10 倍の時間をかけて風下へ流される。

----------

飛翔を :numref:`fig-phases` の段階に分け、段階ごとに異なる運動方程式を使う。

.. _sec-rail:

ランチャ滑走
------------

ランチャ上では、機体はレールの方向 :math:`\bm{d}`\ （:eq:`eq-rail-dir`）にしか動けず、姿勢も変わらない。
レールに沿った速さを :math:`v_\parallel=\bm{v}\cdot\bm{d}` として

.. math::
   :label: eq-rail

   \dot{\bm{v}} = a_\parallel\,\bm{d},\qquad
   a_\parallel = \frac{T\cos\varepsilon - C_A\,q\,S\,\sgn(v_\parallel)}{m} + \bm{g}\cdot\bm{d}

とする。:math:`\varepsilon` は推力のミスアライメント角（:ref:`sec-thrust-line`）で、:math:`C_A` は迎角 0 の値（一般表では :math:`-C_X`）である。
機体はレールに拘束されているので、推力の横成分とそのモーメントは姿勢に影響しない。
初期姿勢はレールの方向と ``launch.roll_deg`` で決まり（:ref:`sec-initial-attitude`）、ランチャ上ではこの姿勢のままである。
:math:`v_\parallel\le0` かつ :math:`a_\parallel<0` のとき（推力が重力に負けて静止しているとき）は :math:`a_\parallel=0` とする。
ステップの途中でレールの終端に達したときは、その時刻と状態をステップ内の補間で求めるので、離脱の時刻と速度は刻み幅にほとんど依存しない（:ref:`sec-step-events`）。
レールに沿った移動距離が :math:`\bm{x}\cdot\bm{d}\ge L_{\mathrm{rail}}` になった時刻にランチャを離れ、自由飛行に移る。
自由飛行は、この離脱の時刻と状態から始める。
離脱の状態の速さを **ランチャ離脱速度**、静安定余裕を離脱時の値として記録する。
燃焼が終わったあとも飛翔が続く間は、機体はレール上を進み続ける（慣性で残りの距離を進んで離れうる）。
燃焼終了後に機体のレールに沿った速度が 0 以下になった、つまりレールを離れずに滑り落ち始めた場合に限り、推力不足としてエラー（:ref:`IY-S080`）にする。

自由飛行
--------

:eq:`eq-translation` と :eq:`eq-euler` による 6 自由度の運動である。
弾道落下モードでは着地までこのまま計算する。

頂点のあとの弾道落下では、全迎角が 60° から 120° の間（流れに対して横向き）で飛んだ時間を ``summary.json`` の ``broadside_time`` [s] に積算する（ステップの始端の迎角で判定し、着地のステップは着地までの分だけ数える。パラシュート降下では 0）。
これが 10 s を超えた落下を「横向きに落ちた」とし、``fell_broadside`` を ``true`` にして、
警告（:ref:`IY-O509`）を出す。
横向きの落下は大迎角でのつり合い（トリム）で、その着地点は検証していない大迎角の空力係数で決まるからである（:ref:`sec-lim-aero`）。結果は使えないものとはせず、終了ステータスは変えない。

.. _sec-parachute:

パラシュート降下
----------------

頂点（:math:`v_z` の符号が正から負に変わった時刻 :math:`t_{\mathrm{apo}}`。補間で求める。:ref:`sec-integrators`）から遅れ :math:`\Delta t` の後に開傘する。
開傘の時刻は、刻み幅によらず正確に :math:`t_{\mathrm{apo}}+\Delta t` である。
開傘した時刻は ``summary.json`` の ``drogue_deploy_time`` に記録する。着地までに開傘しなかった（頂点 + 遅れより前に着地した）飛翔と、弾道落下では出力しない。

:math:`t_{\mathrm{apo}}+\Delta t` にモータがまだ燃えているとき（推力の終わりの時刻 :math:`t_{\mathrm{end}}` より前のとき）は、開傘を :math:`t_{\mathrm{end}}` まで遅らせる。
:math:`t_{\mathrm{end}}` は、推力曲線のうち推力が 0 でない最後の区間の終わりの点の時刻である（推力が 0 のまま続く末尾の点は数えない）。
パラシュート降下の運動方程式（:eq:`eq-parachute`）は推力を持たず、推進剤の消費も扱わないので、推力のある間に開傘すると、残りの推力と推進剤が消えてしまうからである。
遅らせた開傘は ``summary.json`` の ``deploy_delayed`` に、本来の開傘時刻 ``nominal_time``\ （:math:`t_{\mathrm{apo}}+\Delta t`）とその時刻の推力 ``thrust`` [N] として残し、
``the motor still burns at apogee + recovery.delay (t = 11.25 s, thrust 42.0 N): the parachute deployment is delayed to burnout at 12.50 s`` の形（数は例。二段開傘では ``the drogue deployment``）の警告を出す。
``drogue_deploy_time`` は遅らせた時刻 :math:`t_{\mathrm{end}}` である。燃焼時間が頂点より長い、推力の小さい長い燃焼のモータで起こる。
開傘後は機体をパラシュートに吊られた質点とみなし、

.. math::
   :label: eq-parachute

   \dot{\bm{v}} = -\frac{\rho\,|\bm{v}_a|\,(C_DS)_p}{2m}\,\bm{v}_a + \bm{g},\qquad \bm{v}_a=\bm{v}-\bm{w}

とする :cite:`knacke`\ （:math:`(C_DS)_p` は設定 ``cd_s``）。終端降下速度は :math:`v_t=\sqrt{2mg/(\rho\,(C_DS)_p)}` で、
サンプル機体（燃焼後 8 kg、:math:`(C_DS)_p=3.5\ \mathrm{m^2}`）では海面付近で約 6.0 m/s になる。
開傘の衝撃や、開傘までの過渡的な挙動は扱わない。開傘は瞬時に完了し、抗力面積は開傘の瞬間に :math:`0` から :math:`(C_DS)_p` へ跳ぶ（:ref:`page-theory-limitations`）。

.. _sec-dual-deploy:

二段開傘
--------

設定 ``main_cd_s`` と ``main_altitude`` を与えると、二段開傘（ドローグとメイン）になる。
``cd_s`` と ``delay`` のパラシュートがドローグで、頂点から ``delay`` 後に開傘する。
下降して射点からの高さ :math:`h` が ``main_altitude`` :math:`h_m`\ （射点からの高さ、AGL）に達すると、メインが開傘し、
ドローグの抗力面積をメインの抗力面積 :math:`(C_DS)_m`\ （``main_cd_s``）に **置き換える**\ （足し合わせない。ドローグはメインの後ろで切り離されるか、つぶれるとみなす）。

.. math::
   :label: eq-dual-deploy

   (C_DS)(h)=\begin{cases}(C_DS)_p & h>h_m\\ (C_DS)_m & h\le h_m\end{cases}

運動方程式は\ :eq:`eq-parachute` のままで、:math:`(C_DS)_p` を上の値に替える。
メインの開傘もドローグと同じく瞬時で、開傘の衝撃は扱わない。
メインの開傘は、高さが :math:`h_m` に達した時刻に起こり（刻み幅によらない）、そこからメインの抗力面積で続ける。
その時刻と高さ :math:`h_m` は ``summary.json`` の ``main_deploy_time`` と ``main_deploy_altitude`` に書く。
ドローグの開傘がすでに :math:`h_m` 以下で起きるとき（頂点が低いときなど）は、ドローグの開傘と同時にメインが開き、その時刻と高さを記録する。
ドローグとメインの終端降下速度は、それぞれ :math:`\sqrt{2mg/(\rho\,(C_DS)_p)}` と :math:`\sqrt{2mg/(\rho\,(C_DS)_m)}` である。
弾道落下ではメインを使わず、``main_deploy_time`` と ``main_deploy_altitude`` は書かない。
モンテカルロ解析の ``parachute_cd_s_scale`` は、``cd_s`` と ``main_cd_s`` の両方に同じ倍率を掛ける。

.. _sec-landing:

着地
----

ランチャ離脱後に高さ :math:`z_U` が正から 0 以下に変わった時刻を着地時刻として、計算を終える（ECEF モードでは測地的な高さ :math:`h-h_0` について同じ）。
着地の時刻、位置、速度は、ステップ内の補間（:eq:`eq-step-hermite`）で求めるので、刻み幅にほとんど依存しない。``trajectory.csv`` の最終行もこの着地の状態である。着地点は\ :eq:`eq-enu-basis` と :eq:`eq-ecef-lla` で緯度・経度に変換する。


降下方式と着地点
----------------

``ignisyeet sim`` は、設定した回収方式の飛翔を 1 回だけ飛ばす。
``ignisyeet dispersion`` は、回収が有効なら、開傘した場合（パラシュート降下）と開傘しなかった場合（弾道落下）の両方を同じ条件で計算する。
そのため、落下分散で降下方式を選ぶ必要はなく、選ぶのは ``sim`` の 1 回の飛翔と、回収系の値である。

方式ごとの着地点の感度を、サンプル機体（頂点約 4.4 km）の ``power`` の風、部品積み上げ法の係数表で比べる（数値は :ref:`sec-dispersion-safety` の計算例で、360 方位の格子での最大）。

* **弾道落下**：風見効果で風上側へずれるが、ずれは小さい（格子の最大 1549.6 m、7 m/s、270°）。頂点で失速して回転し、落ちる向きがわずかな条件で変わるので、着地点の多角形がいびつになることがある。
* **単一のパラシュート**：降下が長い（頂点 4.4 km から約 11 分）ので、ずれは弾道落下より 1 桁大きい（格子の最大 14315.6 m、7 m/s のべき法則の風）。風の高度分布に敏感で、終端降下速度は :math:`v_t\propto(C_DS)_p^{-1/2}` で効く。
* **二段開傘**：ドローグの降下が短いほどずれは小さい。回収系を ``recovery.cd_s = 0.5``、``recovery.main_cd_s = 8``、``recovery.main_altitude = 300`` にすると、格子の最大は 6188.9 m（7 m/s、90°）になる。
  落下分散では、正常な開傘に加えて、メインが頂点で開く故障（21626.0 m）とドローグだけの降下（5430.4 m）も計算して最大を採る。メインが頂点で開く故障では降下時間が約 3 倍（1021.5 s 対 331.9 s、北風 4 m/s の ``sim``）になり、この機体ではこれが半径を決める。

適用範囲と精度
--------------

* パラシュートは瞬時に開き、抗力面積は開傘の瞬間に 0 から :math:`(C_DS)_p` へ跳ぶ。開傘衝撃と開傘までの過渡的な挙動、ドローグの切り離しの動きは扱わない。
* 二段開傘は 2 段までで、メインはドローグの抗力面積を置き換えるだけである。三段以上の開傘や、気圧・加速度による開傘装置の誤作動は扱わない。
* 降下中の抗力はパラシュートの :math:`C_DS` だけで、機体の抗力は入れない。サンプルでは機体の :math:`C_DS` は約 0.004 m\ :sup:`2` で、パラシュート（3.5 m\ :sup:`2`）の約 0.1 % なので、着地点への影響は数 m の程度である。
* 風は水平方向の定常な風で、突風と乱流は考えない。着地は射点標高の面で判定し、地形の起伏は考えない（:ref:`sec-lim-env`）。
* ランチャ上の抗力はレールに沿った速さだけで求め（風を入れない）、チップオフとレールの摩擦は扱わない。
* 弾道落下で横向きに落ちる場合の着地点は、検証していない大迎角の係数で決まる（:ref:`sec-lim-aero`）。

全体の一覧は :ref:`sec-lim-motion` と :ref:`sec-lim-aero` の回収の項にある。

降下と着地の挙動は、解析解のある条件との検証で確かめている（:ref:`sec-verify-dual`）。パラシュート降下や弾道落下の着地点を実測の飛翔と比べた妥当性確認はない。

選び方
------

降下方式の高さの時間変化を :numref:`fig-descent-modes` に、方式ごとの注意点を :numref:`tbl-choose-descent` に示す。

.. _fig-descent-modes:

.. figure:: /_generated/tikz/descent_modes.*
   :width: 100%

   降下方式による高さの時間変化の概念図。橙が弾道落下、青が単一のパラシュート、緑が二段開傘である。
   見る点は、同じ頂点から、弾道落下は約 1 分で着地するのに対し、パラシュート降下は約 10 倍の時間をかけて着地すること、
   二段開傘は ``main_altitude``\ （:math:`h_m`）まではドローグの速さで落ち、そこから大きなメインに切り替わることである。

.. _tbl-choose-descent:

.. list-table:: 降下方式の選び方
   :header-rows: 1
   :widths: 18 40 42

   * - 方式
     - 警告
     - 保安距離での扱い
   * - 弾道落下（``ballistic``）
     - 頂点のあと全迎角 60°〜120° で 10 s を超えて飛ぶと警告（:ref:`IY-O509`）
     - 開傘しなかった場合として常に計算する。結果は除かない
   * - 単一のパラシュート
     - 燃焼中の開傘時刻は延期して警告（:ref:`IY-O517`）。着地速度が 15 m/s を超えると警告（:ref:`IY-O520`）
     - 半径を決めるのは通常このモードである
   * - 二段開傘
     - ``main_altitude`` が頂点より高いと、メインがドローグと同時に開く警告（:ref:`IY-O511`）
     - 正常な開傘、メインが頂点で開く故障、ドローグだけの降下を計算し、最大を採る

判断の目安は次のとおりである。

* **開傘の遅れ** ``delay`` **は短くしすぎない。** 頂点付近は速度が小さく、遅れは自由飛行のまま機体が頂点を過ぎる時間である。
  開傘の時刻が燃焼中になる設定（燃焼時間が頂点より長い小推力のモータ）は、燃焼終了まで延期され、警告が出る。
* **二段開傘の** ``main_altitude`` **は、ドローグでの降下速度と風に流される時間の兼ね合いで決める。** 高いほどメインの下で流される時間が長くなる。
* **抗力面積** ``cd_s`` **を実機の値より大きく見積もると、** 降下が遅くなり、風下のずれを過大に見積もる。
  回収系のばらつきは ``parachute_cd_s_scale`` で与える（:ref:`page-theory-dispersion`）。
* 着地速度が 15 m/s を超える機体は ``cd_s`` を見直す。

関連する設定
------------

降下方式は ``sim.descent``\ （``"parachute"`` または ``"ballistic"``）で選び、省略すると回収が有効ならパラシュート、無効なら弾道落下になる。
``recovery.enabled`` は回収の有無で、``false`` にすると落下分散は弾道落下だけを計算する。
``recovery.cd_s`` はパラシュートの抗力面積（サンプルは 3.5 m\ :sup:`2`）で、二段開傘ではドローグの値になる。
``recovery.delay`` は頂点から開傘までの遅れ（サンプルは 1.0 s）である。
``recovery.main_cd_s`` と ``recovery.main_altitude`` を両方与えると二段開傘になる。
ランチャ離脱速度は ``launch.rail_length``\ （サンプルは 5 m）と ``launch.elevation_deg`` で決まり、5 m、射角 85° で 45.7 m/s である。
各キーの型と範囲は設定ファイルの章（:ref:`cfg-recovery-cd_s`）にある。
