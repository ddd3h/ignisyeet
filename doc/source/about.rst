IgnisYeet について
====================

開発の方針とライセンス
------------------------

IgnisYeet はどの団体・組織にも属さないオープンソースソフトウェアとして開発している。
飛翔シミュレーションの結果は、保安域の設定や打上げの可否判断といった **安全に直結する判断** の根拠になる。
だからこそ、計算に使うモデル・式・仮定はすべて公開し、誰でも検証できる状態にしておくべきだと考える。

本ドキュメントは、その「検証できる状態」を支えるためのものである。
理論と解説の部では、計算に使う式を示し、どの文献のどの手法に基づくか、どこに近似や限界があるかを明記する。
ソースコードは次の場所で公開している。

    https://github.com/ddd3h/ignisyeet

改良や誤りの指摘は Issue や Pull Request で歓迎する。

**ライセンス**\ ：IgnisYeet は GNU GPL バージョン 3 またはそれ以降（GPL-3.0-or-later）で公開している。
これに加えて、GPLv3 第 7 条 (b) に基づく追加条件として、著作者表示と著作権表示（「IgnisYeet by 西濱大将 (NISHIHAMA Daisuke)」）を、
ソースファイル、ドキュメント、プログラムの起動時の表示と ``--version`` の出力に残すことを求める。
引用と作者への連絡は、条件ではなく **お願い** である。守らなくても GPL が与える権利には影響しない。
全文と詳細は、リポジトリの ``LICENSE``、``NOTICE``、``CITATION.cff`` にある。

本書の読み方
------------

本書は五つの部と開発者向けの部でできている。入口の選び方は :ref:`読者別の入口 <page-index-entry>` にある。
結果を使う前に、:ref:`page-theory-limitations` に目を通してほしい。現時点のモデルが扱えないことと、仮定が崩れる条件を一覧にしてある。

記法と用語
----------

* 設定ファイルのキーと値、コマンド、ファイル名は ``等幅`` で書く。キーは ``[aero.panel]`` の ``body_axial`` のように、表の名前とキーの名前で指す。
* 長さは m、角度は度（式の中ではラジアン）、静安定余裕は機体の基準直径に対する倍（cal）で表す。符号と座標系は :ref:`page-reference-symbols` と :ref:`page-theory-coordinates` にある。
* 「検証」は、モデルと解析解・手計算・別のモデルとの比較を指す。「相互比較」は検証のうち、別のモデルどうしの比較である。「妥当性確認」は実測との比較だけを指す。
  詳しい定義と、各モデルにどの比較があるかは :ref:`page-vv` にある。
* 数値を挙げた箇所には、条件（Mach 数、迎角、機体、メッシュ）を付けた。条件のない数値は、サンプル機体（``examples/sample.toml``）の値である。
