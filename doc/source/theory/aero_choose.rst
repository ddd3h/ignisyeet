空力手法の選び方
==================

機体に働く空気力は、機体の形から推算する。設定 ``aero.method`` は、その推算に使う手法を選ぶ。
手法は部品積み上げ法・パネル法・CFD・外部の表の四つで、どれも同じ形式の係数表を作る。
手法によって、解く物理、成り立つ Mach 数と迎角の範囲、計算にかかる時間、実測との差が違う。
本章は、この違いを示し、目的に合う手法を選ぶ根拠を述べる。
係数の定義は :ref:`page-theory-aero-coefficients`、表の種類と内挿は :ref:`page-theory-aero-tables` にある。
各手法のモデルは :ref:`page-theory-barrowman`、:ref:`page-theory-panel`、:ref:`page-theory-cfd-choose` で述べる。

この章で決めること
--------------------

決めるのは、設定 ``aero.method``\ （:ref:`cfg-aero-method`）の値である。

* ``"barrowman"``：部品積み上げ法（既定）
* ``"panel"``：パネル法
* ``"cfd"``：SU2 による CFD（Euler または RANS）
* ``"table"``：風洞試験などで得た外部の係数表

``"cfd"`` を選んだときの Euler と RANS、壁面の与え方、メッシュは :ref:`page-theory-cfd-choose` で決める。
係数表を軸対称表と一般表のどちらにするか、格子の刻みと範囲をどうするかは :ref:`page-theory-aero-tables` で決める。
どの手法も、実機の係数を保証しない。差の大きい量は不確かさが大きいと考え、その幅を落下分散の ``cn_scale`` と ``ca_scale``\ （:ref:`cfg-dispersion-monte_carlo-cn_scale`、:ref:`cfg-dispersion-monte_carlo-ca_scale`）に反映する。

選び方
--------

手法は、実測の表の有無、機体の形、通る Mach 数、計算に使える時間と道具で選ぶ。
:numref:`fig-choose-aero-method` の質問に上から順に答えると、手法が決まる。

.. _fig-choose-aero-method:

.. figure:: /_generated/tikz/aero_choose_flow.*
   :width: 100%

   ``aero.method`` の選び方。左の列の質問に上から答える。右の箱が選ぶ手法で、右端に Basic Finner の実測（Mach 1.08 から 4.30）との :math:`C_{N\alpha}` の差を添えた（:ref:`sec-aero-accuracy-measured`）。
   Q1 で「はい」なら ``table``、Q2 で「いいえ」なら形状を直接扱う ``cfd`` に進む。Q3 と Q4 の「はい」は、それぞれ ``cfd`` と ``panel`` を選ぶ。

質問の意味と、迷ったときの考え方を次に挙げる。

Q1 外部の係数表を使うか
   風洞試験や他の解析で得た係数表があり、それを飛翔計算に使いたいときだけ ``table`` を選ぶ。
   形状の抽出も空力の計算も行わず、読み込んだ表をそのまま使う（:ref:`sec-aero-external`）。
   推算の手法ではないので、精度は表を作った試験や解析で決まる。

Q2 形状が仮定の範囲にあるか
   部品積み上げ法とパネル法は、軸対称の胴体と、軸まわりに配置した薄い台形のフィンを仮定する。
   ポッド、ランチラグ、非対称なフィンの配置は、抽出した形状に入らない（:ref:`page-theory-geometry`）。
   そのような形を係数に反映するには、STL や STEP の形状をそのまま解く ``cfd`` を選ぶ。

Q3 CFD でなければならない条件があるか
   次のどれかに当てはまるとき、``cfd`` を選ぶ。

   * 飛翔が遷音速（Mach 0.8 から 1.2）を通り、その区間の抗力と安定が結論を左右する。部品積み上げ法とパネル法は、この区間の物理を計算せず、両側の値を補間する。
   * フィンが大きい、胴体が太いなどで、フィンと胴体の干渉が結果に効く。部品積み上げ法は干渉を一つの係数で表し、パネル法は超音速で干渉を胴体の吹き上げだけで表す。
   * 結果を保安距離の判断など安全に直結する用途に使う。実測との差が最も小さい手法を使い、独立な手法で確かめる。

   Euler 方程式（既定）は非粘性なので、摩擦抗力と底面抗力は部品積み上げ法の項で補う。
   摩擦抗力を CFD から得たいときだけ RANS を選ぶ（選び方は :ref:`page-theory-cfd-choose`）。

Q4 設計の途中か、確認の段階か
   形状を変えながら比べる設計の初期は、計算が一瞬で終わる ``barrowman`` が向く。
   静安定余裕が目標に近いとき、あるいは別の手法との差を不確かさの目安にしたいときは、仮定が独立な ``panel`` でも計算する。
   二つの手法の静安定余裕は、小さいほうで判断すると安全側になる（サンプル機体の差は約 0.3 cal。:ref:`sec-vaero-compare-three`）。

三つの推算手法は、次の順に使い分けるのが基本である。

1. **部品積み上げ法で始める。** 速く、外部のプログラムが要らない。形状を変えながら設計を進める段階に向く。
2. **パネル法で比べる。** 仮定が部品積み上げ法と独立なので、両者の差を推算の不確かさの目安にできる。
3. **遷音速・重要な条件は CFD で確かめる。** Mach 数と迎角の点を絞って解き、その間は表で補う。

手法の選び方は、通る Mach 数にも依存する。:numref:`fig-aero-regime-map` に、手法ごとの Mach 数の範囲と、各範囲で使える比較の根拠を示す。

.. _sec-aero-flow:

モデル
--------

空力解析は、形状情報から係数表を作る段階と、飛翔計算が表を内挿する段階に分かれる。
設定 ``aero.method`` で選んだ手法が、STL から取り出した寸法（半径分布、フィンの平面形、機体軸）または STL そのものから係数を求め、係数表にまとめる（:numref:`fig-aero-flow`）。
外部の表だけは形状を使わず、読み込んだ表をそのまま使う。
飛翔計算（6 自由度の剛体運動）と落下分散は、表の内挿と外挿だけを行う。

.. _fig-aero-flow:

.. figure:: /_generated/tikz/aero_flow.*
   :width: 100%

   空力解析の構成。形状情報から四つの手法のどれかで係数表を作り、飛翔計算は表だけを使う。どの手法も同じ形式の表を作るので、飛翔計算は表がどの手法で作られたかを区別しない。

なぜ係数表を先に作るのか
~~~~~~~~~~~~~~~~~~~~~~~~

飛翔計算は時間刻みごとに何度も係数を必要とする。一方、係数は形状と気流の条件だけで決まり、飛翔の途中で形状は変わらない。
そこで、係数を格子上で一度だけ計算しておき、飛翔計算では表の内挿だけを行う。
こうすると、空力モデルの計算の重さと飛翔計算の重さが切り離され、重い手法に置き換えても飛翔計算側は変わらない。
全体のモデルの構成は :ref:`page-theory-overview` にある。

.. _sec-aero-methods:

四つの手法
~~~~~~~~~~

三つの推算手法は、機体のまわりの流れをどこまで物理方程式で解くかが違う。
部品積み上げ法は流れを解かず、部品ごとの経験式と細長体理論の和で係数を作る。
パネル法は機体の表面だけで流れを解き、CFD は機体のまわりの空間全体で解く。
解く範囲が広いほど干渉や衝撃波が自然に入るが、計算の時間と準備が増える。
外部の表は、これらの代わりに実験などで得た係数をそのまま与える。

部品積み上げ法（``method = "barrowman"``、既定、:ref:`page-theory-barrowman`）
   機体をノーズ・胴体・フィン・ボートテールといった部品に分ける。部品ごとの法線力と圧力中心を細長体理論や経験式で求め、\ :eq:`eq-cp-sum` で足し合わせる :cite:`barrowman,niskanen`\ 。
   抗力も部品ごとの経験式の和である。計算は一瞬で終わり、経験式の範囲内では安定した値を返す。
   一方で、使うのは抽出した寸法（半径分布とフィンの平面形）だけで、表面の形そのものは使わない。フィンと胴体の干渉は一つの係数で表す。

パネル法（``method = "panel"``、:ref:`page-theory-panel`）
   抽出した形状から閉じた表面メッシュを作り、その上で流れを解く。
   亜音速では、非粘性・渦なしのポテンシャル流を Morino の定式化 :cite:`morino` で解き、Göthert の変換 :cite:`gothert` で圧縮性を入れる。
   超音速では、各パネルの傾きから圧力を決める局所傾斜法を使う。
   フィンと胴体の干渉やノーズの形は、表面の形から自然に入る。粘性は扱わず、遷音速は両側の値の補間である。

CFD（``method = "cfd"``、:ref:`page-theory-cfd-choose`）
   機体のまわりの空間を体積メッシュで覆い、圧縮性 Euler 方程式（または RANS 方程式）を外部プログラムの SU2 :cite:`su2` で解く。
   衝撃波や遷音速の流れ、フィンと胴体の干渉を、物理方程式から直接得られる。
   形状は、抽出した寸法から作り直すか、STL や STEP をそのまま使う。
   横滑りとロールのケースも解き、6 成分の一般表を作れる。
   ただし、1 ケースに数分から十数分かかる（表全体はケース数に比例する）。SU2・gmsh・Open MPI の準備も要る。
   Euler では、摩擦抗力や底面抗力を部品積み上げ法の項で補う。RANS では、壁面にプリズムの境界層を置いたメッシュで摩擦抗力も解く（作り直した形状だけ）。

外部の表（``method = "table"``）
   風洞試験などで得た係数表を読み込む。形状の抽出と空力モデルの計算は行わない（:ref:`sec-aero-external`）。

次の点は、どの手法を選んでも共通である。

* 係数表の Mach 数と迎角の範囲は、設定 ``aero.mach_max`` と ``aero.alpha_max_deg``\ （:ref:`cfg-aero-mach_max`、:ref:`cfg-aero-alpha_max_deg`）で決まる。飛翔がこの範囲の外の条件を引くと、結果は使えないものとして終了ステータス 3 で終わる（:ref:`IY-O022`、:ref:`IY-O024`。:ref:`sec-aero-out-of-range`）。
* 頂点のあとの弾道落下は機体が横向き（迎角 90° 近く）になるので、``aero.alpha_max_deg`` は既定の 90 のままにする。
* 遷音速の補間は、遷音速の物理（衝撃波の発生、:math:`C_{N\alpha}` のピーク位置）を計算しない。パネル法はとくにピークを過大にしうる（サンプル機体の :math:`M=1.2` で、:math:`C_{N\alpha}` が Euler の CFD より 18.5 % 大きい）。
* 実測で確かめた Mach 数の範囲は 1.08 から 4.30 だけで、亜音速には実測との比較がない（:ref:`sec-aero-accuracy-measured`）。
* Euler の CFD は非粘性で、摩擦抗力と底面抗力を経験式で補う。RANS は Basic Finner では Mach 1.832 の 1 点しか収束していない。

仮定と適用範囲の全体は :ref:`sec-lim-aero`、:ref:`sec-lim-panel`、:ref:`sec-lim-cfd` にある。

精度の証拠
------------

手法の精度は、実測との比較（妥当性確認）と、手法どうしの相互比較で調べている。
前者は実測がある量と範囲に限られ、後者は同じ仮定の上での比較で、どちらが実機に近いかは決まらない。

.. _sec-aero-accuracy-measured:

     - :math:`-25` から :math:`-34` %
     - :math:`-15` から :math:`-28` %
   * - :math:`C_{lp}`\ （ロール減衰）
     - Mach 1.83〜3.15 で :math:`-8` から :math:`+5` %。Mach 3.73 と 4.30 で絶対値が 13〜15 % 小さい。Mach 1.08 と 1.29 で絶対値が 46〜92 % 大きい
     - 部品積み上げ法と同じ値（ロール項は部品積み上げ法）
     - :math:`-12` から :math:`+11` %（正は絶対値が小さい側）

この結果から次のことが分かる。

* **法線力傾斜**\ ：Euler は 3 から 11 % 小さいだけで、部品積み上げ法とパネル法は 2〜3 割小さい。フィンと胴体の干渉と、胴体の円筒部の揚力を線形理論が表せないことが主な理由である（:ref:`sec-validation-discussion`）。
* **圧力中心**\ ：三つの手法とも実測と 4 % 以内で合う。:math:`C_{m\alpha}` の差は、:math:`C_{N\alpha}` の不足をそのまま受ける手法ほど大きい。
* **零揚力の軸力**\ ：三つの手法とも小さい。不足は主に底面抗力にあり、非粘性の Euler では求まらない。
* **ロール減衰**\ ：Mach 1.83 から 3.15 では部品積み上げ法も実測に近い。低い超音速（Mach 1.08 と 1.29）は、翼端の Mach 円すいがフィン全体を覆い、部品積み上げ法の式が荷重の低下を表せない。

この比較の限界を次に挙げる。実測の結果を、形の違う機体や亜音速にそのまま当てはめることはできない。

* 実測がある Mach 数は超音速の 8 点で、亜音速の静的な係数の実測との比較はない。遷音速の :math:`C_{N\alpha}` のピーク（Mach 1.25 付近）も、射場の試験では捉えていない。
* 形状は 1 種類である。フィンの後縁が底面と同じ面にある厚いくさび断面の矩形フィンで、後退角のあるフィンやボートテールは含まない。
* RANS は Mach 1.832 の 1 点だけが収束した。RANS の誤差を Mach 数の範囲で評価することはできない。
* :math:`C_{lp}` の比較は、角速度の無次元化を実測との一致から推定したうえでの比較である（:ref:`sec-validation-limits`）。
