.. _sec-validation:

空力の妥当性確認（Basic Finner）
================================

この章は、空力係数の推算法（部品積み上げ法、パネル法、CFD の Euler と RANS）の値を、Basic Finner の実測値と比べた結果をまとめる。
実測と比べるので、この章の比較は **妥当性確認** である。
実装が式どおりに動くかの検証と、手法どうしの相互比較は :doc:`verification_aero` にある。

Basic Finner は、10 口径の円すい・円柱の胴体に矩形フィン 4 枚を付けた標準模型で、超音速の空力の基準として多くの試験に使われてきた。
実測値は Dupuis と Hathaway の弾道射場の自由飛行試験 :cite:`dupuis1997basicfinner` の Mach 1.08 から 4.30 の値と、
Regan の風洞のロール減衰 :cite:`regan1964rolldamping` である。
亜音速の実測値はない（:ref:`sec-validation-limits`）。

データ、計算の出力、比較の表は ``doc/data/validation/basic_finner/`` に、計算に使った設定と形状は ``examples/basic_finner/`` にある。

     - 長さ d = 30 mm、面積 :math:`S=\pi d^2/4`。ピッチングモーメントは先端から 5.50 口径（0.165 m、模型の重心）まわり

``examples/basic_finner/`` の STEP（``basic_finner.step``）と STL（``basic_finner.stl``）は ``make_basic_finner.py`` が gmsh で作る。
STEP は図面の形状（くさびの断面、後縁の厚さ 2.4 mm）をそのまま持つ。
STL から取り出したフィンは図面の寸法になり、厚さは断面の中央値の 1.3 mm（後縁の厚さの約半分）である。
部品積み上げ法とパネル法はこの取り出したフィンを使い、CFD の壁面は STEP の形状である。
CFD の係数表に足す摩擦と底面の項、Euler のフィンの面の要素の大きさ（``fin_size`` の既定 = 厚さ/4 = 0.34 mm）も、取り出したフィンから決まる。

.. _sec-validation-data:

実測データと信頼性
------------------

**射場の値**\ 。:cite:`dupuis1997basicfinner` は DREV の弾道射場で 25 発の自由飛行を撮影し、6 自由度の最尤法で係数を求めた。
使うのは、同じ Mach 数付近の 2–3 発を同時に当てはめた Table IX の 8 点（Mach 1.077、1.293、1.832、2.375、2.718、3.147、3.734、4.300）である。
長さ基準の Reynolds 数は 7.0×10\ :sup:`6` から 3.0×10\ :sup:`7`、最大の迎角は 0.7–9.0° である。
Table IX には各係数の確率誤差（probable error、%）が付いている。CNα は 1–4 %、Cmα、CX0、Clp は 0–1 % である。
確率誤差は当てはめの統計的な誤差で、発ごとのばらつきや系統誤差を含まない。

**表の値と推定した値**\ 。比べる量の出どころを :numref:`tbl-validation-sources` に分けて示す。

.. _tbl-validation-sources:

.. list-table:: 比べる量の出どころ
   :header-rows: 1
   :widths: 18 82

   * - 量
     - 出どころ
   * - CNα、Cmα
     - Table IX の値そのまま（1/rad）。Cmα は 5.50 口径まわり
   * - :math:`x_{cp}`
     - Table IX の CNα と Cmα から求めた値（:math:`5.50-C_{m\alpha}/C_{N\alpha}` 口径）。確率誤差はない
   * - CX0

   * - Clp（射場）
     - Table IX の値。角速度の無次元化（:math:`pd/(2V)` か :math:`pd/V` か）は報告書に書かれておらず、:math:`pd/(2V)` と **推定** した（根拠は ``sources.md``）
   * - Clp（風洞）
     - :cite:`regan1964rolldamping` の Table 2 の迎角 0 の値を、フィンの面積とスパンの基準から d と :math:`S` の基準に換算した値。スパンを全幅と読んだ換算は **推定** で、射場の値と 10 % 程度で合うことを根拠にした

Clp の無次元化と換算の根拠、表の読み取りの確認、注意点（ロールの減衰しない発、フィンの融損）は ``doc/data/validation/basic_finner/sources.md`` にまとめた。

.. _sec-validation-method:

計算の方法
----------

``examples/basic_finner/basic_finner.toml`` から次の係数表を作り、Table IX の Mach 数の値を比べた（:numref:`tbl-validation-methods`）。

.. _tbl-validation-methods:

.. list-table:: 比べた手法と設定
   :header-rows: 1
   :widths: 18 82

   * - 手法
     - 設定と値の取り方
   * - 部品積み上げ法
     - ``aero.method = "barrowman"``。迎角 0 の行を Mach 数について線形補間した
   * - パネル法
     - ``aero.method = "panel"``。同上
   * - CFD（Euler）
     - ``aero.method = "cfd"``、``surface = "step"``、``wall_size`` 1.5 mm（0.05 口径）、``fin_size`` 0.34 mm、1/4 領域のメッシュを :math:`z=0` で鏡映した半領域（約 56 万セル）。
       Mach 数は Table IX の 8 点、迎角は 0、2、4°。底面は ``base_treatment = "fairing"``\ （比べるために ``"flat"`` も解いた）。
       CNα は :math:`\alpha=2^\circ` の :math:`C_N/\alpha`、:math:`x_{cp}` は同じケースの圧力中心
   * - CFD（RANS）
     - ``model = "rans"``、``wall_size`` 1.5 mm、:math:`y^+=1`、平らな底面、半領域。Mach 1.832、2.375、3.147 の :math:`\alpha=0,2^\circ`\ （``alpha_mode = "single"``）
   * - ロール減衰（Euler）
     - ``roll_damping = true``、``wall_size`` 2.1 mm、``fin_size`` 0.47 mm、全領域（約 66 万セル）。Mach 数は Table IX の 8 点

``wall_size`` は胴体の直径に対して決めた。サンプル機体（直径 100 mm）の RANS の既定 5 mm と同じ 0.05 口径である。
大気は US 標準大気 1976 の海面の値（音速 340.3 m/s）で、射場の空気（音速 343.4–344.0 m/s、密度 1.16–1.20 kg/m\ :sup:`3`）とほぼ同じである。摩擦の項の Reynolds 数は Mach 2.375 で :math:`1.7\times10^7`\ （全長基準）で、射場の範囲に入る。

**軸力の組み立て**\ 。Euler は粘性を含まないので、係数表の CX0 は、CFD が壁面に積分した圧力の軸力（ノーズ、胴体、フィン）に、部品積み上げ法の摩擦抗力と胴体の底面抗力を足したものである（:ref:`sec-cfd-trust`）。
RANS は壁面の圧力と摩擦を CFD で積分し、底面の項を ``rans_base`` で選ぶ。``"model"`` は部品積み上げ法の底面抗力、``"cfd"`` は CFD が底面に積分した圧力の力である。
RANS の壁面は滑らかな壁なので、部品積み上げ法の粗さ（``roughness`` 2 µm）による摩擦の増分を足す。
どちらも 1 回の計算の ``axial_breakdown`` から求まるので、両方を示す。

STEP のモデルでは、底面と同じ面にあるフィンの後縁は、底面と一つの平らな面になる。
CFD はこの面全体を底面（``base``）として扱い、力を積分しない。
そのため、Euler と ``rans_base = "model"`` の RANS の CX0 には、フィンの後縁の底面抗力がどこにも入らない（:ref:`sec-validation-discussion`）。

``"fairing"`` では、円すいを胴体の底面の円の縁の 98 % から付け、フィンの後縁の面は底面に残る（:ref:`sec-cfd-stl-base`）。

比較の値は ``doc/scripts/basic_finner_compare.py``\ （部品積み上げ法とパネル法）と ``doc/scripts/basic_finner_cfd.py``\ （CFD と全体のまとめ）が作る。量の定義はスクリプトの説明にある。

  増えるのは、とがったフィンの前縁（半径 0.12 mm）のまわりの圧力が細かいメッシュで解像されるためと考えられるが、面ごとの内訳は確かめていない。
* 1 ケースは 0.5–3 分（4 ランク）で、1 ケースのメモリの見積もり（:eq:`eq-cfd-mem`）は L2 で 2.0 GB、L4 で 6.1 GB である。

**底面の扱い**\ 。比較には ``"fairing"`` を使う。``"flat"`` は形状を変えないが、平らな底面の後ろの非粘性の流れが定まらず、
力が落ち着いたことを確かめる受け入れの判定（:ref:`sec-cfd-int-convergence`）で、24 ケースのうち 3 ケースが失敗し、11 ケースは窓の平均の受け入れになった。
ロール減衰の 2 ケースも Mach 2.718 以上で失敗した。``"fairing"`` は 24 ケースすべてが収束した。
両者の差は、Mach 1.83 以上で :math:`C_N` が 1 % 程度（``"flat"`` が大きい）、:math:`C_{A,p}` が 0.5 % 未満、:math:`C_{lp}` が 1 % 程度である（Mach 1.293 の ``"flat"`` のロール減衰は 8 % 小さいが、受け入れの窓の値である）。
Mach 1.077 と 1.293 では、``"flat"`` の :math:`C_{A,p}` が 0.027 と 0.006 大きい。
CX0 の底面の項はどちらでも部品積み上げ法の同じ値なので、底面の扱いの選び方は CX0 の差（実測との差 20–35 %）をほとんど変えない。

.. _sec-validation-discussion:

考察
----

法線力傾斜 :math:`C_{N\alpha}`
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

* **部品積み上げ法**\ は Mach 1.83–4.30 で 20–35 %、Mach 1.08 と 1.29 で 31 % 小さい。
  超音速の不足は、``cna_decomposition.csv`` の内訳で説明できる。部品積み上げ法は胴体を細長体の 2 とし、フィンを平板の Ackeret の傾きに翼端の損失と Barrowman の干渉係数 :math:`1+r/(s+r)` を掛けて求める。
  文献の線形理論の積み上げ（特性曲線法の胴体、くさびの厚みの 2 次の効果、細長体理論の :math:`K_{W(B)}` と後部の胴体のない :math:`K_{B(W)}`）は、Mach 2 で胴体の円筒部の揚力（+0.58）、干渉（+0.29）、フィンの厚み（+0.36）を足し、実測との差を 9–16 % に縮める。
  残りは線形理論の外（接合部と翼端の三次元の効果、粘性）である。
  Mach 1.08 と 1.29 は翼端の Mach 円すいが根元に届く範囲で、部品積み上げ法の遷音速の補間が実測の高い値（18.3–18.5）を表さない。
* **パネル法**\ は Mach 1.83–4.30 で 18–34 %、Mach 1.08 と 1.29 で 19–20 % 小さい。
  超音速のフィンは胴体の吹き上げを入れた局所傾斜法で、胴体の円筒部の揚力と :math:`K_{B(W)}` を含まず、フィンの断面は両凸なので、部品積み上げ法との差は 1–3 % にとどまる。
* **Euler** は 2–10 %（平均 6 %）小さく、部品積み上げ法とパネル法の不足の大部分を取り戻す。
  線形理論で足りなかった非粘性の効果（胴体の揚力、干渉、厚み、三次元の効果）は、Euler の解にすべて入るからである。
  残りの差は、メッシュによる分（:ref:`sec-validation-mesh` で 1 % 程度）より大きく、確率誤差（1–4 %）の 2–4 倍のことが多い。
  候補は、粘性（フィンの境界層の排除厚さ、後縁付近のはく離）と、傾きの取り方（Euler は :math:`\alpha=2^\circ` の割線、実測は最大 9° までの運動に Cmα の 3 次の項とともに当てはめた線形の項）である。
  Mach 2.375 の実測は前後の Mach 数の傾向より高く、どの手法でも差が大きく出る。

圧力中心とピッチングモーメント
~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~

* :math:`x_{cp}` はどの手法も実測と 0.3 口径以内（−2.4 から +3.6 %）で合う。
  部品積み上げ法の :math:`x_{cp}` は −2.4 から +2.4 % に収まるが、:math:`C_{m\alpha}` は :math:`C_{N\alpha}` の不足をそのまま受けて 21–37 % 小さい。
  パネル法は :math:`x_{cp}` が 1–4 % 後ろ寄りで、:math:`C_{m\alpha}` は 15–28 % 小さい。
* Euler の :math:`C_{m\alpha}` は Mach 1.29–4.30 で −3 から +4 % に収まり、Mach 1.08 だけ 12 % 小さい。
  :math:`C_{N\alpha}` より合うのは、Euler の :math:`x_{cp}` がわずかに後ろ（Mach 1.83 以上で −0.01 から +0.11 口径）にあり、:math:`C_{N\alpha}` の不足を腕の長さが打ち消すためでもある。
  重心が圧力中心から 1.0–2.9 口径前にあるので、:math:`x_{cp}` の 0.1 口径の差は :math:`C_{m\alpha}` の 3–10 % にあたる。
  :math:`C_{m\alpha}` の一致は、:math:`C_{N\alpha}` と :math:`x_{cp}` を別々に見て判断する。

零揚力の軸力 :math:`C_{X0}`
~~~~~~~~~~~~~~~~~~~~~~~~~~~

* どの手法も 20–38 % 小さい。Euler の :math:`C_{X0}` は部品積み上げ法とほぼ同じである。
  Euler の圧力の軸力（ノーズの造波抗力とフィンの圧力の抗力）は部品積み上げ法のノーズとフィンの項とほぼ等しく、摩擦と底面の項は同じ部品積み上げ法の値だからである。
* Mach 2.375 の内訳は、Euler の圧力の軸力 0.131、部品積み上げ法の摩擦 0.089（乱流、:math:`Re_L=1.7\times10^7`）、胴体の底面 0.105（合計 0.325）で、実測の 0.484 より 0.159 小さい。
  不足の候補は次の三つで、大きさの見積もりを足すと不足とほぼ同じになる。

  * **フィンの後縁の底面抗力（約 0.06）**\ 。後縁の切り落とし（4 枚で :math:`0.41S`）は底面と一つの面になり、CFD は力を積分しない。部品積み上げ法の項も足さないので、どこにも入らない（:ref:`sec-validation-method`）。
    二次元の底面の式 :math:`(1-0.52M^{-1.19})/M^2` で見積もると 0.059 である。
  * **胴体の底面抗力の過小評価（約 0.08）**\ 。部品積み上げ法の底面の項は :math:`0.25/M`\ （Mach 2.375 で 0.105）である。フィンが底面にある機体の自由飛行の底面の圧力係数 −0.185（Mach 2、:cite:`barrowman` Fig. 4-8）を使うと 0.185 になる。
  * **メッシュ（約 0.02）**\ 。圧力の軸力は L2 から細かくすると増え、外挿値は 0.150 である（:ref:`sec-validation-mesh`）。

  底面の圧力は非粘性の Euler では求まらないので、CX0 の妥当性確認は、底面を含めて解く RANS と底面抗力の経験式の精度で決まる。
  Euler の係数表を CX0 に使うときは、底面とフィンの後縁の抗力を外部の値で補うのがよい。
* 部品積み上げ法の CX0 は、Mach 1.83–4.30 で、フィンの厚さを図面どおり 2.4 mm にすると 19–30 % 小さくなる（取り出したフィンでは 23–34 %）。後縁の底面の項が厚さに比例するためである。

RANS_DISCUSSION

ロール減衰 :math:`C_{lp}`
~~~~~~~~~~~~~~~~~~~~~~~~~

* 部品積み上げ法（パネル法も同じ値）は Mach 1.83–3.15 で −8 から +5 %、Mach 3.73 と 4.30 で 13–15 % 小さく、Mach 1.08 と 1.29 で 46–92 % 大きい。
  フィンの法線力傾斜から作るストリップ理論で、翼端の損失を荷重に一様に掛けるので、翼端の Mach 円すいがフィン全体を覆う低い超音速で、減衰への寄与が大きい外側の荷重の低下を表さない。
* Euler の回転座標系の解は Mach 1.08 と 1.29 で 12–13 % 大きく、Mach 1.83–3.15 で −3 から +4 %、Mach 3.73 と 4.30 で 9–10 % 小さい。
  低い超音速の大きな過大は解消する。Mach 3.73 と 4.30 の不足は部品積み上げ法と同じ向きで、粗い ``wall_size``\ （2.1 mm）の影響は確かめていない。
* :math:`C_{lp}` の比較は、無次元化を :math:`pd/(2V)` と推定したうえでの比較である（:numref:`tbl-validation-sources`）。
  Regan の風洞の値（換算）は射場の値より 10 % 程度小さく、両者の差は手法の差と同じ程度である。



.. _sec-validation-limits:

限界
----

* **亜音速の静的な係数がない**\ 。亜音速から Mach 4.5 の射場と風洞の値を含む :cite:`dupuis2002basicfinner` は入手できなかった。亜音速の CNα、Cmα、CX0 の妥当性確認はできていない。
  遷音速の山（Mach 1.25 付近）も射場の試験では捉えていない。
* **超音速の 8 点だけである**\ 。Mach 1.08 と 1.29 は 2–3 発の当てはめで、群の中でも Mach 数が変わる（CmαM、CXM で表されている）。
* **CX0 の比較は底面抗力の推算に強く依存する**\ 。底面とフィンの後縁の圧力は、Euler では求まらず、RANS でも乱流モデルの精度に依存する。
* **減衰の比較は無次元化の推定に依存する**\ 。Clp と Cmq の無次元化は報告書に書かれておらず、推定した（:numref:`tbl-validation-sources`）。
* **形状は 1 種類である**\ 。フィンの後縁が底面と同じ面にある、厚いくさび断面の矩形フィンの機体で、後退角のあるフィンや、底面の前で終わるフィン、ボートテールは含まない。
  ここで得た誤差の大きさを、形の違う機体にそのまま当てはめることはできない。
